# 二叉树的右视图

> **题目**：根据前序遍历和中序遍历恢复二叉树，输出它的右视图（从右侧看过去，每层能看到的那个节点，从上到下）。
> 牛客 BM41 / LeetCode 199。

## 一、核心认知

**右视图 = 每一层最右边的那个节点**，从上到下排成数组。

判断「谁在最右边」有两种视角，对应两条完全不同的路：

| 视角 | 手段 | 天然契合 |
| --- | --- | --- |
| **按层看** | 层序遍历，每层取最后一个 | 直观，和题目「视图」的字面意思一致 |
| **按深度看** | DFS，同深度**第一个被访问**的就是最右 | 省空间，且能顺便省掉建树 |

两条路得到的结果完全一样，但复杂度和代码形态差很多。

## 二、先评价思路：重建 + 层序每层最右 ✅

这个思路**是对的**，也是这题最直白的解法，面试先说出来没问题：

1. 用 `重建二叉树` 的手段（前序第一个是根，`leftSize = k - il`）建出树
2. BFS 层序，每层取队尾那个节点
3. 就是右视图

**但落地时有一个必须卡准的点**：层的边界。

```cpp
while (!q.empty()) {
    int sz = (int)q.size();          // ★ 必须先固定本层节点数
    for (int i = 0; i < sz; ++i) {
        TreeNode* cur = q.front(); q.pop();
        ...
        q.push(cur->left);           // 这里会往队尾加下一层的节点
        q.push(cur->right);
    }
}
```

如果在 `for` 里直接写 `i < q.size()` —— **`q.size()` 会随着 push 不断变大**，`i == sz - 1` 这个「本层最后一个」的判据就彻底失效，右视图会混入其它层的节点。

## 三、解法一：重建 + BFS（你的思路，直观）

```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> res;
        if (!root) return res;
        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            int sz = (int)q.size();
            for (int i = 0; i < sz; ++i) {
                TreeNode* cur = q.front(); q.pop();
                if (i == sz - 1) res.push_back(cur->val);   // 本层最后一个
                if (cur->left)  q.push(cur->left);
                if (cur->right) q.push(cur->right);
            }
        }
        return res;
    }
};
```

也可以把 `if (i == sz - 1)` 换成「每层开始前先记一个值，循环里不断覆盖」，效果一样，但**判 `i == sz - 1` 更直白**。

## 四、解法二：DFS「根-右-左」+ 深度首现（推荐）

**换个视角**：右视图的第 `d` 个元素，就是「所有深度为 `d` 的节点里，最靠右的那个」。

那么在 DFS 里，**只要按「根 → 右 → 左」的顺序访问**，每个深度**第一个**遇到的节点必然是最右的。

```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> res;
        dfs(root, 0, res);
        return res;
    }
private:
    void dfs(TreeNode* node, int depth, vector<int>& res) {
        if (!node) return;
        if (depth == (int)res.size()) res.push_back(node->val);  // 该深度首次出现 = 最右
        dfs(node->right, depth + 1, res);                        // ★ 先右
        dfs(node->left,  depth + 1, res);                        //   后左
    }
};
```

**为什么 `depth == res.size()` 就等价于「该深度还没记录过」**：

`res` 是**严格按深度 0、1、2… 的顺序 append** 的，所以 `res.size()` 永远等于「已记录的最大深度 + 1」。当 `depth == res.size()` 时，说明刚好来了一个比已知最大深度多一层的节点 —— 也就是这个深度的**第一个**节点。

这个写法比 BFS 少一个队列，空间从 `O(n)` 降到 `O(h)`。

⚠️ **顺序绝不能反**：写成「根-左-右」得到的是**左视图**（左斜链上差别最明显）。

## 五、解法三：连树都不建（最优空间）

如果题目只要求右视图、不要求返回树（本题正是如此），那**建树这一步其实可以省掉**。

重建时我们是「前序区间 + 中序区间」两头切；既然 DFS 只需要「根 → 右 → 左」的顺序，那就直接在这两个区间上递归，**根本不用 `new TreeNode`**：

```cpp
class Solution {
public:
    vector<int> solve(const vector<int>& pre, const vector<int>& vin) {
        pos.clear();
        res.clear();
        for (int i = 0; i < (int)vin.size(); ++i) pos[vin[i]] = i;
        dfs(pre, 0, (int)pre.size() - 1, vin, 0, (int)vin.size() - 1, 0);
        return res;
    }
private:
    unordered_map<int, int> pos;
    vector<int> res;

    void dfs(const vector<int>& pre, int pl, int pr,
             const vector<int>& vin, int il, int ir, int depth) {
        if (pl > pr) return;
        int rootVal = pre[pl];
        if (depth == (int)res.size()) res.push_back(rootVal);   // 每层首个 = 最右

        int k = pos[rootVal];
        int leftSize = k - il;

        // ★ 先递归右子树：前序 [pl+1+leftSize, pr]，中序 [k+1, ir]
        dfs(pre, pl + 1 + leftSize, pr,           vin, k + 1, ir, depth + 1);
        // 再递归左子树：前序 [pl+1, pl+leftSize]，中序 [il, k-1]
        dfs(pre, pl + 1,            pl + leftSize, vin, il,  k - 1, depth + 1);
    }
};
```

**注意这里「先右后左」同时影响两件事**：既决定了 `depth` 首现的是最右节点，也决定了递归顺序 —— 但**区间划分公式完全不变**（右子树区间永远是 `[pl+1+leftSize, pr]`），只是调用顺序换了一下。

好处：**省掉 n 次 `new TreeNode`**，也不需要 `queue`。空间只剩哈希表 `O(n)` 和递归栈 `O(h)`。

## 六、三版对比

| | ① 重建 + BFS | ② DFS 根-右-左 | ③ 不建树 DFS |
| --- | --- | --- | --- |
| 时间 | `O(n)` | `O(n)` | `O(n)` |
| 空间 | `O(n)`（队列 + 整棵树） | `O(h)`（递归栈） | `O(n)`（哈希表）+ `O(h)` |
| 是否建树 | 是 | 是 | **否** |
| 额外结构 | `queue` | 无 | `unordered_map` |
| 直观度 | ★★★ 最贴合「视图」字面 | ★★ 需要「深度首现」这个洞察 | ★ 区间划分容易写错 |
| 适用 | 通用；也要返回树的场合 | 返回 `TreeNode*` 的题 | **只返回结果、不返回树**（本题） |

面试建议：**先说 ①（体现「我能把思路落地」），再主动补 ② 或 ③（体现「我还知道有更省的」）**。这题是「能写出 ① 就够，能想到 ② 才加分」的典型。

## 七、易错点

1. **BFS 里 `for (i < q.size())`** —— `size()` 动态变化，层边界失效。**必须先存 `sz`**
2. **DFS 写成「根-左-右」** —— 得到的是左视图
3. **DFS 里用 `depth >= res.size()` 之外的条件判断** —— 必须严格 `==`；用 `>` 会漏记（不可能出现 `depth > size`，但写错方向就一张都不记）
4. **不建树版的区间公式** —— 右子树起点 `pl + 1 + leftSize`，别漏那个 `+1`（和 `重建二叉树` 是同一个坑）
5. **不建树版必须先算 `leftSize` 再递归右子树** —— 否则拿不到右子树的起点
6. **空树返回空数组**，不是返回 `{0}`
7. 题目给的是**引用**参数（`vector<int>&`），别在里面误改原数组

## 八、复杂度

| 维度 | 值 |
| --- | --- |
| 时间 | `O(n)` —— 每个节点访问一次（BFS / DFS 都一样） |
| 空间 | BFS `O(n)` 队列；DFS `O(h)` 栈；不建树版另加 `O(n)` 哈希表 |
| 结果长度 | 恰好等于**树高** `h`（每层一个） |

> 反过来说：**右视图的长度 = 树高**。这是个可以顺手用来校验的小性质。

## 九、面试延伸

- **左视图** → DFS 改成「根-左-右」，其余完全不变
- **每层平均值 / 每层最大值** → 必须 BFS（DFS 得额外按 depth 分组，反而绕）
- **之字形层序（LC103）** → BFS + 按层反转
- **俯视图 / 底视图** → 不能只靠深度，需要**记录水平坐标**（`dfs(node, row, col)`）
- **「为什么 DFS 能代替 BFS」** → 因为「每层最右」这个问题只依赖**深度**这一个维度，而深度在 DFS 里天然可得；一旦问题需要「同层的兄弟关系」（如每层平均值），DFS 就不占优势了

## 十、实测

三版实现用 `g++ -std=c++17 -Wall` 编译（零警告），5 组用例全部一致通过：

| 用例 | pre / vin | 期望 | 结果 |
| --- | --- | --- | --- |
| 甜筒形（右子树更深） | `[1,2,5,3,4]` / `[2,5,1,3,4]` | `[1,3,4]` | 三版均 ✅ |
| 左深右浅 | `[1,2,4,3,5]` / `[4,2,1,3,5]` | `[1,3,5]` | 三版均 ✅ |
| 全左斜链 | `[1,2,3]` / `[3,2,1]` | `[1,2,3]` | 三版均 ✅ |
| 单节点 | `[1]` / `[1]` | `[1]` | 三版均 ✅ |
| 空树 | `[]` / `[]` | `[]` | 三版均 ✅ |

**「全左斜链」这一例最能区分左右视图**：右视图是 `[1,2,3]`（每层只有一个节点，它同时是最左也是最右），如果 DFS 写成「根-左-右」，左斜链上结果**恰好一样**；要区分必须用「左子树深、右子树浅」的用例（第 2 例）。
