### 原理：prefab 资产不能 AddComponent + ScriptableWizard vs EditorWindow 📎[[Unity创建编辑器窗体EditorWindow]]
- **为什么不能给 prefab 资产 AddComponent**：AddComponent 只作用于场景/运行时实例（内存 GameObject 的组件数组）；prefab 资产是磁盘序列化文件无组件数组。正路：实例化 → 实例加组件（可 Undo）→ `PrefabUtility.SaveAsPrefabAsset` 覆盖保存 → 销毁临时实例
- **EditorWindow vs ScriptableWizard**：EditorWindow = 常驻可停靠工作台；ScriptableWizard = 模态向导对话框（自带 Create/Cancel、OnWizardCreate、helpString/errorString/isValid、public 字段自动显示）。长期面板用 EditorWindow；"输入→确认→执行"流程用 Wizard

### FireSim_URP_VR — FireHoseFX 粒子接入 Ignis 灭火 🔥
- **文件**：`Assets/Scripts/Author/LJJ/FireExtinguisher/FireHoseFXToIgnisLink.cs`
- **需求**：水枪粒子命中火焰自动灭火，不需要 WaterGun.cs / IWaterJetReceiver 桥接
- **方案**：FireHoseFX 运行时创建多个 ParticleSystem 子物体（Stream_Droplets / Stream_MicroMist / Nozzle_Atomisation / Impact_*），原 `sendCollisionMessages = false`；本脚本 `Invoke(SetupParticles, 0.2f)` 等初始化完成后，找到目标粒子开启碰撞消息 + `AddComponent<ParticleExtinguish>()`（Ignis 自带灭火组件）
- **关键调参**（关键平衡点）：
  - `particleExtinquishRadius = 0.15f`：扑灭半径，值=cube 一边长时单颗粒子秒灭整个 cube
  - `incrementalPower = 0.0005f`：单颗粒子扑灭量，约 0.0001~0.001
  - 只用 Droplets（约 386 颗/秒）灭火节奏最可控 ≈5 秒；勾 Mist 灭火更快但容易秒灭
- `LateUpdate` 每帧保险：防止 sendCollisionMessages 被外部改回
- 粒子类型过滤 `ShouldApplyTo`：按名字 Droplets/Mist/Nozzle/Impact 分类应用

```csharp
void SetupParticles()
{
    var particles = GetComponentsInChildren<ParticleSystem>(true);
    foreach (var ps in particles)
    {
        if (!ShouldApplyTo(ps.name)) continue;
        var collision = ps.collision;
        collision.sendCollisionMessages = true;   // FireHoseFX 默认 false
        var pe = ps.GetComponent<ParticleExtinguish>();
        if (pe == null) pe = ps.gameObject.AddComponent<ParticleExtinguish>();
        pe.particleExtinquishRadius = particleExtinquishRadius;
        pe.incrementalPower = incrementalPower;
    }
}
```
