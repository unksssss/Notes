# 排序算法：快排 / 归并 / 堆排

## 对比总览（必背）

| 算法 | 平均时间 | 最坏时间 | 额外空间 | 稳定 | 特点 |
|------|---------|---------|---------|------|------|
| 快排 | O(n log n) | **O(n²)** | O(log n) | ❌ | 平均最快，怕有序数组 |
| 归并 | O(n log n) | O(n log n) | **O(n)** | ✅ | 稳定，适合外部排序 |
| 堆排 | O(n log n) | O(n log n) | **O(1)** | ❌ | 省内存，常数大实际慢 |

> **记忆口诀**：快排快但怕有序、归并稳但费内存、堆排省内存但慢常数。

## 1. 快速排序（平均之王）

**思想**：分治三步走
1. 选基准（pivot）
2. 分区：比基准小的放左边、大的放右边（基准归位）
3. 递归对左右子区间重复

**复杂度**：
- 平均 O(n log n)：分区大致对半，递归 log n 层，每层扫 n 个元素
- **最坏 O(n²)**：已有序数组 + 固定取末尾基准 → 每次只切出一边，递归深度退化为 n
- 空间 O(log n)（递归调用栈），**最坏退化为 O(n)**

**⚡ 最经典的坑：不稳定！**
交换时相等元素相对顺序可能被打乱：`[3a, 3b, 1]` → `[1, 3b, 3a]`

**优化**：随机选基准 / 三数取中，把最坏情况概率压到几乎为零。

## 2. 归并排序（稳定暖男）

**思想**：分治（和快排相反顺序）
1. 数组对半拆，拆到单元素（天然有序）
2. 两两合并：双指针从小到大归并成有序区间

**复杂度**：
- 时间稳定 O(n log n)，任何输入都不退化
- 空间 O(n)：合并需要辅助数组
- **稳定**：合并时相等元素先取左半边

**适用**：外部排序（数据大到内存装不下）、链表排序（顺序访问，天然适配归并）。

**为什么归并适合链表/外部排序，快排不行（Day 23 加深）**：
- **链表**：归并的合并只需顺序遍历两个有序序列，链表天然只支持顺序访问；快排的 partition 要随机访问 + 双向扫描交换，链表上定位第 i 个元素是 O(n)，直接退化
- **外部排序（超大文件）**：切块 → 每块读入内存排成有序段（run）→ **多路归并**逐段合并写回磁盘，内存永远只装得下几块；快排需要**全量数据在内存**随机访问，物理上做不到
- **稳定性**：归并稳定（相等元素保持原序），多关键字排序（先按 A 再按 B）时第一轮顺序不丢；快排交换会打乱
- **复杂度保证**：归并任何输入都是 O(n log n)；快排最坏 O(n²)（有序数组 + 固定基准），随机化/三数取中也只是概率缓解

## 3. 堆排序（省内存硬汉）

**思想**：数组表示完全二叉树（大顶堆：父 ≥ 子）
1. **建堆**：乱序数组调整成大顶堆，堆顶 = 最大值
2. **排序**：堆顶与末尾交换 → 堆大小减 1 → 堆顶下沉（sift down）恢复堆性质
3. 重复直到堆空

**复杂度**：
- 最坏也 O(n log n)，输入好坏都稳定
- 空间 O(1)：原地排序
- **不稳定**：交换堆顶/末尾时相等元素相对顺序可能变

**缺点**：常数大、cache 不友好（跳跃访问），工程上通常比快排慢。

**⚡ 数组 ↔ 完全二叉树索引映射（必背）**：
```
索引 i 的节点：
  左孩子 = 2*i + 1
  右孩子 = 2*i + 2
  父节点 = (i-1) / 2
```

**下沉（sift down）**：堆的核心操作——把某节点与较大的孩子交换，直到父 ≥ 子。单次 O(log n)。

**⚡ 建堆是 O(n) 不是 O(n log n)（面试最爱挖的坑！Day 18/19 连续复习）**：
从最后一个非叶节点（`n/2 - 1`）倒着逐个下沉，越靠近底层的节点下沉次数越少，总操作数求和是**线性**的。多数人误以为是 O(n log n)。

**核心直觉**：堆 ≠ 有序数组，只保证"父 ≥ 子"（大顶堆），所以**只有堆顶是全局最大值，兄弟之间无序**。排序 = 反复"堆顶与末尾交换 → 堆大小减 1 → 堆顶下沉"，共 n-1 次 × O(log n) = O(n log n)。

**⚡ 升序还是降序？（Day 33 灯皇答反过，必背口诀）**：
- **大顶堆 → 升序**：堆顶是最大，与末尾交换 → 大数依次归位到**数组尾部**，从后往前填，前段自然剩最小
- **小顶堆 → 降序**：堆顶是最小，先被扔到末尾
- 口诀：**"大顶堆，尾巴先放大，排出来升序；要降序就换小顶堆"**

**排序阶段逐轮演算（Day 33 教学，例 [12,9,8,5,6,4,3] 大顶堆）**：
```
第1轮: 12↔3 堆缩[0..5] 3下沉2层 → [9,6,8,5,3,4 | 12]
第2轮: 9↔4  堆缩[0..4] 4下沉2层 → [8,6,5,4,3 | 9,12]
第3轮: 8↔3  堆缩[0..3] 3下沉2层 → [6,4,5,3 | 8,9,12]
第4轮: 6↔3  堆缩[0..2] 3下沉1层 → [5,4,3 | 6,8,9,12]
第5轮: 5↔3  堆缩[0..1] 3下沉1层 → [4,3 | 5,6,8,9,12]
第6轮: 4↔3  → [3 | 4,5,6,8,9,12]  完成：升序 ✅
```
每轮三件事：**交换堆顶↔堆尾 → heapSize-- → 新堆顶下沉**；已排序区永远在数组尾部（竖线右侧），不再参与堆操作。

## 面试高频题

1. **快排为什么最坏是 O(n²)？** → 每次基准都是最值，分区退化成每次只去掉一个元素，递归深度 n
2. **哪个排序稳定？** → 归并 ✅；快排/堆排 ❌
3. **排序大文件用哪个？** → 归并（外部排序，分段读入内存归并）
4. **要求 O(1) 空间 + 保证最坏 O(n log n)？** → 堆排
