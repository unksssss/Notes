# 动态规划入门

## 两大核心概念

1. **最优子结构**：大问题的最优解可以由子问题的最优解组合出来。
   - 例：到第 n 级台阶的走法 = 到第 n-1 级的走法 + 到第 n-2 级的走法
2. **重叠子问题**：子问题被反复计算。
   - 朴素递归算斐波那契，`F(5)` 要算 `F(3)` 两次、`F(2)` 三次……指数爆炸 O(2ⁿ)

> DP 的本质：**用空间换时间**，把重复计算的子问题结果缓存下来（数组 / 记忆化）。

## 三板斧套路

1. **定义状态**：`dp[i]` 表示什么？（一切的基础）
2. **写状态转移方程**：`dp[i]` 怎么由前面的状态推出来？（核心难点）
3. **定初始值和遍历顺序**：`dp[0]`/`dp[1]` 是多少？从前往后还是从后往前？

## 经典例题：爬楼梯

**原题**：一次能上 1 级或 2 级，爬到第 n 级有多少种走法？

- 状态：`dp[i]` = 爬到第 i 级的走法数
- 转移：`dp[i] = dp[i-1] + dp[i-2]`（最后一步要么跨 1 级、要么跨 2 级，互斥所以相加）
- 初始：`dp[1] = 1`，`dp[2] = 2`
- 答案：`dp[n]`，O(n) 时间

**变体（面试高频）**：一次只能上 1 级或 **3 级**：

- 转移：`dp[i] = dp[i-1] + dp[i-3]`（最后一步跨 1 级或 3 级）
- 初始：`dp[1] = 1`（只能 1 级）、`dp[2] = 1`（只能 1+1）、`dp[3] = 2`（1+1+1 或直接跨 3 级）

## ⚠️ 易混点：方法数 vs 最少步数（Day 20 失分）

爬楼梯有两个长得极像但**转移方程完全不同**的变体，面试必考：

| 问法 | 转移方程 | 例子 |
|---|---|---|
| **"多少种走法 / 方案数"** | **加法**：`dp[i] = dp[i-1] + dp[i-2]` | 到 n 级台阶的方法数 |
| **"最少需要几步 / 最小成本"** | **min + 1**：`dp[i] = min(dp[i-1], dp[i-2]) + 1` | 跳到 n 级的最少步数 |

**判断口诀**：问**"数量 / 方案"** → 情况互斥相加（组合计数）；问**"最值 / 成本"** → `min`/`max` 取优再加一（最优化）。

注意边界也别混：方法数 `dp[1]=1, dp[2]=2`；最少步数 `dp[0]=0, dp[1]=1, dp[2]=1`（一次跨 2 级只需 1 步）。
