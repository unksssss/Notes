#### A 组 · 螺旋矩阵第三版：改成边界收缩，只剩一个字母（LC 54 / BM98）

前两版（哈希表记访问 → 死循环 TLE；转向模拟 + `%3`）之后，第三版终于走对路线 —— 四边界收缩 + 后两条边加 `if`，结构完全正确，**只剩初始化一个字母**。

| # | 问题要点 | 知识点 | 处理 |
| --- | --- | --- | --- |
| A1 | `int bottom = n - 1;` 为什么错 | `bottom` 是**最大行号**，必须用行数 `m`；写成列数 `n` 就错位 | 已讲解 / 已补记 📎 [[螺旋矩阵]] |
| A2 | 本地"跑通了"是怎么回事 | 方阵 `m == n` 时 `n - 1 == m - 1`，**用例规模掩盖了错误** | 已讲解 |
| A3 | 非方阵实测表现 | m<n 越界段错误（3×4 / 2×3 / 1×3）；m>n 漏数据（4×3 漏末行、3×1 只剩 `[1]`） | 已讲解 |
| A4 | 自测该测哪些用例 | 铁律：**至少各测一个 `m > n` 和一个 `m < n`** —— 3×4 暴露越界崩、4×3 暴露少一行 | 已讲解 |
| A5 | 判了 `matrix.empty()`，`matrix[0].empty()` 要不要判 | `{{}}` 时 `right = -1` 循环不进、恰好安全，但建议一起判掉 | 已讲解 |
| A6 | `bottom--` / `left++` 写在 `if` 里面对不对 | `if` 与 `while` 条件同源，为假时本就该退出，结果等价；标准写法放外面更省心 | 已讲解 |

只把 `n - 1` 改成 `m - 1`，9 组用例（含 3×4 / 4×3 / 3×1 / 1×3）全部正确。

#### B 组 · 旋转矩阵（牛客 BM99 / LC 48）：四路映射全对，错在转几格

| # | 问题要点 | 知识点 | 处理 |
| --- | --- | --- | --- |
| B1 | 原地四路轮换的映射对不对 | `(r,c) → (c, n-1-r)`，四位置闭环 + `temp` 存第一个 → 轮换四次归位，`O(1)` 空间 | 已讲解 / 已归档 📎 [[旋转矩阵]] |
| B2 | `for (i = 0; i < n - 1; i++)` 错在哪 | 每层要转的次数是**当前层边长 − 1 = `right - left`**，不是整行长度 | 已讲解 |
| B3 | 为什么 n ≤ 3 全对 | n=3 只有第 0 层，`n-1` 恰好等于所需次数；内层 `left == right` 直接退出 | 已讲解 |
| B4 | n = 4 / 5 / ≥6 分别什么现象 | 4、5：内层多转 → 结果错乱；≥6：越界（n=6 第 3 层 i=4 访问 `mat[2][6]`）→ 段错误 | 已讲解 |
| B5 | 最不容易写错的写法 | 转置（`j = i + 1` 只走上三角）+ 逐行 `reverse` —— 两次简单置换合成一个复杂置换 | 已讲解 |
| B6 | 顺 / 逆 / 180° 的统一口诀 | 顺时针 = 转置 + 行 reverse；逆时针 = 转置 + 列 reverse；180° = 行 reverse + 上下 reverse | 已讲解 |

> **两题同一个病灶**：正确性被**用例规模**兜住了 —— 螺旋矩阵靠方阵、旋转矩阵靠 n≤3。这类"小规模必过、中规模错乱、大规模崩"的 bug 最难自查，因为第一组用例永远是绿的。
