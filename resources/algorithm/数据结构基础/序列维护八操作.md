# 序列维护八操作

## 一、题目

维护一个初始为空的整数序列，`q` 次操作（`q ≤ 7×10³`）：

| op | 格式 | 含义 |
|---|---|---|
| 1 | `1 x` | 尾部追加 `x` |
| 2 | `2` | 删除末尾（保证非空） |
| 3 | `3 i` | 输出下标 `i`（0 起） |
| 4 | `4 i x` | 在下标 `i` 与 `i+1` 之间插入 `x` |
| 5 | `5` | 升序排序 |
| 6 | `6` | 降序排序 |
| 7 | `7` | 输出长度 |
| 8 | `8` | 输出整个序列，空格分隔 |

## 二、核心认知

**这题不是算法题，是「题面 → 标准库」的翻译题。**

8 个操作逐一对应 `std::vector` 的一个成员/算法，一个都不需要自己实现：

| op | vector 写法 | 复杂度 |
|---|---|---|
| 1 追尾 | `a.push_back(x)` | 摊还 `O(1)` |
| 2 删尾 | `a.pop_back()` | `O(1)` |
| 3 查下标 | `a[i]` | `O(1)` |
| 4 中间插入 | `a.insert(a.begin() + i + 1, x)` | `O(n)` |
| 5 升序 | `sort(a.begin(), a.end())` | `O(n log n)` |
| 6 降序 | `sort(a.begin(), a.end(), greater<int>())` | `O(n log n)` |
| 7 长度 | `a.size()` | `O(1)` |
| 8 整行输出 | 遍历 + 空格控制 | `O(n)` |

`q ≤ 7×10³`，最坏情况全是在头部插入 → `q²/2 ≈ 2.5×10⁷` 次搬移，**vector 完全够用**，不需要平衡树或块状链表。

## 三、完整代码（ACM 模式）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int q;
    if (!(cin >> q)) return 0;

    vector<int> a;
    a.reserve(q + 1);              // 最多 q 次插入，预留免扩容

    while (q--) {
        int op;
        cin >> op;
        switch (op) {
            case 1: { int x; cin >> x; a.push_back(x); break; }
            case 2: { a.pop_back(); break; }
            case 3: { int i; cin >> i; cout << a[i] << '\n'; break; }
            case 4: { int i, x; cin >> i >> x; a.insert(a.begin() + i + 1, x); break; }
            case 5: { sort(a.begin(), a.end()); break; }
            case 6: { sort(a.begin(), a.end(), greater<int>()); break; }
            case 7: { cout << a.size() << '\n'; break; }
            case 8: {
                for (size_t j = 0; j < a.size(); ++j) {
                    if (j) cout << ' ';          // ★ 行末不留空格
                    cout << a[j];
                }
                cout << '\n';                    // ★ 空序列也要换行
                break;
            }
        }
    }
    return 0;
}
```

## 四、四个坑（按踩坑概率排序）

### ① 空序列执行 op8 要输出「一个空行」

```cpp
if (!a.empty()) { ... }   // ❌ 空序列时这一行什么都不输出
```

题目说「输出当前整个序列，元素之间用空格分隔」—— 空序列就是一个**空行**。写成"非空才输出"会让空序列那次操作少一行，后面所有输出整体错位。

正确做法：**循环可以为空，但换行必须执行**。

### ② 行末不能多空格

```cpp
for (int j = 0; j < n; ++j) cout << a[j] << ' ';   // ❌ 末尾多一个空格
for (size_t j = 0; j < a.size(); ++j) {
    if (j) cout << ' ';
    cout << a[j];
}                                                   // ✅
```

多数 OJ 对行末空格宽容，但也有严格比对（Presentation Error / WA）的。养成习惯。

### ③ 插入下标是 `i + 1`

「在下标 `i` 与 `i+1` 之间插入」= 新元素**成为新的下标 `i+1`**，所以是 `a.begin() + i + 1`。

写成 `a.begin() + i` 就变成"插在 `i` 前面"，整体左移一位。

注意 `i` 的合法范围是 `0 ≤ i < size`，所以 `i + 1 ≤ size`，`begin() + size == end()` 也是合法插入位置 —— 当 `i == size-1` 时正好插到末尾，不会越界。

### ④ `size()` 是 `size_t`

`cout << a.size()` 没问题（无符号），但 `for (int j = 0; j < a.size(); ++j)` 会有符号/无符号比较警告（`-Wsign-compare`）。写 `size_t j` 或在 `case 3` 里 `int i` 与 `size()` 比较时注意。

## 五、复杂度

| 项 | 值 |
|---|---|
| 最坏时间 | `O(q²)`（全是中间插入）≈ 2.5×10⁷ 次搬移，`q ≤ 7×10³` 稳过 |
| 排序 | 每次 `O(n log n)`，`n ≤ q` |
| 空间 | `O(q)` |

**如果 `q` 到 1e5**：`O(q²)` 就是 1e10，过不了 → 需要块状链表（`__gnu_pbds` / 手写分块）或平衡树（按 rank 插入）。本题数据范围明确不需要。
