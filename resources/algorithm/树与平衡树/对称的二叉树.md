# 对称的二叉树

对应 **剑指 Offer 28 / LeetCode 101**。

> 题面：给定一棵二叉树，判断它是否是自身的镜像（即是否轴对称）。
> - 对称的严格含义：`root->left` 与 `root->right` 互为镜像；
> - 空树视为对称。

## 一、核心认知：对称是「结构镜像」，不是「序列回文」

对称的递归定义（写代码前必须先说清楚这个）：

```
isMirror(a, b) 成立 ⟺
    a->val == b->val
    且 isMirror(a->left,  b->right)
    且 isMirror(a->right, b->left)
```

注意配对是**交叉**的：`a->left` 对 `b->right`。

对称的树，其中序遍历**确实**回文（所以回文是**必要条件**），但反过来**不成立** —— 因为遍历序列丢掉了「节点挂在左边还是右边」的结构信息。

### ❌ 反例（中序回文但不对称）

```
       1
      / \
     2   3
    /   /
   3   2
```

- 中序遍历 = `3, 2, 1, 2, 3` → **完全回文** ✓
- 但 `root->left = 2`、`root->right = 3`，值不等 → **不对称** ✗

所以「中序遍历 + 序列逆序比较」这条路**判据本身就不成立**。

## 二、❌ 初版思路的实现问题（即使判据对了也跑不通）

初版思路：中序遍历，把「根节点之前」的节点值存入 `vector`，之后把节点值与 `vector` 逆序比对。

| # | 问题 | 说明 |
| --- | --- | --- |
| 1 | **`result[i]` 越界（UB）** | `i` 初值 0、`push_back` **之后**才 `i++`，导致 `i` 恒等于 `size()` —— 比较时访问的是**尾后位置** |
| 2 | **左子树为空时必然越界** | 此时 `result` 是空 `vector`，第一个比较就是 `result[0]` |
| 3 | **`i--` 到负数后继续访问** | 没有 `i >= 0` / 非空判断 |
| 4 | **不提前剪枝** | `r = r && ...` 即使已经是 false 也把整棵树走完 |
| 5 | **变量名遮蔽模板名** | `stack<TreeNode*> stack;` 在 `using namespace std` 下变量 `stack` 遮蔽 `std::stack`，后续再用模板就编译失败 |
| 6 | **状态机可读性极差** | `isBeginJudge` + `cur == pRoot` 判分割点。这个判断**本身是对的**（中序中根之前的节点恰为左子树），但没必要这么绕 |

**关键结论**：把上面 6 条全部修好（比如让 `i = result.size() - 1`），拿第一节的反例跑，依然会返回 `true` —— 判据错了，实现再干净也没用。

## 三、解法一：递归镜像（首选）

```cpp
class Solution {
public:
    bool isSymmetrical(TreeNode* pRoot) {
        if (!pRoot) return true;                        // 空树视为对称
        return isMirror(pRoot->left, pRoot->right);
    }

private:
    bool isMirror(TreeNode* a, TreeNode* b) {
        if (!a && !b) return true;                      // 1. 都空 → 这一对对齐
        if (!a || !b) return false;                     // 2. 一空一非空 → 结构不对齐
        if (a->val != b->val) return false;             // 3. 值不等
        return isMirror(a->left,  b->right)             // ★ 交叉：左对右
            && isMirror(a->right, b->left);             // ★ 交叉：右对左
    }
};
```

### 必须记住的点

**① 三个终止条件的顺序不能换**

`(!a && !b)` 必须排第一：它既是「都空则对称」的判定，也顺手挡掉了后面所有的解引用。先比值就会空指针崩溃。

**② 交叉比较，不是同侧比较**

写成 `isMirror(a->left, b->left) && isMirror(a->right, b->right)` 就变成「判两棵树是否完全相同」（LC100）了。

**③ 空树 / 单节点都返回 true**

`isMirror(nullptr, nullptr)` → `true`，单节点树自然对称。

## 四、解法二：迭代 + 队列（BFS 变形）

```cpp
bool isSymmetrical(TreeNode* pRoot) {
    if (!pRoot) return true;
    queue<TreeNode*> q;
    q.push(pRoot->left);
    q.push(pRoot->right);                              // 成对入队
    while (!q.empty()) {
        TreeNode* a = q.front(); q.pop();
        TreeNode* b = q.front(); q.pop();               // 每次弹出成对的两个
        if (!a && !b) continue;                         // 都空：跳过，别把空指针塞进队列
        if (!a || !b || a->val != b->val) return false;
        q.push(a->left);  q.push(b->right);             // ★ 交叉入队
        q.push(a->right); q.push(b->left);
    }
    return true;
}
```

`if (!a && !b) continue;` **不能省** —— 省了会把两个空指针的子树继续塞进队列，队列膨胀且失去意义。

## 五、解法三：中序 + 逆中序双栈同步走（不推荐）

若面试官要求「保留中序思路且非递归」，可以做「左-根-右」与「右-根-左」两个栈同步推进、逐个比对。本质仍是镜像比较，只是把递归换成了显式栈，**代码量翻倍、边界更多，面试不推荐**。

## 六、易错点

1. **用中序遍历回文判对称** → 会误判（反例见第一节），这是本题最大的陷阱
2. 交叉比较写成同侧比较 → 变成判「两棵树相同」
3. 终止条件顺序写反（先比值后判空）→ 空指针解引用
4. 队列版漏掉 `if (!a && !b) continue;` → 空指针对继续入队
5. 幻想用 BST 那一套「中序 = 升序」的判据 → **这里没有 BST 性质可用**，题目给的是普通二叉树

## 七、复杂度

| 维度 | 值 |
| --- | --- |
| 时间 | **O(n)**，每个节点恰好访问一次 |
| 空间 | 递归 **O(h)**；队列版最坏 **O(n)**（完全二叉树最后一层） |
| 剪枝 | 一旦发现不对称立即 `return false`，不必走完全树 |

## 八、面试延伸

- **「把这棵树翻转成镜像」** → LeetCode 226，递归交换左右孩子
- **「判两棵树是否相同」** → LeetCode 100，**同侧**比较（与本题的唯一差别）
- **「判两棵树是否互为镜像」** → 本题的泛化，直接调 `isMirror(T1, T2)`
- **「对称 N 叉树」** → 子节点数组反转后逐个比较
- **「迭代怎么写」** → 队列 / 栈成对入队，注意交叉
- **思想层面**：**判结构必须递归到结构**；遍历序列只保留「值 + 相对顺序」，丢掉了父子归属信息
