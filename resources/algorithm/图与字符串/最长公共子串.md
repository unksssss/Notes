# 最长公共子串

## 一、题目

给两个字符串，求它们的**最长公共子串**（要求在原串中**连续**），返回这个子串。

```
"1AB2345CD" 和 "12345EF"   →  "2345"
"abcde"     和 "bc"        →  "bc"
"abc"       和 "def"       →  ""
```

## 二、核心认知：连续 vs 可跳，只差一行转移

这题最容易错的不是 DP 的骨架，而是**把「子串」当成「子序列」来做**。两者只差一个转移式：

| 题目 | 允许跳过字符吗 | 不等时的转移 | 输入 `abc` / `ac` |
|---|---|---|---|
| **最长公共子串** LC718 | **不允许**（必须连续） | `dp[i][j] = 0` ★ | `"a"` 或 `"c"`，长度 **1** |
| 最长公共子序列 LC1143 | 允许 | `dp[i][j] = max(上, 左)` | `"ac"`，长度 **2** |

**为什么子串要归零**：`dp[i][j] = 以 s1[i-1]、s2[j-1] 结尾的公共子串长度`。既然必须「以这两个字符结尾」，那这两个字符不相等时，这个「以它们结尾的串」根本不存在 —— 长度只能是 0。不能像子序列那样「继承前面的最优值」，因为继承来的值意味着**结尾不是当前字符**，那就断了连续性。

> **一句话**：子序列的 DP 是「求最大值」，子串的 DP 是「求最长后缀」。

## 三、状态定义与转移

```
dp[i][j] = s1 的前 i 个字符 与 s2 的前 j 个字符 中，以 s1[i-1] 和 s2[j-1] 结尾的最长公共子串长度
```

```cpp
if (s1[i-1] == s2[j-1])
    dp[i][j] = dp[i-1][j-1] + 1;     // 接上前面那段
else
    dp[i][j] = 0;                     // ★ 断链，归零（不是 max！）
```

`dp[0][*]` 和 `dp[*][0]` 全 0（空串没有公共子串），所以数组开 `(n+1) × (m+1)`，下标从 1 开始，`i-1` 才对应真实字符。

## 四、★ 答案怎么取：边填边记，不要回头反推

这是灯皇初版翻车的第二个地方 —— 他的 `anwser()` 试图扫描 `dp` 的**最后一行**，找「哪一段是递增的」，然后 `str2[left..right]` 拼答案。

**这个思路行不通**，原因有两个：

1. **最后一行只是 `s2` 每个字符对 `s1` 整体的匹配情况**，它不包含「这一段是不是连续」的信息；
2. 用 `max` 转移时最后一行是**单调递增**的（如 `0,1,1,2`），任何递增段都能被误认为答案 —— 这正是「把前一个字符错误加入结果」的来源。

正确做法：**在填表的过程中，顺手记住最大值和它出现的行号**。

```cpp
int best = 0, endi = 0;             // best = 最大长度，endi = 最大值所在的行（对应 s1 的结束下标）
if (dp[i][j] > best) { best = dp[i][j]; endi = i; }
...
return best ? s1.substr(endi - best, best) : "";
```

**`endi - best` 的来历**：`dp[i][j]` 是「以 `s1[i-1]` 结尾」的长度 `best`，所以这段串的起点是 `i - best`（0-based 的 `s1` 里，结束位置 `i-1`，起点 `i-1-best+1 = i-best`）。

## 五、完整代码

```cpp
class Solution {
public:
    string LCS(string str1, string str2) {
        int n = (int)str1.size(), m = (int)str2.size();
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
        int best = 0, endi = 0;

        for (int i = 1; i <= n; ++i) {
            for (int j = 1; j <= m; ++j) {
                if (str1[i - 1] == str2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                    if (dp[i][j] > best) { best = dp[i][j]; endi = i; }
                } else {
                    dp[i][j] = 0;                  // ★ 子串：断链归零
                }
            }
        }
        return best ? str1.substr(endi - best, best) : "";
    }
};
```

**只求长度时**（LC 718 可以不要串）就不用 `endi`，只维护 `best`。

## 六、滚动数组：空间从 O(nm) 降到 O(m)

`dp[i][j]` 只依赖 `dp[i-1][j-1]`（左上角）。所以整张表只需要**两行**：

```cpp
string LCS(string str1, string str2) {
    int n = (int)str1.size(), m = (int)str2.size();
    vector<int> prev(m + 1, 0), cur(m + 1, 0);
    int best = 0, endi = 0;

    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= m; ++j) {
            if (str1[i - 1] == str2[j - 1]) {
                cur[j] = prev[j - 1] + 1;
                if (cur[j] > best) { best = cur[j]; endi = i; }
            } else {
                cur[j] = 0;
            }
        }
        swap(prev, cur);
        fill(cur.begin(), cur.end(), 0);      // ★ 清空旧行，否则残留值会污染
    }
    return best ? str1.substr(endi - best, best) : "";
}
```

⚠️ `fill(cur.begin(), cur.end(), 0)` 不能省。`cur` 是上一轮换下来的 `prev`，里面全是旧数据，不清理就会把「上一行的值」当成「左上角」。

> 更省的做法是**单行 + 倒序遍历 `j`**（`dp[j] = dp[j-1] + 1` 从右往左），但那要求只求长度、不回溯字符串。这题要返回串，双行更清晰。

## 七、复杂度

| 版本 | 时间 | 空间 |
|---|---|---|
| 二维 DP | `O(n·m)` | `O(n·m)` |
| 滚动数组 | `O(n·m)` | **`O(m)`** |
| 暴力（枚举起点 + `string::find`） | `O(n²·m)` | `O(1)` |

面试先写二维版（好讲、好回溯答案），被追问「能不能省空间」再上滚动数组。

## 八、灯皇初版的 6 处错误

原代码实测 **10 例 5 错**：

| 输入 | 期望 | 初版输出 | 症状 |
|---|---|---|---|
| `1AB2345CD` / `12345EF` | `2345` | **`1234`** | 多了一个前导字符 |
| `abcdef` / `zab` | `ab` | **`za`** | 完全跑偏 |
| `abcde` / `bc` | `bc` | **`c`** | 少了一个 |
| `abc` / `def` | `""` | **`f`** | 无解却输出了字符 |
| `""` / `abc` | `""` | **`c`** | 无解却输出了字符 |

| # | 错误 | 后果 |
|---|---|---|
| 1 | **转移用 `max(dp[i-1][j], dp[i][j-1])`** | 这是**子序列**的写法，不是子串 |
| 2 | **判据 `str1[i] == str2[j] && str1[i-1] == str2[j-1]`** | ① 多要了一个条件；② `str1[i]`、`str2[j]` 在 `i == size()` 时**越界** |
| 3 | **`anwser()` 从 dp 表最后一行反推** | 最后一行不含「连续性」信息，无法定位答案 |
| 4 | **`left`/`right` 的更新逻辑** | 无法表达「哪一段是最长公共子串」，只能凑出一段区间 |
| 5 | **`str2[i]` 当 `i == size()`** | C++11 起返回 `'\0'`（合法但无意义），`push_back` 后输出时看不见 → 表现为「多一个空字符 / 少一个字符」 |
| 6 | **`anwser(string, vector<vector<int>> dp)` 按值传** | 每调用一次拷贝整张表，`O(nm)` 白白浪费；应传 `const&` |

**第 2 条的越界最隐蔽**：`for (int i = 1; i < dp.size(); i++)` 里 `i` 最大到 `dp.size()-1 == str1.size()`，而 `str1[str1.size()]` 是越界读。`std::string::operator[]` 在 `pos == size()` 时返回 `'\0'`（C++11 明确允许），所以**不崩**，但读到的是假数据 —— 又一个「不报错的错」。

## 九、三个概念别混

| 概念 | 英文 | 是否连续 | 典型题 |
|---|---|---|---|
| 最长公共**子串** | Longest Common **Substring** | ✅ 必须连续 | LC 718 / BM66 |
| 最长公共**子序列** | Longest Common **Subsequence** | ❌ 可跳 | LC 1143 |
| 最长公共**前缀** | Longest Common **Prefix** | ✅ 且必须从下标 0 开始 | [[最长公共前缀]] LC 14 |

**记法**：Substring 里有 "string"，字符串是**一整条连续的**；Subsequence 里有 "sequence"，序列**可以挑着取**。

## 十、易错点

1. **`else` 分支写 `max`** → 变成子序列，答案偏大（最常见）
2. **答案从 dp 表反推** → 必须边填边记 `best` + `endi`
3. **`s1[i]` 与 `s1[i-1]` 混用** → 1-based DP 配 0-based 字符串，`i-1` 才对
4. **`substr` 第二个参数是长度不是下标** → `substr(endi-best, best)`
5. **`best == 0` 时要返回空串** → 否则 `substr(n, 0)` 虽然合法，但如果算错下标会抛 `out_of_range`
6. **滚动数组忘清空 `cur`** → 残留旧值污染
7. **按值传 `dp`** → 白白拷贝

## 十一、面试延伸

- **「返回任意一个最长公共子串」** → 本题；**「返回长度」** → 去掉 `endi` 即可
- **「多个最长解，返回字典序最小的」** → 记录所有 `endi`，或按字典序比较候选
- **「n ≤ 10^5 怎么做」** → DP 的 `O(nm)` 过不了，要上**后缀自动机 / 后缀数组 + 二分哈希**，`O(n log n)`
- **「两个串的公共子串个数」** → 后缀自动机，跟本题不是一个思路
- **和 KMP 的关系** → 求「一个串是否包含另一个」用 KMP `O(n+m)`；求「最长的公共部分」才需要 DP 或后缀结构
