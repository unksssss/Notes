# 多项式输出

## 一、题意与六条规则

给 `n` 和 `n+1` 个整数 `aₙ, aₙ₋₁, …, a₀`（保证 `aₙ ≠ 0`），按标准形式输出多项式。

规则全在这六条里，**每一条都是一个 if**：

| # | 规则 | 例子 |
|---|---|---|
| 1 | 从**最高次**往低次输出 | 先 `x^3` 再 `x^2` |
| 2 | 系数为 **0** 的项**整项不输出** | `0x^4` → 不写 |
| 3 | 系数为 **±1** 时**省略数字**（**常数项除外**） | `1x^2` → `x^2`；但 `1` 要写成 `1` |
| 4 | 次数为 **1** 时写 `x`，不写 `x^1` | `3x^1` → `3x` |
| 5 | 次数为 **0** 时只写系数 | `5x^0` → `5` |
| 6 | **第一项**系数为正时**不加 `+`** | `x^3+x` 不是 `+x^3+x` |

样例：

```
输入          输出
3              x^3-x^2+1
1 -1 0 1

5              100x^5+1
100 0 0 0 0 1
```

## 二、你问的那个「1 省略不了」

```cpp
if (a[j].length() == 1 && a[j][0] == 1) {   // ❌
    temp += "x^" + to_string(i);
    continue;
}
```

**`a[j][0]` 是 `char`，`1` 是 `int`。** 两者比较时，`char` 会提升成 `int` —— 但提升的是**字符编码**：

```cpp
char ch = '1';
ch          →  49        // ASCII
ch == 1     →  false     // 49 != 1
ch == '1'   →  true
```

所以 `a[j][0] == 1` **恒为假**，这个分支一次都没进过，「省略 1」自然没生效。

实测（你这份代码）：

```
n=3  系数: 1 -1 0 1
  你的    1x^3-x^2+0x^1+1x^0     ← 1 全都留着
  正确    x^3-x^2+1
```

同理 `a[j][1] == 1`（判断 `"-1"`）也是同样的问题 —— 两个分支**都**没生效。

> **这是 C++ 里最经典的静默失效之一**：不报错、不警告，编译通过，逻辑永远走 else。
> 编译器其实**有能力**警告：`-Wchar-subscripts` 不管这个，但 `-Wall` 下把整数和字符比通常也不提醒。
> 判断标准：**只要看到 `x[i] == 某个数字`，先问一句「这是字符还是整数？」**

## 三、更麻烦的：改了 `'1'` 反而更错

那个 `continue` 是个陷阱：

```cpp
if (...) {
    temp += "x^" + to_string(i);
    continue;              // ← 直接跳到下一轮，跳过末尾的 result += temp
}
...
result += temp;            // ← 首项的输出就这样丢了
```

实测只把 `== 1` 改成 `== '1'`：

```
n=3  系数: 1 -1 0 1
  你的       1x^3-x^2+0x^1+1x^0
  只改'1'    -x^2+0x^1+x^0          ← x^3 项整个消失！
  正确       x^3-x^2+1
```

**修了一个 bug，暴露了另一个。** 这也是为什么「看到 bug 就改一处、跑一下还是不对」很容易让人怀疑方向 —— 其实是对了，只是撞上了下一层。

> **纪律：`continue` 前面必须确认「有没有本该在循环末尾执行、但会被跳过的语句」。**
> 更稳的写法是**永远不写 `continue`**，用 `if/else` 把分支写完。

## 四、另外三处

### ① 系数为 0 没跳过

```cpp
n=5  系数: 100 0 0 0 0 1
  你的    100x^5+0x^4+0x^3+0x^2+0x^1+1x^0
  正确    100x^5+1
```

零系数项必须**整项消失**，连 `+` 都不能留。

### ② `x^1` 和 `x^0` 没特判

```
x^1  →  应该写 x
x^0  →  应该只写系数（x^0 = 1，不用写出来）
```

你的输出里 `0x^1`、`1x^0` 都是这种。

### ③ 常数项的 1 不能省略

这是规则 3 的**唯一例外**，也是「省略 1」最容易做过头的地方：

```
系数 1 出现在 x^2 上  →  x^2      （省略数字）
系数 1 出现在常数项上 →  1        （不能省，省了就什么都没有）
系数 -1 出现在常数项上 →  -1      （不能只写 -）
```

所以「省略 ±1」这个动作**必须带一个 `i == 0` 的例外**。

## 五、正确写法

一个循环、四条判断，不需要 `i == n` 的首项特判：

```cpp
string solve(int n, const vector<int>& c) {
    string res;
    for (int i = n; i >= 0; --i) {
        int v = c[n - i];                 // 第 i 次的系数（输入是从 n 次到 0 次）
        if (v == 0) continue;             // ① 零系数整项跳过

        if (!res.empty() && v > 0) res += '+';   // ② 非首项的正号

        if (v == 1) {                     // ③ 系数 ±1 省略数字
            if (i == 0) res += '1';       //    但常数项必须写
        } else if (v == -1) {
            res += (i == 0 ? "-1" : "-");
        } else {
            res += to_string(v);          //    其它正常写（含负号）
        }

        if (i >= 1) {                     // ④ x^1 不带 ^1，x^0 不写 x
            res += 'x';
            if (i >= 2) { res += '^'; res += to_string(i); }
        }
    }
    return res.empty() ? "0" : res;
}
```

### 四个设计要点

**1. 不单独处理首项，用 `res.empty()` 判断**

```cpp
if (!res.empty() && v > 0) res += '+';
```

第一项时 `res` 还是空的 → 不加 `+`。**这比 `i == n` 更稳**，因为跳过零系数后，「第一个真正输出的项」不一定是 `i == n`。

> 你原代码用 `if (i == n)` 判首项 —— 如果 `aₙ` 后面的系数里有 0 被跳过，逻辑就乱了。

**2. 负号由系数自己带**

`to_string(-5)` 就是 `"-5"`，不用手动加 `-`。只有 `v == -1` 这一个特例需要手写 `-`（因为数字被省略了）。

**3. `.empty() ? "0"` 兜底**

题目保证 `aₙ ≠ 0`，所以不会全零。但加上这行不花钱，防的是其它变体题。

**4. 输入用 `int` 不用 `string`**

你原代码把系数存成 `string`，于是所有比较都变成字符串操作（`length()==1 && [0]=='1'`），既啰嗦又容易错。**系数本质是整数，先转 `int` 再说**：

```cpp
int v;  cin >> v;
```

要输出时 `to_string(v)` 一行搞定。

## 六、实测（8 组用例）

| 系数 | 你的 | 只改 `'1'` | 正确 |
|---|---|---|---|
| `1 -1 0 1` | `1x^3-x^2+0x^1+1x^0` | `-x^2+0x^1+x^0` | **`x^3-x^2+1`** |
| `1 1 0` | `1x^2+1x^1+0x^0` | `+x^1+0x^0` | **`x^2+x`** |
| `1 1` | `1x^1+1x^0` | `+x^0` | **`x+1`** |
| `-1 1 0` | `-1x^2+1x^1+0x^0` | `+x^1+0x^0` | **`-x^2+x`** |
| `100 0 0 0 0 1` | `100x^5+0x^4+…+1x^0` | 同左 | **`100x^5+1`** |
| `-1 0 0 0 -1` | `-1x^4+0x^3+0x^2+0x^1-x^0` | `+0x^3+…-x^0` | **`-x^4-1`** |
| `1 -1 1` | `1x^2-x^1+1x^0` | `-x^1+x^0` | **`x^2-x+1`** |
| `3 0 -1 0` | `3x^3+0x^2-x^1+0x^0` | 同左 | **`3x^3-x`** |

## 七、必须记住的点

1. **`char` 和 `int` 比较比的是编码**：`'1' == 1` 是 `false`，`'1' == 49`。
2. **`continue` 会跳过循环末尾的收尾语句**（这里是 `result += temp`）。
3. **系数为 0 的项连符号都不能留**。
4. **`x^1` 写 `x`，`x^0` 只写系数**。
5. **常数项的 ±1 不能省略** —— 这是「省略 1」的唯一例外。
6. **首项不靠 `i == n` 判，靠「结果串还是空的」判** —— 因为零系数会被跳过，第一个输出项未必是最高次。

## 八、易错点

| 坑 | 后果 | 正确做法 |
|---|---|---|
| `a[0] == 1` | 分支恒假，「省略 1」全失效 | `== '1'` |
| `continue` 前有收尾语句 | 整项丢失 | 用 if/else，不写 continue |
| 零系数没跳过 | 输出 `0x^4` | `if (v == 0) continue` |
| `x^1` 写全 | `x^1` 应为 `x` | `if (i >= 2)` 才写 `^i` |
| 常数项省了 1 | 输出空串或 `+` | `if (i == 0) res += '1'` |
| 首项用 `i == n` 判 | 零系数被跳过后多出 `+` | 用 `res.empty()` |
| 系数存成 string | 比较繁琐易错 | 存 `int`，输出时 `to_string` |

## 九、复杂度

`O(n)` 时间、`O(n)` 字符串空间（结果长度）。

## 十、延伸

**Q：如果有多个变量（多元多项式）怎么办？**

那就不是一道题了 —— 需要表达式树/项结构体，按字典序排项。这题的「标准形式」只在一元情况下唯一。

**Q：如果要求合并同类项？**

输入就得是「(系数, 次数) 列表」，用 `map<int,long long>` 按次数累加，再逆序输出，正好复用本题的格式化逻辑。

**Q：同类「按规则格式化输出」的题**

- NOIP 2009 多项式输出（本题）
- LC 273 整数转英文单词（三位一组 + 单位词）
- LC 12 整数转罗马数字（从大到小贪心拼）
- 牛客「数字转中文读法」

共同点：**先把「所有分类」列全（一张表），再写 if 链**。漏一条就 WA 一类用例。

## 一句话总结

> **`'1'` 不是 `1`。** 而「省略 1」这件事，只有「常数项的 1」不能省。
