# 贪心算法入门

## 核心思想

**每一步都选当前看起来最优的选择**，指望局部最优能推出全局最优。

> 贪心像"每次先拿最大的"，简单直接，但只在特定问题上成立。

## 经典例子：找零钱

**面额 25 / 10 / 5 / 1，找 63 美分**，贪心"先拿最大的"：

- 25×2=50（剩 13）→ 10（剩 3）→ 1×3 → 共 **6 枚** ✅ 最优

**换面额 25 / 20 / 10 / 5 / 1，找 40 美分**：

- 贪心：25（剩 15）→ 10（剩 5）→ 5 → **3 枚**
- 最优：**20 + 20 = 2 枚** 💀 **贪心翻车！**

**结论**：贪心策略只在满足**贪心选择性质**（当前最优不影响后续选择）的问题上成立，不成立时要用**动态规划**兜底。

## 与动态规划的分界

| | 贪心 | 动态规划 |
|---|---|---|
| 决策方式 | 每步选局部最优，**不回看** | 保存所有子问题状态，**全局比较** |
| 适用 | 贪心选择性质成立的问题 | 最优子结构 + 重叠子问题 |
| 典型 | 活动选择、Huffman 编码、Prim/Kruskal | 找零钱（非贪心面额）、背包、LCS |

**找零钱 DP 状态定义（易错）**：`dp[i]` = 找 i 元需要的**最少硬币数**（不是"方法数"！方法数是另一道题）：

```
dp[0] = 0
dp[i] = min(dp[i-1], dp[i-3], dp[i-4]) + 1   // 面额 1/3/4
```

例：面额 1/3/4 找 6 元 → dp[6] = min(dp[5], dp[3], dp[2]) + 1 = min(2,1,2)+1 = **2 枚** ✅（3+3）

## 识别套路

- 面试里"每一步做局部最优选择" + 要求证明/说明为什么成立 → 贪心
- 同样的问题但贪心**举出反例** → 立刻切 DP
