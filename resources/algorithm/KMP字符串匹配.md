# KMP 字符串匹配

## 问题背景

在主串 text 里找模式串 pattern 出现的位置。

- **暴力法**：从主串每个位置开始逐字符比，失配则主串指针回退一位重新比 → 最坏 **O(n×m)**

## KMP 核心思想：失配时主串指针绝不回退！

**例子**：
```
主串:    A B C A B C A B D
模式串:  A B C A B D
```
- 从主串第 0 位开始比：`ABCAB` 全对上，第 5 位 `C` vs `D` **失配**
- 暴力法：主串指针回到第 1 位，模式串归零从头再来
- **KMP 的想法**：前 5 位 `ABCAB` 已匹配，其中前缀 `AB` 和后缀 `AB` 相同（最长相等前后缀长度 = 2）→ 模式串直接滑 2 格，让 `AB` 对齐，接着从 `C` 继续比！

```
主串:    A B C A B C A B D
模式串:        A B C A B D   ← 滑动 2 格，从 C 继续比
```

## next 数组（前缀表）——KMP 的魂

预处理模式串，算出每个位置的最长相等前后缀长度：
```
模式串:  A B C A B D
next:    0 0 0 1 2 0
```

**失配时模式串滑动距离 = 已匹配长度 − next[失配前一位]**

## 相等前后缀直观理解（彩带比喻，Day 19 巩固）

把字符串想成一条彩带：
- **前缀** = 从左边剪一段（不能剪整条）
- **后缀** = 从右边剪一段（不能剪整条）
- **相等前后缀** = 左右剪出来的两段**一模一样**

例：`ABAB`
| 长度 | 前缀 | 后缀 | 相等 |
|---|---|---|---|
| 1 | A | B | ❌ |
| 2 | AB | AB | ✅ |
| 3 | ABA | BAB | ❌ |

→ 最长相等前后缀 = `AB`（长度 2）。注意：**不能算整条串自己**（否则永远等于全长，没意义）。

**为什么值钱**：匹配中途失配时，已匹配部分的后缀已与主串对齐；若模式串前缀与它相等，就能直接平移接上，主串指针不回退。

## next 数组两种约定（面试常混！）

- **约定 A（next[0] = -1）**：`ABABC` → `[-1, 0, 0, 1, 2]`，失配时模式串指针**直接跳 next[j]**
- **约定 B（next[0] = 0）**：`ABCABD` → `[0, 0, 0, 1, 2, 0]`，失配时**滑动距离 = 已匹配长度 − next[失配前一位]**

> 两种本质相同，**背实现前先确认是哪种约定**！

**计算本质**：模式串"自己匹配自己"（递推）——字符相同则 +1，不同则回退到 next[next]，与匹配过程同理。

## 复杂度

- 预处理 O(m) + 扫描 O(n) = **O(n+m)**
- 空间 O(m)

## 一句话总结

> 暴力法把"已经比过、确认匹配"的信息浪费掉了；KMP 用 next 数组把这份信息**复用**起来，让模式串"聪明地滑动"，主串指针只进不退——这就是它比暴力快的关键。

## 面试高频追问

1. **为什么主串指针可以不回退？** → 已匹配部分的信息（最长相等前后缀）足以确定模式串能滑多远，不存在漏匹配
2. **next 数组怎么构建？** → 递推：利用前一位的 next 值，字符相同则 +1，否则回退到 next[next]，本质和匹配过程一样
3. **暴力 O(n×m) vs KMP O(n+m) 什么时候差最多？** → 模式串长且重复字符多，如 text 全是 'a'、pattern = "aaaaab" 时暴力退化最严重
