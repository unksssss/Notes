### FireSim_URP_PC — 训练任务配置系统五件套（ConductTraining，13:47 批量）

**设计主线**：JSON 数据驱动 —— 后端下发任务 → Manager 解析 → Panel 切换 → Content 展示 → 场景元素编辑器配置并导出。五组件职责单一、事件解耦。

#### 1. ConductTrainingManager — 任务数据解析与选中

```cs
public bool TrySelectTaskJson(string taskJson, string dataSourceName = null)
{
    TaskData taskData;
    try { taskData = JsonUtility.FromJson<TaskData>(taskJson); }
    catch (ArgumentException e) { Debug.LogError($"解析失败：{dataSourceName}\n{e.Message}"); return false; }
    return TrySelectTask(taskData);
}

public bool TrySelectTask(TaskData taskData)
{
    if (taskData == null) { Debug.LogError("不能选择空任务数据。"); return false; }
    if (_missionContent == null) { Debug.LogError("MissionContent 引用未配置。"); return false; }
    if (!_missionContent.TryDisplayTask(taskData)) return false;   // 显示成功才提交状态
    CurrentTaskData = taskData;
    CurrentTaskChanged?.Invoke(taskData);                          // 事件广播给 SceneContent 等
    return true;
}
```

要点：
- `JsonUtility.FromJson` 失败抛 `ArgumentException`（非 null），try/catch 时不能只判 null。
- **先显示、后提交**：`TryDisplayTask` 失败（如地图类型无对应 Toggle）就不更新 CurrentTaskData，避免"切了任务但界面没跟上"的状态错乱。
- `CurrentTaskChanged` 事件是 SceneContent/其他面板的订阅入口，OnEnable 订阅 / OnDisable 退订对称。

#### 2. ConductTrainingPanel — 任务选择 + 功能面板切换 + 背景动画

- 两个绑定结构：`TrainingTaskBinding`（displayName/taskId/Toggle/Mock JSON TextAsset）与 `PanelViewBinding`（Toggle/ContentPanel/Background/动画类型）。
- 背景动画 6 种可配置：`FadeIn / ScaleIn / SlideFromLeft / SlideFromRight / SlideFromTop / SlideFromBottom`，枚举驱动 switch 分支（📎 [[DOTween与协程选型]]）。
- 面板动画：从下方 `Vector2.down * 200f` 起点 `DOAnchorPos` + `Ease.OutBack` 弹入；背景 `DOFade` / `DOScale` / `DOAnchorPos` + `Ease.OutCubic`。
- **订阅/退订对称 + 委托缓存**：`_taskToggleListeners/_viewToggleListeners` 数组缓存 `UnityAction<bool>` 闭包，OnEnable BindListeners / OnDisable UnbindListeners + `KillOwnedTweens()`，防重复订阅泄漏（📎 [[协程原理与unitask]]）。
- Toggle 同步用 `SetIsOnWithoutNotify`（不触发回调，避免循环）。
- `ReturnToLogin()`：关面板 → 开登录面板 → `TryGetComponent<LoginPanel>()` 播进入动画，否则 fallback 还原 scale。

#### 5. SceneElementDragHandler — 拖拽 + 区域钳制

```cs
public void OnDrag(PointerEventData eventData)
{
    if (!RectTransformUtility.ScreenPointToLocalPointInRectangle(
            _dragArea, eventData.position, eventData.pressEventCamera, out Vector2 localPoint))
        return;
    Vector2 anchoredPoint = localPoint - _dragArea.rect.center;
    _rectTransform.anchoredPosition = ClampToDragArea(anchoredPoint);
}

private Vector2 ClampToDragArea(Vector2 anchoredPosition)
{
    Vector2 iconSize = Vector2.Scale(_rectTransform.rect.size, new Vector2(
        Mathf.Abs(_rectTransform.localScale.x), Mathf.Abs(_rectTransform.localScale.y))); // scale 补偿
    Vector2 maximum = (areaSize - iconSize) * 0.5f;
    return new Vector2(
        Mathf.Clamp(anchoredPosition.x, -maximum.x, maximum.x),
        Mathf.Clamp(anchoredPosition.y, -maximum.y, maximum.y));
}
```

- `IBeginDragHandler` 里 `SetAsLastSibling()` 保证拖拽中的图标盖在最上层（📎 [[UGUI事件接口与EventTrigger]]）。
- 锚点坐标 ↔ 归一化坐标互转：`normalized = anchored / areaSize + 0.5`，供快照跨任务恢复、跨分辨率复用。

### FireSim_URP_PC — NPC 任务系统落地（10:45 / 10:53）

路径：`Assets/Scripts/Author/Lv/Task/`

#### 1. PersonEscapeTask — 人员自主逃生任务（首个接入 TriggerHandler 的完整任务）

```cs
protected override void OnTaskStart()
{
    TriggerHandler trigger = npcs[0].transform.parent.GetComponentInChildren<TriggerHandler>();
    trigger.TriggerEnter.AddListener(col => RunStep());   // 玩家走进逃生区触发
}

private void RunStep()
{
    foreach (var npc in npcs)
    {
        NPC_NavFollower fol = npc.GetC<NPC_NavFollower>();
        fol.SetLeader(startPos);        // 指定跟随目标（逃生集合点）
        fol.isTargetEnd = true;
        fol.OnComplete = () => fol.gameObject.SetActive(false);  // 到达后隐藏 NPC
    }
}
```

`TriggerHandler` 通用触发器：`OnTriggerEnter/Exit` 过滤 `"Player"` 标签后派发 `UnityEvent<Collider>`，任务侧订阅即用。

#### 2. NPC_NavFollower — 跟随 + 狭窄通道堵塞自救

- 跟随：`refreshInterval = 0.2s` 节流刷新 `SetDestination`；`dist > followDistance` 才移动，否则 `isStopped + ResetPath`；动画只在 `isMoving` 状态翻转时 `SetBool`（防每帧冗余赋值）。
- **狭窄通道自救三级兜底**（SphereCast 探测 NPC Layer）：前方有人 → 停车等待 2s → 超时 `NoObstacleAvoidance` + 0.8 倍速挤过去 → 再卡 1s `agent.Warp` 随机侧移 0.2m → 畅通后恢复 `HighQualityObstacleAvoidance` + 原速（📎 [[Physics Raycast 与 NonAlloc]]）。
- 手动转向：`agent.updateRotation = false` + `Quaternion.Slerp` 朝 `agent.velocity` 平滑转头。

#### 3. NPC_Anim — 动画封装

- 所有参数 `Animator.StringToHash` 缓存 int（📎 [[Animator参数与性能优化]]）。
- 初始状态协程带 `Random.Range(0.5f, 1f)` 随机延迟，**防止一批 NPC 同时播放相同动作的"复制人"观感**；`_initAnimCoroutine` 先 Stop 再开，防叠加。

#### 4. WarningLineTask — 楼梯警戒线任务

- 5 个警戒锥 + 警戒线配对：点击锥体（ShowHigh 高亮）→ 警戒线 `SetActive` 切换 + `DOLocalMoveY(0, 0.5f).SetEase(Ease.OutSine)` 从 0.4 高度放下（📎 [[DOTween与协程选型]]）。
- **任务完成条件**：确认数 = 5 且索引全部落在 2~6（着火层 ± 上下两层），满足才 `TaskComplete()`，防乱设警戒区。
- `OnTaskFail/OnTaskReset` 统一 `ResetAllWarnLines()` 全量复位（隐藏警戒线 + `triggers[i].PushReset()`）。

#### 5. CharacterMoveController — 去程/返程状态机续

- 高响应参数：`agentAcceleration = 1000f`、`agentAngularSpeed = 720f`、`avoidancePriority = 50`、`agentRadius = 0.4 / height = 1.8`。
- 返程双模式 `ReturnModeConfig readonly struct`（isCarry 3m/s / isDown 2m/s）映射动画 + 速度；协程内清理必须 `StopAllMovement(stopCurrentCoroutine: false)` 防自杀。
- 到达判定 `remainingDistance <= stoppingDistance + arrivalTolerance`；`OnValidate` 全字段防反配置。
