# 进制转换

> 场景：把 `"1A"` / `"0x1A"` 这样的十六进制字符串转成十进制整数 `26`。

## 一、核心：一条式子搞定 N 进制

```cpp
v = v * base + digit(c);
```

十六进制就是 `base = 16`，二进制 `base = 2`，八进制 `base = 8`。**这条式子和十进制版的 `v = v * 10 + (c - '0')` 是同一个东西**，只是基数换了。

举例 `"1A"`：

| 步骤 | 读到 | digit | v 的变化 |
| --- | --- | --- | --- |
| 初始 | — | — | 0 |
| 1 | `'1'` | 1 | `0*16 + 1 = 1` |
| 2 | `'A'` | 10 | `1*16 + 10 = 26` |

**注意 `+` 和 `*` 别写反**（`v += v*16` 是常见手误，见 `验证IP地址` 里 `toNum` 那个 bug）。

## 二、`digit(c)`：一个字符值多少

```cpp
int hexVal(char c) {
    if (c >= '0' && c <= '9') return c - '0';
    int l = c | 0x20;                        // 'A'|0x20 = 'a'，折成小写只判一段
    if (l >= 'a' && l <= 'f') return l - 'a' + 10;
    return -1;                               // 非法字符
}
```

`0x20` 是 ASCII 里大小写唯一的差别位（见 `验证IP地址` 附录里 `isxdigit` 的写法）。数字 `'0'..'9'` 这一位本来就是 1，`| 0x20` 不变，所以要先判数字再折小写。

## 三、遇到 `0x` 里的 `x` 怎么办

**`x` 是前缀标记，不是数字。** 三种处理方式：

| 方式 | 写法 | 评价 |
| --- | --- | --- |
| **① 先剥前缀**（推荐） | `if (s.size() > 2 && s[0]=='0' && (s[1]=='x'\|\|s[1]=='X')) s = s.substr(2);` | 明确、能对剩下的部分逐字符校验 |
| ② 循环里跳过 `x` / `X` | `if (c=='x'\|\|c=='X') continue;` | ❌ 会把**字符串中间**的 x 也跳过，掩盖 `"1x2"` 这种非法输入 |
| ③ 交给 `stoi` / `strtol` | 它们自己处理 | 最省事，但失去了逐字符校验能力 |

**完整手写版**：

```cpp
long long hexToDec(string s) {
    if (s.size() > 2 && s[0] == '0' && (s[1] == 'x' || s[1] == 'X'))
        s = s.substr(2);                     // ★ 剥前缀
    long long v = 0;
    for (char c : s) {
        int d = hexVal(c);
        if (d < 0) return -1;                // 非法字符
        v = v * 16 + d;
    }
    return v;
}
```

`0` 单独一个字符时不会被误剥（`s.size() > 2` 挡住了），`"0x"` 这种只有前缀没数字的会得到 `v = 0` —— 需要严格的话再加一个「剥完不能为空」的判断。

## 四、标准库四种方式

```cpp
stoi(s, nullptr, 16);            // string -> int，第二个参数可拿到"停在哪"
stoll(s, nullptr, 16);           // -> long long
stoul(s, nullptr, 16);           // -> unsigned long
strtol(s.c_str(), &end, 16);     // C 风格，end 指出解析到哪
sscanf(s.c_str(), "%x", &v);     // 格式化读入
istringstream iss(s); iss >> hex >> v;   // 流式
```

**`stoi` 的行为要点**（实测）：

| 输入 | `stoi(…, 16)` | 说明 |
| --- | --- | --- |
| `"1A"` | `26` | 无前缀也行 |
| `"0x1A"` | `26` | **认 `0x` 前缀** |
| `"0X1A"` | `26` | 大写 X 也认 |
| `"ffff"` | `65535` | 大小写都行 |
| `"7FFFFFFF"` | `2147483647` | `INT_MAX`，恰好到头 |
| `"FFFFFFFF"` | **抛 `out_of_range`** | 超出 int 范围 |

**所以「十六进制经常超过 int」这件事要提前想好**：颜色值 `0xFFFFFFFF`、IPv6 的 32 位分组、文件哈希，都会超。要么用 `stoul` / `stoll`，要么自己用 `long long` 累乘。

```cpp
stoul("FFFFFFFF", nullptr, 16);   // 4294967295
stoll("FFFFFFFF", nullptr, 16);   // 4294967295
```

`stoi` 的两类异常：

- **`invalid_argument`** —— 一个字符都没解析出来（如 `"xyz"`）
- **`out_of_range`** —— 解析出来了但超范围（如 `"FFFFFFFF"`）

## 五、`strtol` 的宽容行为（想报错的话得用它）

```cpp
const char* s = "1AxZZ";
char* end = nullptr;
long v = strtol(s, &end, 16);     // v = 26，end 指向 "xZZ"
```

`strtol` **解析到第一个非法字符就停**，并把位置写回 `end`。判断「整串是否都被消费」：

```cpp
if (*end != '\0') { /* 有非法尾巴 */ }
```

`stoi` 也可以这样（第二个参数是 `size_t* pos`）：

```cpp
size_t pos = 0;
int v = stoi(s, &pos, 16);
if (pos != s.size()) { /* 没读完 */ }
```

## 六、反过来：十进制转十六进制（输出）

```cpp
cout << hex << 255;                          // ff
cout << showbase << hex << 255;              // 0xff
cout << uppercase << showbase << hex << 255; // 0XFF
printf("%x %X", 255, 255);                   // ff FF
```

⚠️ **`hex` / `showbase` / `uppercase` 都是「粘性」的格式化标志** —— 一旦设置，**后面所有输出都受影响**，必须显式关掉：

```cpp
cout << hex << v << dec;        // 用完立刻切回十进制
cout << noshowbase << nouppercase;
```

这是个经典的坑：局部打了个十六进制，结果后面所有 debug 输出都变成十六进制了。

手写版（不用 iostream 标志）：

```cpp
string decToHex(unsigned long long v) {
    if (v == 0) return "0";
    const char* d = "0123456789abcdef";
    string s;
    while (v) { s += d[v % 16]; v /= 16; }
    reverse(s.begin(), s.end());
    return s;
}
```

## 七、通用 N 进制（2 / 8 / 16 都能用）

```cpp
int toDec(const string& s, int base) {
    int v = 0;
    for (char c : s) {
        int d = hexVal(c);              // digit 值：0-9 -> 0-9，a-f -> 10-15
        if (d < 0 || d >= base) return -1;   // ★ 超出该进制的合法范围
        v = v * base + d;
    }
    return v;
}
```

`d >= base` 这个检查很重要：`toDec("2", 2)` 应该非法（二进制只有 0/1），没有这句就会算出 2。

## 八、实测

`g++ -std=c++17 -Wall -O2` 零警告，手写版与 `stoi` 逐一对比（含前缀、大小写）：

| 输入 | 手写 | `stoi(…,16)` |
| --- | --- | --- |
| `"0"` | 0 | 0 |
| `"1A"` | 26 | 26 |
| `"0x1A"` | 26 | 26 |
| `"0X1A"` | 26 | 26 |
| `"ff"` | 255 | 255 |
| `"FF"` | 255 | 255 |
| `"7F"` | 127 | 127 |
| `"100"` | 256 | 256 |
| `"FFFF"` | 65535 | 65535 |

全部一致。溢出与输出行为：

```
stoi("7FFFFFFF", 16) = 2147483647（INT_MAX）
stoi("FFFFFFFF", 16) 抛 out_of_range
stoul("FFFFFFFF", 16) = 4294967295
strtol("1AxZZ", &end, 16) = 26，停在 "xZZ"
cout << hex << 255  ->  ff        （且后续输出都变 hex，必须用 dec 关掉）
```
