# 元素方碑能量均衡

## 一、题意

一排 n 块方碑，第 i 块能量 `aᵢ ≥ 1`。可以无限次操作：

选一个 `i ∈ [2, n-1]`，然后在 `a_{i-1}` 和 `a_{i+1}` 之间搬 1 点能量：

- 正面：`a_{i-1} -= 1`，`a_{i+1} += 1`
- 反面：`a_{i+1} -= 1`，`a_{i-1} += 1`

全程每个 `aₖ ≥ 0`。问能否让所有 `aᵢ` 相等。

> 多个测试组，`t ≤ 10⁴`，`n ≤ 2×10⁵`，所有组的 n 之和 ≤ 2×10⁵，`aᵢ ≤ 10⁹`。

## 二、唯一题眼：`i-1` 和 `i+1` 奇偶性相同

```
下标:  1   2   3   4   5   6   7
       ●       ●       ●       ●      ← 奇数组（1-indexed 奇数位）
           ○       ○       ○          ← 偶数组
              ↑
           i=3 时操作的是 2 和 4
```

`i-1` 与 `i+1` 相差 **2**，所以**一定同奇偶**。操作只是在同一组内部搬运能量。

于是有两个**互相绝缘**的不变量：

```
S_odd  = a₁ + a₃ + a₅ + …    （永不变）
S_even = a₂ + a₄ + a₆ + …    （永不变）
```

**这两组之间永远借不到能量。** 这就是灯皇漏掉的那一刀。

### 最终全为 x 时

设最终所有元素都等于 `x`。那么：

```
S_odd  = cnt_odd  × x     →  x = S_odd  / cnt_odd
S_even = cnt_even × x     →  x = S_even / cnt_even
```

其中 `cnt_odd = ⌈n/2⌉`、`cnt_even = ⌊n/2⌋`。

**所以判据是三条**：

1. `S_odd` 能被 `cnt_odd` 整除
2. `cnt_even > 0` 时，`S_even` 能被 `cnt_even` 整除
3. 两个商相等

## 三、为什么条件满足就一定做得到

组内相邻的两个位置（差 2）可以互相搬 1，所以**每组内部是一条连通的链**。

链上 ±1 搬运有个好性质：**只要总和相同，任意两个非负序列互相可达**。构造如下：

```
① 把整组能量全搬到最左端
   从右往左，a_k > 0 就往左搬一格 —— 搬走不会让任何位置变负
   搬完：[S, 0, 0, …, 0]
② 从左往右分配成 x
   a_j--, a_{j+1}++ 重复 (x - 已放好的量) —— 目标 x ≥ 1，也不会变负
```

`x ≥ 1` 是因为 `aᵢ ≥ 1`，平均值必然 ≥ 1。所以**非负约束永远不构成障碍**（这是本题能出成"判断题"而非"求最少步数"的原因）。

### 可操作性核对（i 必须落在 [2, n-1]）

| 组 | 需要的 i | 合法性 |
|---|---|---|
| 奇数组相邻对 (k, k+2) | `i = k+1` | `k ≥ 1`、`k+2 ≤ n` ⟹ `2 ≤ i ≤ n-1` ✅ |
| 偶数组相邻对 (k, k+2)，k ≥ 2 | `i = k+1 ≥ 3` | 需 `n ≥ 4` |

所以 `n ≥ 4` 时两组都完整连通；`n ≤ 3` 时偶数组至多 1 个元素，本来就不需要操作。

## 四、逐 n 校对（公式自动覆盖所有边界）

| n | cnt_odd | cnt_even | 判据 | 等价含义 |
|---|---|---|---|---|
| 1 | 1 | 0 | `S_odd` 必然被 1 整除，无偶数约束 | 恒 YES ✅ |
| 2 | 1 | 1 | `a₁/1 == a₂/1` | `a₁ == a₂`（没有合法 i）✅ |
| 3 | 2 | 1 | `a₁+a₃` 偶 且 `/2 == a₂` | a₂ 动不了，必须等于 a₁a₃ 均值 ✅ |
| ≥4 | ⌈n/2⌉ | ⌊n/2⌋ | 两组各自均分且商相等 | 两组独立连通 ✅ |

**同一套公式通吃所有 n**，不需要对 n=1/2 写特判 —— 因为 `cnt_even = 0` 时跳过偶数约束即可。

## 五、灯皇代码的四个问题

```cpp
bool solve(vector<int> nums) {
    int sum=0;
    for(int i=0;i<nums.size();i++) sum += nums[i];
    return sum%nums.size()==0;      // ❌ 只判了「全局和能被 n 整除」
}
```

### ① 主错：全局和条件既不充分也不必要

**不充分**：全局和能被 n 整除，不代表两组能各自均分。

```
[4, 1, 1]      sum = 6，6 % 3 == 0  →  他 YES
               S_odd = a1+a3 = 5，5/2 不是整数  →  正确 NO

[1, 1, 1, 5]   sum = 8，8 % 4 == 0  →  他 YES
               S_odd = 1+1 = 2 → 均值 1
               S_even = 1+5 = 6 → 均值 3     →  正确 NO

[3, 1]         sum = 4，4 % 2 == 0  →  他 YES
               n=2 没有合法 i，a1≠a2          →  正确 NO
```

**也不必要**：反例不存在（全局和 = `cnt_odd·x + cnt_even·x = n·x`，一定被 n 整除），所以他的条件严格弱于正解 —— 只会漏判，不会误判 NO。

### ② `int sum` 溢出

`n ≤ 2×10⁵`、`aᵢ ≤ 10⁹` → 总和最大 `2×10¹⁴`，而 `int` 上限约 `2.1×10⁹`。实测 n=10⁵、全 1e9：

```
真实总和 = 100000000000000        （需要 long long）
int 保存 = 276447232              （已溢出，有符号溢出是 UB）
灯皇判定 = NO      正确 = YES
```

**而且有符号溢出是 UB**，编译器可以把整个判断优化成任何结果。

### ③ `cout << "YES"` 没有换行

多组测试的答案必须**各占一行**。实测三组：

```
灯皇: YESYESYES
正确: YES
      NO
      NO
```

**粘成一行的多组答案，除 t=1 的用例外全部 WA** —— 这正好解释了「5/9」：通过的 5 个大概率都是单组用例。

### ④ `sum % nums.size()` 的类型混算

`nums.size()` 是 `size_t`（无符号），`int sum % size_t` 会先把 `sum` 转成 `size_t`。一旦 `sum` 溢出成负数，转换后变成一个巨大的无符号数，结果完全失去意义。

### 附带

`bool solve(vector<int> nums)` 按值拷贝整个 vector（`O(n)` 复制），改成 `const vector<int>&`。

## 六、正解

```cpp
#include <cstdio>

int main() {
    int t;
    if (scanf("%d", &t) != 1) return 0;

    while (t--) {
        int n;
        scanf("%d", &n);

        long long sOdd = 0, sEven = 0;
        for (int i = 0; i < n; ++i) {
            long long x;
            scanf("%lld", &x);
            if (i % 2 == 0) sOdd  += x;      // 0-indexed 偶数 = 1-indexed 奇数位
            else            sEven += x;
        }

        long long cOdd  = (n + 1) / 2;
        long long cEven = n / 2;

        bool ok = (sOdd % cOdd == 0);
        long long target = sOdd / cOdd;

        if (ok && cEven > 0)
            ok = (sEven % cEven == 0) && (sEven / cEven == target);

        puts(ok ? "YES" : "NO");
    }
    return 0;
}
```

**两个下标体系别搞混**：

| 题目（1-indexed） | 代码（0-indexed） |
|---|---|
| 第 1、3、5 块 | 下标 0、2、4 → `i % 2 == 0` |

`i % 2 == 0` 在 0-indexed 里对应的正是题目的"奇数位"，第一次写很容易反。

## 七、实测

### BFS 暴力（真正模拟操作，全程检查非负）

枚举 `n = 1..5`（aᵢ ∈ 1..4，n=5 取 1..3）、`n = 6` 全枚举（aᵢ ∈ 1..3）、`n = 4..7` 随机抽样（aᵢ ∈ 1..6）：

| 验证范围 | 组数 | 灯皇条件判错 | 正解判错 |
|---|---|---|---|
| n=1 | 4 | 0 | 0 |
| n=2 | 16 | **4** | 0 |
| n=3 | 64 | **14** | 0 |
| n=4 | 256 | **44** | 0 |
| n=5 | 243 | **30** | 0 |
| n=6 全枚举 | 729 | — | 0 |
| n=4..7 随机 | 1200 | — | **0** |
| **合计** | **2512** | **92（16%）** | **0** |

正解输出（样例 `[1,1]`、`[4,1,1]`、`[1,1,1,5]`）：`YES / NO / NO` ✅

## 八、必须记住的点

1. **看操作的作用范围**：`i-1` 与 `i+1` 差 2 → 同奇偶 → **奇偶两组各自守恒**。
2. **守恒量决定可达的必要条件**，而且这题它也是充分的（链上 ±1 搬运连通）。
3. **"全局和能被 n 整除"只是必要条件的一半** —— 分组之后每组都要均分。
4. **多组测试必须每组一行**，`cout << "YES"` 不带 `\n` 是多组题的头号杀手。
5. **总和用 `long long`**：`n × aᵢ` 上限 `2×10¹⁴`。
6. **0-indexed 的 `i % 2 == 0` = 1-indexed 的奇数位**。

## 九、易错点

| 坑 | 后果 | 正确做法 |
|---|---|---|
| 只用全局和 | 漏掉分组约束，约 16% 用例错 | 分奇偶两组判 |
| `int sum` | 10¹⁴ 溢出，且是 UB | `long long` |
| `cout << "YES"` 无换行 | 多组答案粘连，全 WA | `<< '\n'` / `puts` |
| `sum % size()` | 无符号混算，溢出后更荒诞 | 先转 `long long` |
| `i % 2` 方向搞反 | 奇数组变偶数组 | 0-indexed 偶数 = 题目奇数位 |
| `cnt_even == 0` 未处理 | n=1 时除零 | `if (ce)` 包住 |
| 按值传 vector | `O(n)` 复制 | `const vector<int>&` |

## 十、复杂度

| 项 | 值 |
|---|---|
| 每组时间 | `O(n)`（一遍读入 + 一次判断） |
| 空间 | `O(1)`（不需要存数组，边读边累加） |
| 总计 | `O(Σn) ≤ 2×10⁵` |

正解**连 vector 都不用开** —— 读完 x 直接累加到两个变量里，这也是 `O(1)` 空间。

## 十一、延伸

### 同族题：找不变量

这类"能否通过某种局部操作达成目标"的判断题，套路固定：

1. **写下每次操作改变了什么**（哪些量变、哪些量不变）
2. **把所有不变量找全**（可能不止一个）
3. **判断"不变量相同"是否也是充分的**（这步最难，靠构造或 BFS 验证）

经典对照：

| 题 | 操作 | 不变量 |
|---|---|---|
| 本题 | 隔一个搬 1 | 奇数组和、偶数组和 |
| LC 1342 变成全 0 | 偶数减半 / 奇数减一 | 无（是求步数，贪心） |
| 数组奇偶重排 | 相邻交换 | 逆序对奇偶性 |
| 15 数码 | 滑块移动 | 逆序对奇偶性 + 空格行号 |
| 交换相邻元素排序 | 相邻交换 | 逆序对数（求最少步数） |

> **"不变量"是判定题的第一反应**。看到「能否变成」，先问「什么没变」。

### 如果题目改问「最少操作次数」

那就变成：每组内把 `aᵢ` 变成 `x` 的最少相邻搬运步数。链上答案是

```
Σ_{k} | (a₁ - x) + (a₂ - x) + … + (a_k - x) |
```

（前缀和的绝对值之和，即"带权中位数"同款）。可以作为下一道练习题。
