# 链表中环的入口结点

对应 **剑指 Offer 23 / LeetCode 142**。题面：给一个链表，若其中包含环，找出**环的入口结点**；无环返回 `null`。

> 判环本身（是否有环）是前置问题，见 [[链表反转]] 的「快慢指针判环」节；本篇专注**找入口**。

## 两步走

**第一步：快慢指针判环，找到相遇点**（Floyd 判圈算法）
`slow` 每步 1、`fast` 每步 2。有环则二者必在环内相遇。

**第二步：定位入口**
相遇后，把 `fast` **重置为 `head`**，两个指针都改为**每次 1 步**同速前进；**再次相遇的位置就是环的入口**。

```csharp
public ListNode DetectCycle(ListNode head)
{
    ListNode slow = head, fast = head;
    // 第一步：找相遇点
    while (fast != null && fast.next != null)
    {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) break;          // 相遇
    }
    if (fast == null || fast.next == null) return null;  // 无环

    // 第二步：fast 回到头，两指针同速再走
    fast = head;
    while (slow != fast)
    {
        slow = slow.next;
        fast = fast.next;                 // 注意：这次是 1 步！
    }
    return slow;                          // 相遇处即环入口
}
```

时间 **O(n)**、空间 **O(1)**。

## 为什么「再次相遇处就是入口」——数学推导

设：

- `a` = 头结点 → 环入口 的距离
- `b` = 环入口 → 相遇点 的距离
- `c` = 相遇点 沿环继续走回环入口 的距离
- 环长 `L = b + c`

相遇时：

| 指针 | 走过的路程 |
| --- | --- |
| `slow` | `a + b`（刚进环就被追上，不足一圈） |
| `fast` | `a + b + nL`（多绕了 `n` 整圈，`n ≥ 1`） |

由速度比 2:1 得：

```
fast = 2 × slow
a + b + nL = 2(a + b)
nL = a + b
a = nL - b
a = (n - 1)L + (L - b) = (n - 1)L + c
```

**结论：`a = (n-1)L + c`。**

也就是说：从**头结点**走到**环入口**的距离 `a`，等价于从**相遇点**沿环走到**环入口**的距离 `c`，再多绕 `(n-1)` 整圈。

所以让一个指针从头出发、另一个从相遇点出发，**同速前进，它们只会在环入口相遇**（绕整数圈不会改变落点）。

> 💡 记忆口诀：**「头 → 入口 = 相遇点 → 入口（+ 整数圈）」**，所以两指针分别从这两处同速出发，相遇即入口。

## 易错点（面试扣分项）

1. **快指针必须是 2 步** —— 相对速度才是 1 步/次，否则可能永远追不上（相对速度 0 就死循环）。
2. **循环条件必须写 `fast != null && fast.next != null`** —— 只判 `fast != null` 会在 `fast.next.next` 处空引用。
3. **第二步里 `fast` 要改成 1 步** —— 最常见的笔误：继续用 `fast.next.next`。
4. **不能直接返回相遇点** —— 相遇点在**环内**，不一定是入口（只有 `a = c` 即 `n=1` 时才恰好重合）。
5. **无环时先返回 `null`** —— 别让 `while (slow != fast)` 在无环情况下拿 null 跑。

## 延伸考点

| 追问 | 解法 |
| --- | --- |
| 判断是否有环 | 快慢指针相遇即 `true`（O(1) 空间，优于 HashSet 的 O(n)） |
| 求**环的长度** | 相遇后从该点继续走，再次回到该点所走过的步数即 `L` |
| 求环上任意参数 | 拿到入口 + 环长即可推出全部 |
| 如何**断开环** | 找到入口后，从入口沿环走一圈，把最后一结点的 `next` 置 `null` |

**对比记忆**：本题和 [[两个链表的第一个公共结点]] 是同一类巧劲 —— 前者用「路程相等」，后者用「速度比 1:2 + 路程等式」，都不需要额外的哈希表空间。
