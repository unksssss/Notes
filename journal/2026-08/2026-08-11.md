### FireSim_URP_VR — LJW 通用装备系统落地（7 文件新框架）

今天完成了一套**左右手通用装备系统**，把装备的"装配 / 切换 / 使用生命周期"统一收口，替代旧 Wt 的 `EquipmentMgr`（已整体注释废弃）。

**核心文件**：`Assets/Scripts/Author/LJW/Equipment/Runtime/`

```cs
// EquipmentManager — 状态机核心（单例）
[DisallowMultipleComponent]
[DefaultExecutionOrder(-50)]   // 比默认脚本更早 Awake，保证 Instance 先就绪
public sealed class EquipmentManager : MonoBehaviour
{
    sealed class HandEquipmentState
    {
        public EquipDefinition Definition;          // 当前装备配置
        public EquipmentBase Equipment;             // 当前装备实例
        public bool IsUsing;
        public EquipmentUseContext UseContext;
        public readonly Dictionary<Object, EquipmentUseContext> UseSources = new(); // 多来源
        public readonly List<Object> InvalidSources = new(); // 清理已销毁引用
    }
}
```

关键设计：
- **多来源使用计数**：`UseSources` 字典按 `SourceObject` 去重，第一个来源加入才调 `BeginUse`，最后一个移除才调 `EndUse`——一个来源结束不会打断其他仍有效的按键/触发区域
- **无效引用清理**：`RemoveInvalidSources` 每帧扫描 `pair.Key == null` 的已销毁对象并移除（Unity 对象销毁后 C# 引用非 null，必须显式判空）
- 四种 API：`Equip/Uneqip`（装配）、`BeginUse/EndUse`（持续）、`UseOnce`（单击一次）、`ToggleUse`（开关切换）
- 事件广播：`EquipmentChanged`（换装）、`EquipmentUseChanged`（使用状态）
- `SafeDestroy`：运行时 `Destroy`（帧末延迟），编辑器 `DestroyImmediate`（即时）

```cs
// EquipmentBase — 装备抽象基类
public abstract class EquipmentBase : MonoBehaviour
{
    public abstract void BeginUse(EquipmentUseContext context);
    public virtual void UpdateUse(EquipmentUseContext context, float deltaTime) { }
    public abstract void EndUse(EquipmentUseContext context);
    public virtual bool CanUse(EquipmentUseContext context) => isActiveAndEnabled;
    internal void ApplyMountPose() // 挂点姿势：localPosition/Rotation/Scale
    { ... }
}
```

- **输入桥接** `EquipmentInputBridge`：订阅 `XRInputModule.ButtonInfoReceived`，按 `EquipmentButtonUseMode` 分发——`PressAndHold`（Down/Up）、`SingleClick`、`Toggle`；目标解析 `ResolveTarget()` 依次查 FarRay→Near→Poke→UI 四种交互源的悬停对象
- **触发器** `EquipmentTriggerZone`：装备 Collider 进/出 Trigger 驱动使用，`WhileInside`（区域内持续）/ `OnceOnEnter`（进入一次）；`_requiredDefinition` 白名单按 `id` 匹配；`Reset()/OnValidate()` 强制 `isTrigger = true`
- **具体装备** `FireExtinguisherEquipment`：喷口 `Physics.Raycast` + `_fireLayer` 检测火焰（当前是日志验证版，待接入实际灭火逻辑）

### FireSim_URP_VR — FireSetPanel 数值显示改比率 + 单位

- 删除 `UnitMeter/UnitMeterPerSec/UnitPercent` 三常量 → 按字段语义显示：m / m/s 字段显示实际值带单位（`"8.0 m"`），其余显示 `当前值/Range上限` 百分比（`"60 %"`）
- **`GetDisplayMax(fieldName, fallback)`**：反射读 `FlammableObject` 字段的 `[Range]` 上限作为 100% 基准，`static readonly Dictionary` 缓存字段信息——**只反射一次**，无 Range 的字段回退面板 `xxxMax`

```cs
private float GetDisplayMax(string fieldName, float fallback)
{
    if (displayMaxCache.TryGetValue(fieldName, out float max)) return max;
    // 反射读 RangeAttribute.max，缓存后返回
}
```

### FireSim_URP_VR — 左手腕 UI Move 坐标空间统一（DOLocalMove 飞远 Bug）

- 🐛 **现象**：TutorialPanel 把 `DOMove` 改成 `DOLocalMove` 后 UI 飞到远处
- **根因**：`LeftHandWristUIMgr` 调用 `Move()` 传的是世界坐标 `.position`，而 `DOLocalMove` 需要**本地坐标**；且 TutorialPanel/WristStepPanel 的 else 瞬移分支还用 `.position`（世界），动画/瞬移两分支坐标系不一致
- **修复**（方案 B：统一本地坐标）：`LeftHandWristUIMgr` 全部 9 处改传 `.localPosition`；面板 Move 的 else 分支改 `transform.localPosition = Pos`
- **前提**：`transformShow/Left/Right` 锚点与各 wristUI 面板必须是**同一父级**（都是 LeftHandWristUIMgr 子物体），localPosition 才有公共参照系
