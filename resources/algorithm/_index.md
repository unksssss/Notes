| --- | --- |
| [[DFS与BFS遍历算法]] | DFS/BFS 对比；二叉树四种遍历（前/中/后 + 层序）；BFS 无权图最短路、DFS 环检测 |
| [[二叉搜索树BST]] | 中序 = 升序；插入查空位、删除三情况（双子用中序后继）；**顺序插入退化成链 → 引出平衡树** |
| [[平衡二叉树]] | **家族概念不是具体树**：给 BST 附加「高度约束」防退化；`bf = 左高 − 右高`（**不是节点数差**）；强度谱系 AVL 严格 `\|bf\|≤1`（1.44log₂n）→ 红黑树弱平衡（2log₂(n+1)）→ Treap 随机 → Splay 均摊；维持手段统一是**旋转**（改结构不改中序）；与完全二叉树/BST 构成三个正交维度 |
| [[判断平衡二叉树]] | 平衡 = **每个节点**左右子树高度差 `abs(hl-hr) <= 1`（差 1 也合法）；❌ 两坑方向相反：只判根不递归子树（漏判）、用 `==` 代替 `abs(…)`（误判）；最优解后序 + `-1` 哨兵 + 双短路 → `O(n)`，自顶向下版最坏 `O(n²)`（剑指 55-2 / LC 110） |
| [[二叉搜索树的最近公共祖先]] | **LCA = p 与 q 第一次被「分到两边」的节点**：都小于 cur 走左、都大于 cur 走右、否则 cur 即答案（含 p/q 自身是 cur）；一次遍历 **O(h)/O(1)**，**不需要存路径**；对照「路径法」存两条根路径取最后一个公共节点，O(h) 空间但能泛化到普通二叉树 LC236（剑指 68-I / LC 235） |
| [[二叉树的最近公共祖先]] | 普通二叉树（无有序性）→ 只能**后序自底向上**：`dfs` 返回「该子树里找到的 p/q 或已确定的 LCA」，某节点**左右返回值都非空**时它就是 LCA；`O(n)/O(h)`，降不到 `O(h)`；命中即返回自身是因为「节点可以是自己的祖先」；与 BST 版（自顶向下 O(h)/O(1)）互为两种范式（剑指 68-II / LC 236） |
| [[二叉平衡树AVL]] | **\|bf\| ≤ 1 严格平衡**；最小失衡子树；四型旋转 LL/RR/LR/RL；插入至多 1 次旋、删除最坏 O(log n) 次；树高 ≤ 1.44log₂n |
| [[红黑树]] | 五性质 + 黑高推导；插入三 case（看叔节点）；2-3-4 树同构；C++ `map/set` 底层 |
| [[二叉搜索树转双向链表]] | **中序 = 升序 → 转链不用旋转**；`node->left=prev` 接前驱、`prev->right=node` 接后继；核心坑 `prev` 必须 `TreeNode*&` 引用传参 + 改 left 必须在递归左子树之后（剑指 36） |
| [[对称的二叉树]] | 对称 = `root->left` 与 `root->right` **互为镜像**，**交叉比较**（`a->left` 比 `b->right`）；终止条件顺序不能换：都空 true / 一空一非空 false / 值不等 false；❌ **中序回文 ≠ 对称**（有反例）（剑指 28） |
| [[合并二叉树]] | **同侧配对**（`a->left` 配 `b->left`）—— 与《对称的二叉树》的**交叉**正好相反；重叠节点值相加 + 不重叠节点**整棵子树直接接管**（base case 必须 `return` 对方而非 `nullptr`）；O(min(m,n)) / O(min(h₁,h₂))（LC 617） |
| [[二叉树的镜像]] | **对每个节点做一次 `swap(left, right)`** —— 改的是**指针/结构**不是值；**单参**遍历 + 每节点独立操作，不需要成对处理（与《对称的二叉树》的双参成对骨架相反）；❌ 交换 `val` 是根本性错误（剑指 27 / LC 226） |
| [[验证二叉搜索树]] | **BST 约束是「整棵子树」级不是「父子」级**（反例 10/5,15/6,20 每条父子边都合法却非 BST）；正解：带**上下界区间**递归（往左收紧上界、往右收紧下界）或**中序严格升序**；边界须用 `LLONG_MIN/LLONG_MAX`（Windows 下 `long` 是 32 位）（剑指 98 / LC 98） |
| [[判断完全二叉树]] | 层序 BFS：**一旦出现空节点，后面不能再有非空**；★ 关键是把 `nullptr` 也入队当「断层标记」（与常规 BFS 判空再入队相反），否则 `seenEmpty` 永不触发 → **恒返回 true**；另一解用层序编号，判据 `maxIdx == n`；O(n) / O(n)（LC 958） |

> **树系学习路线（固定顺序，别跳）**：**BST → AVL → 红黑树**
> BST 讲清"有序 + 会退化"；AVL 讲清"用旋转维持平衡"；红黑树讲清"放宽标准 + 颜色记账"以少旋转。
> 贯穿三者的认知：**旋转看结构（一字/之字），不看记账字段**（AVL 用 `int height`，RBT 用 `bool color`）。
>
> **树系递归通用铁律**：想把修改**带出递归**，参数就得传引用（`TreeNode*& prev`）。
> 区分口诀：改**指针指向的内容**（`node->left = x`）值传递就生效；改**指针本身**（`prev = node`）**必须**用引用，否则副本随栈帧销毁、结果静默出错。
> 另一条**时机铁律**：改 `left` 必须在**递归左子树之后**（后序位置），提前改会顺着新指针走丢整棵左子树。
>
> **「单参 vs 双参」判据**：只对**一个**节点做局部变换（镜像 `swap(left,right)`）→ **单参**递归；需要**两个**节点互为参照 → **双参**递归。
> 双参再分两档：**同侧**（[[合并二叉树]]：`a->left` 配 `b->left`）与**交叉**（[[对称的二叉树]]：`a->left` 配 `b->right`）。
> 三题正好构成完整对照 —— [[二叉树的镜像]]（单参）/ [[合并二叉树]]（双参·同侧）/ [[对称的二叉树]]（双参·交叉）。
>
> **「静默失效」铁律**：下面这类 bug **不崩、不报错、语法完全合法，但结果恒错** —— 排查时优先怀疑。已积累三个案例：
> ① **迭代中序的循环条件写成 `cur && !st.empty()`** → 初始栈必空，条件一上来就 false，**循环体一次不进**（[[验证二叉搜索树]]）
> ② **完全二叉树判定「判空再入队」** → 队列永无空节点，`seenEmpty` 永不触发，**恒返回 true**（[[判断完全二叉树]]）
> ③ **镜像交换 `a->val` 而非指针** → 树形一点没变，只是换了标签（[[二叉树的镜像]]）
> 共同特征：**该触发的标志从未被触发** / **该改变的结构从未改变**。写完先问一句「这个标志/判据在什么情况下才会变？」

## 建议刷题顺序

1. **先过链表**（反转 → 相交 → 环），套路最集中，容易建立手感；
2. **再啃树系**（遍历 → BST → AVL → 红黑树），面试高频且互相串联；
3. **二分 + 排序**（含逆序对）作为独立专题，边界条件最容易翻车；
4. **DP / 贪心 / 递归迭代转换**属于思想层，穿插复习；
5. **KMP / A\*** 是专项加分项，考前过一遍思路即可。
