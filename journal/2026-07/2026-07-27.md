### 配电房项目 — HookRope 地下绳索方案重构（Pin 约束 → ObiParticleAttachment + RopeFade 淡出）

**目标文件**: `Assets/Scripts/HookRope.cs`

**改动概要**：
- 从"全长双端 Pin 约束"方案改为"地下绳索"方案
- 绳索 transform 放在 `Y=0.05`（玩家脚下地面），仅水平方向延伸
- 锚点端不再 Pin，绳索从地下自然被拖出，多余部分通过 RopeFade 材质在锚点处淡出消失

**具体改动**：

**① 材质系统替换**
```diff
- ropeObj.GetComponent<MeshRenderer>().material = material;
+ ropeObj.GetComponent<MeshRenderer>().material = new Material(Shader.Find("Custom/RopeFade"));
+ _fadeMat = ropeObj.GetComponent<MeshRenderer>().material;
+ _fadeMat.SetColor("_Color", material != null ? material.color : Color.white);
+ if (material != null && material.mainTexture != null)
+     _fadeMat.mainTexture = material.mainTexture;
```
原因：原来直接复用外部 material，现在需要 RopeFade 着色器实例以实现每帧更新的淡出控制。

**② 绳索路径改为纯水平**
```diff
- Vector3 dir = new Vector3(toAnchor.x, Mathf.Abs(toAnchor.y) + 1f, toAnchor.z).normalized;
+ toAnchor.y = 0; // 水平方向
+ Vector3 dir = toAnchor.normalized;
```
原因：之前沿锚点方向向上抬升（`Mathf.Abs(toAnchor.y) + 1f`），绳索在空中从高处下落堆积，视觉不自然。改为纯地下水平延伸，绳索穿过锚点后直接淡出。

**③ Pin 约束 → ObiParticleAttachment 改造**
```diff
- var ec = ropeEnd.GetComponent<ObiColliderBase>();
- var sc = ropeStart.GetComponent<ObiColliderBase>();
- // ... PinConstraints 手动管理 ...
- batch.AddConstraint(_rope.solverIndices[0], ec, ...);
- batch.AddConstraint(_rope.solverIndices[_rope.activeParticleCount - 1], sc, ...);
+ var attStart = _rope.gameObject.AddComponent<ObiParticleAttachment>();
+ attStart.target = ropeEnd;
+ attStart.particleGroup = _blueprint.groups[0];
+ attStart.attachmentType = ObiParticleAttachment.AttachmentType.Static;
+ attStart.constrainOrientation = false;
```
根因：Pin 约束需要 `ObiColliderBase` 组件，且双端 Pin 导致绳索在锚点端也被固定，无法实现"地下拖出"效果。改为 ObiParticleAttachment（Static 模式），只 Pin 玩家端粒子组 group[0]，锚点端自由。

**④ 新增淡出控制 + 路径追踪**
```csharp
// 设置淡出面：以 AnchorCube 为面心，法向指向玩家
_fadeMat.SetVector("_FadeCenter", ropeStart.position);
_fadeMat.SetVector("_FadeNormal", (ropeEnd.position - ropeStart.position).normalized);
_fadeMat.SetFloat("_FadeWidth", fadeWidth);
```
每帧在 `Update()` 中更新 `_FadeCenter` 和 `_FadeNormal`，确保淡出面跟随玩家和锚点位置变化。

### 配电房项目 — RopeFade.shader 自定义 URP 淡出着色器

**目标文件**: `Assets/Shaders/RopeFade.shader`

关键算法 — **点到面距离淡出**：
```hlsl
// >0 在玩家侧（可见），<0 在多余侧（隐形）
float distToPlane = dot(IN.positionWS - _FadeCenter, _FadeNormal);
float fade = saturate(1.0 + distToPlane / max(_FadeWidth, 0.001));
col.a *= fade;
```
- `_FadeCenter`: 锚点世界坐标（AnchorCube 位置）
- `_FadeNormal`: 锚点→玩家方向，决定哪侧可见
- `_FadeWidth`: 过渡带宽度，控制淡出柔和度
- 着色器属性：透明队列、Blend SrcAlpha OneMinusSrcAlpha、ZWrite Off、Cull Off

### 配电房项目 — RotationBackPack 轮播式背包选择界面

**目标文件**: `Assets/Scripts/Author/Wt/UI/BackPackPlus/RotationBackPack.cs`

**功能**：
- 基于 `RotationDiagram2D` 的轮播算法，左中右三格可见
- 数据源：`List<EquipDefinition>` → 默认从 `GameRoot.Instance.equips` 读取
- 交互：左右按钮滑动、Item 拖拽滑动、点击非中间 Item 自动滚到中间
- 选中 UI 更新：名称 `tmp_EquipName` + 描述 `tmp_EquipDesc` + 装备按钮 `btn_Equip`
- 事件回调：`onEquipSelected` → 外部监听选中变更

**技术细节**：
```csharp
private float CalcX(float ratio, float length)
{
    if (ratio <= 0.25f) return ratio * length;
    if (ratio <= 0.75f) return (0.5f - ratio) * length;
    return (ratio - 1f) * length;
}
```
- 按缩放排序确立 UI 层级（`SetSiblingIndex`）
- 仅显示缩放 Top 3 的 Item，其余隐藏（`gameObject.SetActive(false)`）
- DOTween 动画：`DOAnchorPos` 水平移动 + `DOScale` 缩放，`OnComplete` 设层级
- 端点检测：点击非中间 Item 时，取最短路径切换（`diff > half → diff -= count`）

### 配电房项目 — VRTipsPanel VR 提示面板

**目标文件**: `Assets/Scripts/Author/Wt/UI/TipsPanel/VRTipsPanel.cs`

**实现**：
- 单例模式（`instance = this`）
- `Awake()` 时记录初始位置和缩放，`gameObject.SetActive(false)`
- `OnEnable()` 自动触发"前往任务选择"提示

**显示流程**（`ShowTips` 协程）：
1. 设置文本 → `SetActive(true)`
2. `DOLocalMove` 上移 0.3 单位（0.5s 动画）
3. `WaitForSeconds(3f)` 保持显示
4. `DOLocalMove` 回到原位 + `DOScale` 缩小到 0.1 倍（0.5s 动画）
5. `OnComplete` → `SetActive(false)`, 恢复 `localScale`
