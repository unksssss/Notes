# 螺旋矩阵

## 一、题目

给 `m × n` 矩阵，按**顺时针螺旋**顺序返回所有元素。

```
[[1,2,3],        →  [1,2,3,6,9,8,7,4,5]
 [4,5,6],
 [7,8,9]]

[[1, 2, 3, 4],   →  [1,2,3,4,8,12,11,10,9,5,6,7]
 [5, 6, 7, 8],
 [9,10,11,12]]
```

## 二、核心认知

两条完全不同的路，选对了就不用纠结转向：

| 思路 | 状态 | 空间 | 难易 |
|---|---|---|---|
| **A. 模拟「转向」** | 当前位置 `(r,c)` + 方向 `dir` + **访问标记** | `O(mn)` | 容易漏边界 |
| **B. 逐层「剥边」** | 四条边界 `top/bottom/left/right` | **`O(1)`** | 推荐 |

灯皇选了 A，但**访问标记用错了容器** —— 这是本题唯一的死因。

## 三、❌ 灯皇初版：死循环，7 组用例全无输出

```cpp
unordered_map<int, int> map;          // ① 状态表示不成立
...
while (i < m && j < n) {              // ⑤ 循环条件不适配螺旋
    if (map.find(i) != map.end()) {   // ② 这个分支永远进不去
        result.push_back(matrix[i][j]);
        map[i] = j;                   // ③ 只有这里才写 map
        switch (dir) { ... }
    } else {
        dir = (dir + 1) % 3;          // ④ %3 应为 %4
    }
}
```

### ① `unordered_map<int,int>` 存不下「访问状态」

`map[i] = j` 的语义是「第 `i` 行的已访问列是 `j`」——**一行只能记住一个列号**。而第 0 行你要访问 `n` 个格子，记到最后一个就覆盖前面的。

正确容器只有一个选择：`vector<vector<bool>> visited(m, vector<bool>(n, false))`。

### ②③ 只有 `if` 分支写 map，`if` 又永远不成立 → 死循环

关键的死锁链：

```
map 初始为空
→ map.find(i) == map.end() 恒真
→ 永远走 else
→ else 里只改 dir，不写 map
→ map 永远为空 …（回到第一行）
```

同时 `i`、`j` 一次都没动过，`while (i < m && j < n)` 恒为真 —— **原地打转，永不退出**。

实测 7 组用例（3×3 / 3×4 / 1×3 / 3×1 / 1×1 / 2×2 / 2×3）：**7 组全部死循环、输出为空**。

> 这类"状态机自己把自己锁死"的写法，表现是 TLE 而不是 WA。排查时先问：**这个循环里，有哪个变量真的在朝退出条件前进？**

### ④ `% 3` 应为 `% 4`

方向有四个（右 0 / 下 1 / 左 2 / 上 3），取模必须是 `% 4`。写 `% 3` 的话 `dir` 永远在 `0,1,2` 之间循环，**方向 3（向上）永远到不了**。

### ⑤ `while (i < m && j < n)` 不适合螺旋

螺旋路径会**向左、向上**走，`i`、`j` 都不是单调递增的。这条件既挡不住负数越界，也会在第一圈走完后误判。

正确的循环次数是**固定的 `m * n` 次**（每个格子正好访问一次）。

### 还有两个隐患

- `int n = matrix[0].size();` —— `matrix` 为空时 `matrix[0]` 越界。必须先 `if (matrix.empty() || matrix[0].empty()) return {};`
- 转向后没有检查新位置是否越界，`j++` 直接冲到 `n` 就会读越界。

## 四、修法一：保留「转向」思路

```cpp
vector<int> spiralOrder(vector<vector<int> >& matrix) {
    vector<int> res;
    if (matrix.empty() || matrix[0].empty()) return res;
    int m = (int)matrix.size(), n = (int)matrix[0].size();
    vector<vector<bool>> visited(m, vector<bool>(n, false));
    const int d[4][2] = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};   // 右下左上

    int r = 0, c = 0, dir = 0;
    for (int k = 0; k < m * n; ++k) {          // ★ 固定走 m*n 步
        res.push_back(matrix[r][c]);
        visited[r][c] = true;                  // ★ 先标记再找下一步
        int nr = r + d[dir][0], nc = c + d[dir][1];
        if (nr < 0 || nr >= m || nc < 0 || nc >= n || visited[nr][nc]) {
            dir = (dir + 1) % 4;               // ★ %4
            nr = r + d[dir][0];
            nc = c + d[dir][1];
        }
        r = nr; c = nc;
    }
    return res;
}
```

改动的分工：

| 改动 | 解决 |
|---|---|
| `visited` 二维数组 | 能记住整行/整列每个格子 |
| `for k < m * n` | 循环次数确定，不会失控 |
| 先标记、再**试走**下一步 | 「能走就走，走不动才转」—— 这才是螺旋的真实规则 |
| `% 4` + 越界检查 | 方向 3（上）可达，且不会走出矩阵 |

## 五、修法二：四边界收缩（推荐，`O(1)` 额外空间）

```cpp
vector<int> spiralOrder(vector<vector<int> >& matrix) {
    vector<int> res;
    if (matrix.empty() || matrix[0].empty()) return res;
    int top = 0, bottom = (int)matrix.size() - 1;
    int left = 0, right = (int)matrix[0].size() - 1;

    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; ++j) res.push_back(matrix[top][j]);   // 上边 →
        ++top;
        for (int i = top; i <= bottom; ++i) res.push_back(matrix[i][right]); // 右边 ↓
        --right;
        if (top <= bottom)                                                    // ★ 必须判
            for (int j = right; j >= left; --j) res.push_back(matrix[bottom][j]);
        --bottom;
        if (left <= right)                                                    // ★ 必须判
            for (int i = bottom; i >= top; --i) res.push_back(matrix[i][left]);
        ++left;
    }
    return res;
}
```

### 后两条边为什么必须加 `if`

剥完上边和右边后，**矩阵可能已经被剥空了**（只剩一行或一列）。此时再走「下边 / 左边」就是把同一行（或同一列）**倒着再输出一遍**。

```
[[1,2,3]]   不加 if：1 2 3  然后 2 1        ← 重复
[[1],[2],[3]] 不加 if：1 2 3 然后 2 1       ← 重复
```

前两条边不用判，因为 `top`/`right` 刚更新过，`for` 循环天然空转。

## 六、必须记住的点

1. **「访问标记」必须能表示"每个格子"** —— `map<int,int>`（行→列）只能记一行一个位置。二维布尔数组才够。
2. **循环要有确定的次数或确定的推进** —— 螺旋固定 `m*n` 步；写成 `while (i<m && j<n)` 且里面不一定推进，就会死循环。
3. **方向取模是 `% 4`**，四个方向不是三个。
4. **剥边法后两条边必须判空** —— 否则单行/单列重复输出。这是本题最经典的漏判。

## 七、易错点

1. **状态写错导致死循环**（本例）—— 表现是 TLE，不是 WA，容易误以为是"效率不够"。
2. **`% 3`** —— 少一个方向，向上的螺旋永远走不出来。
3. **转向后不检查越界** —— `j++` 到 `n` 就访问 `matrix[i][n]`。
4. **`matrix[0]` 未判空** —— 空输入直接崩。
5. **剥边少写 `if`** —— 单行/单列重复。
6. **边界变量用 `int` 从 0 递减** —— `--left` 后可能变 `-1`，`while (left <= right)` 虽能挡住，但一旦写成 `unsigned` 就会下溢。

## 八、复杂度

| 解法 | 时间 | 空间 |
|---|---|---|
| 转向 + visited | `O(mn)` | `O(mn)` |
| **边界收缩** | `O(mn)` | **`O(1)`**（除输出本身） |

## 九、面试延伸

- **LC 59 螺旋矩阵 II**：给你 `n`，按螺旋顺序**填** 1..n²，边界收缩正好反过来用
- **LC 885 螺旋矩阵 III**：从任意起点按螺旋走，要额外处理"撞到边界后继续转"的情形
- **顺时针旋转 90°**：先转置再逐行 `reverse`
- **LC 48 旋转图像**：原地四角轮换，`matrix[i][j] ↔ matrix[j][n-1-i]` 一组四个
- **蛇形/对角线遍历（LC 498）**：方向只有两条，用 `(i+j)` 的奇偶判断

## 十、补记：第三版（2026-11-19）改用边界收缩，只差一个字母

灯皇重写成边界收缩版，整体结构完全正确（四周边界 + 后两条边加 `if`），但初始化里写错一个字母：

```cpp
int m = matrix.size();
int n = matrix[0].size();
int right  = n - 1;
int bottom = n - 1;   // ❌ 应为 m - 1
```

`bottom` 是**最大行号**，必须用行数 `m`；写成列数 `n` 就错位了。

### 实测：方阵全对，非方阵全崩或漏行

| 用例 | m×n | `bottom` 实际值 | 结果 |
|---|---|---|---|
| 3×3 | 3×3 | 2 ✓ | 正确 |
| 2×2 | 2×2 | 1 ✓ | 正确 |
| 1×1 | 1×1 | 0 ✓ | 正确 |
| 3×4 | 3×4 | **3**（越界） | **Segmentation fault** |
| 2×3 | 2×3 | **2**（越界） | **Segmentation fault** |
| 1×3 | 1×3 | **2**（越界） | **Segmentation fault** |
| 4×3 | 4×3 | 2（应为 3） | 漏最后一行：`[1,2,3,6,9,8,7,4,5]` |
| 3×1 | 3×1 | 0（应为 2） | 只剩 `[1]` |

**只把 `n - 1` 改成 `m - 1`，9 组用例全部正确。**

### 为什么这类错极难自查

`m == n` 时 `bottom = n - 1` 恰好等于 `m - 1` —— **方阵永远是对的**。而大多数人本地只测 `[[1,2,3],[4,5,6],[7,8,9]]` 这一组，于是"跑通了"。

> **矩阵题的自测铁律：至少测一个 `m > n` 和一个 `m < n`。**
> `3×4`（m<n）暴露"越界崩"，`4×3`（m>n）暴露"少一行"——两个方向都不能省。

### 另外两点

- `if (matrix.empty())` 判了，但没判 `matrix[0].empty()`（`{{}}` 这种）。本例恰好安全（`right = -1`，循环不进），但建议一起判掉。
- 把 `bottom--` / `left++` 写在 `if` 里面**是对的**（`if` 条件与 `while` 条件同源，为假时循环也该退出了），不影响结果；标准写法放在外面只是更省心。
