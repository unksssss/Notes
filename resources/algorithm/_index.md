> **树系学习路线（固定顺序，别跳）**：**BST → AVL → 红黑树**

> 贯穿三者的认知：**旋转看结构（一字/之字），不看记账字段**（AVL 用 `int height`，RBT 用 `bool color`）。

## 建议刷题顺序

1. **先过链表**（反转 → 相交 → 环），套路最集中，容易建立手感；
2. **再啃树系**（遍历 → BST → AVL → 红黑树），面试高频且互相串联；
3. **二分 + 排序**（含逆序对）作为独立专题，边界条件最容易翻车；
4. **DP / 贪心 / 递归迭代转换**属于思想层，穿插复习；
5. **KMP / A\*** 是专项加分项，考前过一遍思路即可。
