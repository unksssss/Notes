# 最长公共前缀

> **题目**：给定字符串数组 `strs`，返回所有字符串的**最长公共前缀**；不存在则返回 `""`。
> 例：`["flower","flow","flight"]` → `"fl"`；`["dog","racecar","car"]` → `""`

## 一、核心认知

**「前缀」的严格含义：必须从下标 0 开始。** 这跟「最长公共子串」完全不同 —— `"flower"` 里的 `"low"` 再长也和前缀无关。

所以答案只有一个参数要定：**长度 `j`**。`j` 的含义是「所有字符串的第 `0..j-1` 位都相同」。找到最大的这个 `j`，答案就是 `strs[0].substr(0, j)`。

所有解法都在干同一件事：**求这个 `j`**。

## 二、解法一：纵向扫描（首选）

把字符串排成矩阵，**一列一列往下比**。以 `strs[0]` 的第 `j` 位为基准，看所有串的第 `j` 位是否都等于它。

```cpp
string longestCommonPrefix(const vector<string>& strs) {
    if (strs.empty()) return "";
    for (int j = 0; j < (int)strs[0].size(); ++j) {
        char c = strs[0][j];
        for (int i = 1; i < (int)strs.size(); ++i) {
            if (j >= (int)strs[i].size() || strs[i][j] != c)   // ★ 越界判断在前
                return strs[0].substr(0, j);
        }
    }
    return strs[0];                     // 第一个串整个都是公共前缀
}
```

**为什么是首选**：

1. **最坏也是最优**：最坏情况（全部相同）要扫完 `strs[0]` 的每一列，正好 `O(S)`，没有多余开销
2. **能提前退出**：一发现不一致立刻返回，不用管后面的串
3. **空间 `O(1)`**：不需要任何辅助结构

**最关键的那一行**：

```cpp
if (j >= (int)strs[i].size() || strs[i][j] != c)
//  └────── 短路保护 ──────┘   └─ 只有左边为 false 才执行 ─┘
```

`||` 是短路求值：左边为 `true`（这个串已经到底了）时，**右边根本不会执行**，所以 `strs[i][j]` 不会越界。**顺序反了就是 UB**。

这和 `栈与队列的相互实现` 里括号匹配那题的 `st.empty() || st.top() != leftOf(c)` 是**同一个模式**：**会解引用的检查必须放在 `||` 左边**。

## 三、解法二：横向扫描

拿第一个串当「候选前缀」，**和每个串依次求 LCP，前缀只会越缩越短**。

```cpp
string longestCommonPrefix(const vector<string>& strs) {
    if (strs.empty()) return "";
    string prefix = strs[0];
    for (int i = 1; i < (int)strs.size(); ++i) {
        int j = 0;
        while (j < (int)prefix.size() && j < (int)strs[i].size()
               && prefix[j] == strs[i][j]) ++j;
        prefix = prefix.substr(0, j);
        if (prefix.empty()) return "";      // 提前收工
    }
    return prefix;
}
```

- **优点**：`prefix` 单调变短，遇到极不匹配的串能迅速归零
- **缺点**：每个字符串都可能被 `substr` 复制一次，常数比纵向扫描大

两种都是 `O(S)`（`S` = 所有字符总数），面试说哪个都行，**纵向稍微更常被接受**。

## 四、解法三：排序后只比首尾（代码最短）

```cpp
string longestCommonPrefix(vector<string> strs) {   // ★ 值传递，要排序
    if (strs.empty()) return "";
    sort(strs.begin(), strs.end());                 // 字典序
    const string& a = strs.front();
    const string& b = strs.back();
    int j = 0;
    while (j < (int)a.size() && j < (int)b.size() && a[j] == b[j]) ++j;
    return a.substr(0, j);
}
```

**为什么只比首尾就够？** 靠字典序的一个性质：

> 若字典序最小的串 `a` 和最大的串 `b` 的前 `j` 位相同（记为 `P`），则**任何中间串 `s`（`a ≤ s ≤ b`）的前 `j` 位也必然是 `P`**。

反证：若 `s` 的前 `j` 位比 `P` 小，则 `s < a`，矛盾；比 `P` 大，则 `s > b`，也矛盾。

所以「首尾的 LCP」= 「全体的 LCP」。

**代价**：排序是 `O(n log n)` 次字符串比较，每次比较最坏 `O(m)` → 总 `O(n·m·log n)`，**比纵向扫描差**。好处是代码短、写起来不容易错。面试时可以主动说「这个很优雅但复杂度更高」。

## 五、四种做法对比

| 做法 | 时间 | 空间 | 特点 |
| --- | --- | --- | --- |
| **纵向扫描** | `O(S)` | `O(1)` | ★ 首选，能提前退出 |
| 横向扫描 | `O(S)` | `O(1)` | `prefix` 单调收缩，遇不匹配串收缩快 |
| 排序比首尾 | `O(n·m·log n)` | `O(n)`（排序） | 代码最短，思路最巧 |
| Trie | `O(S)` | `O(S)` | 同一前缀天然共享路径，适合「多次查询」场景 |
| 二分长度 + 哈希 | `O(S log m)` | `O(n)` | 面试加分项，但本题没必要 |

`S` = 所有字符串字符数之和，`m` = 最短串长度，`n` = 串的个数。

## 六、易错点

1. **`strs[i][j]` 越界** —— 必须写 `j >= strs[i].size() ||` 放在**前面**（短路保护），写成后面就是 UB。`std::string::operator[]` 越界不检查
2. **空数组** —— `strs[0]` 直接崩，要先 `if (strs.empty()) return "";`
3. **数组里有空串** —— 纵向扫描在 `j = 0` 时就命中 `0 >= strs[i].size()` → 返回 `substr(0,0)` = `""`，天然正确；但排序法要注意空串会排到最前面
4. **`substr(0, j)` 第二个参数是长度不是下标** —— 这里恰好等于 `j`，但写 `substr(0, j - 1)` 就少一个字符
5. **只有一个串** —— 纵向扫描循环走完返回 `strs[0]` ✅；如果写成「和 `strs[1]` 比」就要特殊处理
6. **用 `strs[0]` 当结果返回** —— 忘了 `substr` 会把整个第一个串返回（比如 `["abc"]` 恰好对，`["abc","abd"]` 就错成 `"abc"`）
7. **排序法用引用传参** —— 会改掉调用方的数组
8. **`size()` 返回 `size_t`（无符号）** —— 和 `int j` 比较会有符号/无符号警告，用 `(int)` 强转

## 七、复杂度

| 维度 | 值 |
| --- | --- |
| 时间（纵向） | `O(S)`，`S` = 所有字符总数；最坏 `O(n·m)` |
| 空间（纵向） | `O(1)` 额外（返回值不算） |

**注意**：`O(S)` 比 `O(n·m)` 更准确 —— 因为一旦某个串很短，扫描会立刻停止，实际比较次数远小于 `n·m`。

## 八、面试延伸

- **「最长公共子串」**（不要求从 0 开始）→ 完全不同的题：后缀自动机 / 广义 SAM / DP / 二分+哈希
- **「最长公共子序列 LCS」** → 又是另一题，DP 经典
- **「如果是多次查询同一批串的前缀」** → 建 **Trie**，公共前缀就是「从根往下唯一分叉前的那段」，`O(m)` 每次
- **「后缀数组里的 LCP」** → 相邻后缀的最长公共前缀数组（height 数组），是字符串算法的基石之一
- **「数组不是字符串而是整数呢」** → 完全一样，把 `char` 换成元素类型即可
- **变体：两个串的 LCP** → 直接一个 `while` 循环，比本题更简单（本题是 n 个串）

| --- | --- | --- | --- | --- |
| `["flower","flow","flight"]` | `fl` | ✅ | ✅ | ✅ |
| `["dog","racecar","car"]` | `""` | ✅ | ✅ | ✅ |
| `["a"]` | `a` | ✅ | ✅ | ✅ |
| `[]` | `""` | ✅ | ✅ | ✅ |
| `["","b"]` | `""` | ✅ | ✅ | ✅ |
| `["abc"]` | `abc` | ✅ | ✅ | ✅ |
| `["abc","abc"]` | `abc` | ✅ | ✅ | ✅ |
| `["ab","a"]`（第二个先到底） | `a` | ✅ | ✅ | ✅ |

| `["aaa","aa","aaaa"]`（最长在最后） | `aa` | ✅ | ✅ | ✅ |

**随机对拍 5000 组**（三版互相比对）全部一致。
