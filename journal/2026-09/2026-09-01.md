**① 拖拽 vs 点击判定：5px 阈值分离** —— 按下时只记录起点，移动超过阈值才进入拖拽，否则松开时按"点击选中/再次点击取消"处理：

```cs
private void UpdateLeftPointerInteraction()
{
    if (!_isDragging)
    {
        float mouseDistance = Vector3.Distance(_leftMouseDownPosition, Input.mousePosition);
        if (mouseDistance < _dragStartThreshold)   // _dragStartThreshold = 5f
            return;
        BeginDrag(_pressedObject);
        _isDragging = true;
    }
    DragObject();
}
```

**② 拖拽放置三连校验**：禁摆层 LayerMask 位运算过滤 + 表面法线 Dot 判定（只允许偏上表面）+ PlacementOffset 抬升防穿模：

```cs
Ray ray = _placementCamera.ScreenPointToRay(Input.mousePosition);
if (!Physics.Raycast(ray, out RaycastHit hit, _maximumRayDistance, ~0, QueryTriggerInteraction.Ignore))
    return;

int hitLayerMask = 1 << hit.collider.gameObject.layer;
bool isBlocked = (_blockedPlacementLayers.value & hitLayerMask) != 0;   // 禁摆层
if (isBlocked) return;

float upwardAmount = Vector3.Dot(hit.normal, Vector3.up);               // 表面朝上程度
if (upwardAmount < _minimumUpwardNormal) return;                        // 0.7 ≈ 45°

_draggedObject.transform.position = hit.point + hit.normal * _draggedObject.PlacementOffset;
```

- 拖拽期间 `BeginDrag` 禁用自身全部 Collider（防射线打到自己），`EndDrag` 恢复 + `SaveTransformData()` 持久化
