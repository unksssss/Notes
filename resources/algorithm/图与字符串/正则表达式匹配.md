# 正则表达式匹配

## 一、题目

给字符串 `str` 和模式 `pattern`，判断能否**整串匹配**。

- `.` 匹配**任意一个**字符
- `X*` 表示 `X` 重复 **0 次或多次**（`X` 是 `.` 或字母）

```
""      "a*"        → true     a* 匹配 0 次
"a"     "a*"        → true
"aa"    "a*"        → true
"ab"    ".*b"       → true     .* 吃 "a"，b 配 "b"
"ab"    ".*c"       → false
"aab"   "c*a*b"     → true     经典用例
"mississippi" "mis*is*p*."  → false
```

## 二、状态定义

```
dp[i][j] = str 的前 i 个字符（str[0..i-1]）能否被 pattern 的前 j 个字符（pattern[0..j-1]）匹配
```

**尺寸必须是 `(m+1) × (n+1)`** —— 因为要表达「前 0 个字符」（空串）和「前 j 个模式」。

`dp[0][0] = true`（空串配空模式）。

## 三、两条转移

### 情况 A：`pattern[j-1]` 不是 `*`

它必须和 `str[i-1]` 对上，对上了就退回左上角：

```cpp
if (pattern[j-1] == '.' || pattern[j-1] == str[i-1])
    dp[i][j] = dp[i-1][j-1];     // 这一个字符算配上了，看前面的
// 否则保持 false
```

### 情况 B：`pattern[j-1]` 是 `*`

`*` 修饰的是**它前面的那个字符** `pattern[j-2]`。两种用法，**取或**：

| 用法 | 含义 | 转移 |
|---|---|---|
| **匹配 0 次** | `X*` 整个当不存在 | `dp[i][j-2]` |
| **匹配 ≥1 次** | 吃掉 `str[i-1]` | `dp[i-1][j]`（前提：`p[j-2]` 能配 `s[i-1]`） |

```cpp
if (pattern[j-1] == '*') {
    dp[i][j] = dp[i][j-2];                              // ① 0 次
    if (pattern[j-2] == '.' || pattern[j-2] == str[i-1])
        dp[i][j] = dp[i][j] || dp[i-1][j];              // ② ≥1 次
}
```

**`dp[i-1][j]` 为什么能表示"多次"**：它表示「`str` 前 `i-1` 个能被 `pattern` 前 `j` 个匹配」。既然前 `i-1` 个都配上了，再多配一个 `str[i-1]` 也是同一个 `X*` 干的 —— 递归地就表示"用了任意多次"。

### 边界：`dp[0][j]`（空串能配哪些模式？）

只有 `X*X*X*...` 这种整体能匹配空串的形式：

```cpp
for (int j = 1; j <= n; ++j)
    if (pattern[j-1] == '*' && j >= 2)
        dp[0][j] = dp[0][j-2];
```

`"a*b*"` → `dp[0][2]=true`（a* 0 次），`dp[0][4]=true`（b* 0 次）。
`"ab*"` → `dp[0][2]=false`（a 不是 `X*`，配不了空串）。

## 四、灯皇初版的四处错

穷举 204 组（12 个 str × 17 个 pattern），**原版错 47 组（23%）**。

### ① 数组少一列（最危险，UB）

```cpp
vector<vector<bool>> dp(m + 1, vector<bool>(n, false));   // ❌ n 应该是 n + 1
```

`j` 的循环是 `1..n`，访问 `dp[i][n]` —— 而每行只有 `n` 个元素（下标 `0..n-1`），**每一行的最后一格都在越界读写**。

`std::vector<bool>` 是位压缩的，`operator[]` 不做越界检查，所以**不会崩**，只会读到不确定的位。表现就是「时对时错」：

```
同一份代码两次运行，"b" vs "a" 一次返回 false（对）、一次返回 true（错）
```

这类 UB 比崩溃更难查 —— 它有时能通过全部用例。

### ② `j > 2` 应为 `j >= 2`

```cpp
else if (j > 2 && pattern[j-1] == '*')     // ❌ 漏掉 j == 2
else if (j >= 2 && pattern[j-1] == '*')    // ✅
```

`j == 2` 对应 `pattern` 刚好是 `X*` 两字符（如 `"a*"`），是**完全合法且最常见**的形式。`j > 2` 让它整格跳过，`dp[i][2]` 永远是 `false`：

```
"a"  vs "a*"   → 错答 false
"aa" vs "a*"   → 错答 false
"ab" vs "a*b"  → 错答 false
"aaa" vs "a*a" → 错答 false
```

### ③ 判据漏了 `pattern[j-2] == '.'`

```cpp
if (pattern[j-2] == str[i-1])                         // ❌ '.' 永远配不上
if (pattern[j-2] == '.' || pattern[j-2] == str[i-1])  // ✅
```

`.` 在这里也要当通配符，否则 `X*` 里的 `X` 是 `.` 时整条链断掉：

```
"ab"  vs ".*b"   → 错答 false（正确答案 true：.* 吃 "a"）
"aab" vs ".*b"   → 错答 false
```

### ④ 能匹配时漏了 `dp[i][j-2]`（0 次）

```cpp
if (能匹配) dp[i][j] = dp[i-1][j] || dp[i-1][j-2];   // ❌ 少了 dp[i][j-2]
```

这个 bug 最隐蔽，因为它**只在"`X*` 应该匹配 0 次"时才暴露**：

```
"a"  vs "aa*"   → 错答 false（正确 true：第一个 a 配 a，a* 配 0 次）
"ab" vs "abb*"  → 错答 false（正确 true：ab 配 ab，b* 配 0 次）
```

而 `dp[i-1][j-2]` 这一项**是冗余的** —— 它能被 `dp[i-1][j]` 蕴含（`X*` 匹配 0 次时两者等价）。所以正确写法是把 `dp[i-1][j-2]` 换成 `dp[i][j-2]`，不是"加一项"。

### 四个 bug 的独立影响量

| 修复到哪一步 | 204 组里的错误数 | 该 bug 贡献 |
|---|---|---|
| 原版 | 47 | — |
| 只修列数 | 42 | 越界 **5** |
| 再修 `j>=2` | 26 | `j>2` **16** |
| 再修 `.` 判据 | 2 | 漏 `.` **24** |
| 再修 `dp[i][j-2]` | **0** | 漏「0 次」**2** |

> 四个 bug **全部独立成立**，不是重复计数。这也解释了为什么"改一个地方就觉得该过了" —— 每修一个都能多过一批用例，但都不够。

## 五、多余的兜底反而掩盖了问题

```cpp
if (pattern == ".*") return true;
```

`.*` 确实匹配一切，所以这句**结果正确**。但它让 `"a"`、`"ab"`、`""` 这些用例直接短路返回，**把 DP 的 bug 全遮住了** —— 只要测的用例里恰好有 `.*`，就会以为算法对。

**兜底特判是 bug 的遮羞布**。写 DP 时不要加这种"我觉得这里可能有问题所以先特判掉"的代码，它会让你失去最有效的测试信号。

## 六、正解

```cpp
class Solution {
public:
    bool match(string str, string pattern) {
        int m = (int)str.size(), n = (int)pattern.size();
        vector<vector<bool>> dp(m + 1, vector<bool>(n + 1, false));  // ★ n+1
        dp[0][0] = true;

        // 空串：只有 X*X*X*... 能匹配
        for (int j = 1; j <= n; ++j)
            if (pattern[j - 1] == '*' && j >= 2)                      // ★ j>=2
                dp[0][j] = dp[0][j - 2];

        for (int i = 1; i <= m; ++i) {
            for (int j = 1; j <= n; ++j) {
                if (pattern[j - 1] == '*') {
                    if (j >= 2) {
                        dp[i][j] = dp[i][j - 2];                      // ★ 0 次
                        if (pattern[j - 2] == '.' ||
                            pattern[j - 2] == str[i - 1])             // ★ 含 '.'
                            dp[i][j] = dp[i][j] || dp[i - 1][j];      // ★ ≥1 次
                    }
                } else if (pattern[j - 1] == '.' ||
                           pattern[j - 1] == str[i - 1]) {
                    dp[i][j] = dp[i - 1][j - 1];
                }
            }
        }
        return dp[m][n];
    }
};
```

实测 204 组穷举 + 2 万组随机对拍（字母表 {a,b}，pattern 保证合法）**全部正确**。

## 七、复杂度

| 维度 | 值 |
|---|---|
| 时间 | `O(m · n)` |
| 空间 | `O(m · n)`，可优化到 **`O(n)`**（滚动数组，但 `dp[i][j-2]` 需要本行数据，要保留当前行） |

**注意**：滚动到一维时 `dp[j-2]` 是**当前行**的值，不能直接用上一行覆盖 —— 要用两个数组交替，或者倒序 + 一个临时变量保存 `dp[i-1][j-1]`。

## 八、易错点

1. **表开成 `(m+1)×(n+1)`** —— 少一列就是越界 UB，而且不崩
2. **`j >= 2` 不是 `j > 2`** —— `X*` 两字符的情况最常见
3. **`*` 的两条分支都要考虑**：0 次（`dp[i][j-2]`）和 ≥1 次（`dp[i-1][j]`），取或
4. **`X` 是 `.` 时也要能匹配** —— 判据里 `.` 和字母要并列
5. **不要用 `pattern == ".*"` 之类特判兜底** —— 会遮住真正的 bug
6. **`dp[i-1][j-2]` 是冗余项** —— 正确写法是 `dp[i][j-2]`

## 九、面试延伸

- **LC 44 通配符匹配**：`?` 匹配任意**一个**，`*` 匹配任意**串**（包括空）。注意这里的 `*` 不修饰前一个字符，转移完全不同（`dp[i][j] = dp[i-1][j] || dp[i][j-1] || dp[i-1][j-1]`）
- **「不用递归会不会更快」**：递归 + 记忆化和 DP 都是 `O(mn)`；纯递归会指数爆炸
- **「返回匹配的具体位置」**：改成求最长前缀，答案取 `dp[i][n]` 里最大的 `i`
- **工程里怎么做**：用 `std::regex`（慢，但正确）或 RE2（快，不支持回溯引用）
