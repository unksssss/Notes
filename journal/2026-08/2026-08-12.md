### FireSim_URP_VR — 热成像模块 ThermalImagingFX 三件套（新建）

- 目标文件：`Assets/Scripts/Author/LJW/ThermalImagingFX/Runtime/`（ThermalSensorController.cs / ThermalSceneRenderer.cs / ThermalSignature.cs）
- 需求：消防演练里的热成像仪——把场景温度以热成像画面呈现，支持 4 档调色板切换
- 实现思路（与"改全局 shader"不同的**代理渲染器 + 专属图层**方案）：
  1. **ThermalSceneRenderer**：每 1.5s 扫描所有 MeshRenderer/SkinnedMeshRenderer，在 thermalLayer(31) 生成 `HideAndDontSave` 隐藏代理物体，共享同一份 ThermalData 材质（不实例化），完整复制骨骼/混合权重与渲染设置（关阴影/探针/运动向量）
  2. **温度写入用 MaterialPropertyBlock** 而非材质实例：每帧写 `_TemperatureC/_Emissivity/_SurfaceVariationC/_VariationScale/_NoiseSeed`，避免材质膨胀 📎 [[Unity 渲染批处理体系]]
  3. 无 ThermalSignature 的对象自动回退：`Hash01(instanceID)` 确定性伪随机在 ambient±variation 间散布温度；`GetAverageMetallic` 读共享材质金属度，在 metalEmissivity(0.42) 与 nonMetalEmissivity(0.94) 间插值发射率
  4. **ThermalSensorController**（挂相机，DefaultExecutionOrder(100)）：`thermalCamera.enabled = false` 关自渲染，按 refreshRate(15fps) 节流手动 `thermalCamera.Render()` 写 RenderTexture（HDR 开、MSAA 关）；温度量程 0~650°C 经 `Shader.SetGlobalFloat` 下发 `_ThermalRangeMinC/MaxC/AmbientC`；显示材质做调色板（WhiteHot/BlackHot/IronRedHot/RainbowLava）、gamma、对比度、固定图案噪声、边缘增强、暗角、扫描线、十字准星，`_SensorFrame` 驱动帧间噪声滚动
  5. **ThermalSignature**：单物体温度签名，`Mathf.MoveTowards` 按 heatingRate/coolingRate 逼近目标温；正弦热脉冲相位用 `GetInstanceID() * 0.6180339f`（黄金比例）打散防同步闪烁；暴露 `AddHeat/RemoveHeat/SetTemperature` 供火焰/灭火系统调用

```cs
// ThermalSensorController 核心：降频手动渲染
float now = Time.unscaledTime;
if (now < nextRenderTime) return;
nextRenderTime = now + 1f / Mathf.Max(1f, refreshRate);
if (!temperatureBuffer.IsCreated()) temperatureBuffer.Create();
thermalCamera.Render(); // enabled=false 后手动出图
```

### FireSim_URP_VR — 编辑器工具：网格转碰撞体（新建）

- 目标文件：`Assets/Scripts/Editor/MeshToChildBox.cs`（Tools/Mesh/生成自定义碰撞体）+ `MeshToParentBox.cs`（Tools/Mesh/生成整合碰撞体）📎 [[Unity编辑器扩展开发入门]] 📎 [[Unity创建编辑器窗体EditorWindow]]
- **MeshToChildBox** 算法：
  1. `mesh.bounds` 按世界 `lossyScale` 缩放得世界包围盒，按 maxBoxSize 均匀切 X/Y/Z 网格
  2. 逐格 `IsBoxOverlappingMesh`：先 `Bounds.Contains` 查顶点，再用三角形包围盒 `Bounds.Intersects` 做三角-盒相交近似
  3. **关键坑**：`center` 存局部坐标、`size` 存世界尺寸——因为 **BoxCollider.size 是世界空间量**，子物体用 `localScale = 1/lossyScale`（逐轴防除零）补偿父缩放
  4. `MergeAdjacentBoxes` 迭代两两合并（Encapsulate），仅当合并后各轴 ≤ maxSize 才接受，把相邻小盒坍缩成大盒减少碰撞体数量；全程 Undo 支持
- **MeshToParentBox**：批量"清碰撞体 + 整体包围盒"替换；`CalculateCombinedBounds` 遍历子级 MeshFilter/SkinnedMeshRenderer，局部 bounds 经 `TransformPoint/TransformVector` 转世界后 Encapsulate；`AddBoundingBoxCollider` 用 `InverseTransformPoint/Vector` 转回父局部空间并取绝对值（防负缩放）；支持 includeInactive、仅清除模式，全部 Undo 记录
