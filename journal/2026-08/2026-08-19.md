### C++ 学习 — HashMap 迭代器完成（链地址法 + 跳桶 + range-for）

目标：`D:\CppTest\hello\HashMap\HashMap.cpp`（258 行，16:35 更新）

在 08-14 手搓的链地址法 HashMap 上补上**迭代器**，支持 `for (auto& v : map)` 遍历。迭代器是 HashMap 的内部类，持有 `cur`（当前节点）+ `bucketsIndex`（当前桶下标）+ `buckets`（桶数组指针）**三件套**：

```cpp
class Iterator{
    Node* cur;
    size_t bucketsIndex;
    const std::vector<Node*>* buckets;
public:
    Node& operator*()  { return *cur; }              // 返回 Node&：key/value 同时可拿
    Iterator& operator++() {
        if (cur->next != nullptr) { cur = cur->next; return *this; }   // ① 链内：直接后跳
        // ② 链走到尾 → 跳桶：从 bucketsIndex+1 起找下一个非空桶的链头
        for (size_t i = bucketsIndex+1; i < buckets->size(); i++)
            if ((*buckets)[i] != nullptr) { cur = (*buckets)[i]; bucketsIndex = i; return *this; }
        cur = nullptr;                               // 找不到 → end 哨兵
        return *this;
    }
    bool operator!=(const Iterator& other) { return cur != other.cur; }
    Iterator(Node* c, size_t idx, const std::vector<Node*>* b)
        : cur(c), bucketsIndex(idx), buckets(b) {}
};

Iterator begin() {  // 第一个非空桶的链头；全空返回 end()
    for (size_t i=0; i<buckets.size(); i++)
        if (buckets[i] != nullptr) return Iterator(buckets[i], i, &buckets);
    return end();
}
Iterator end()   { return Iterator(nullptr, buckets.size(), &buckets); }  // nullptr 哨兵
```

**核心难点：跳桶**——链地址法下同桶节点是单链表，走到链尾后不能停，必须从 `bucketsIndex+1` 开始找下一个非空桶的链头继续，否则**空桶之间的节点全丢**。`end()` 用 `nullptr` 哨兵而非真实节点，`!=` 比较指针即可。

**踩坑记录（教学 review 三轮）**：

| # | 错误写法 | 问题 | 修复 |
|---|---|---|---|
| ① | `begin` 返回 `*buckets[0]` | Node 不是 Iterator，类型不匹配 | 值构造 `Iterator(buckets[i], i, &buckets)` |
| ② | `end` 用 `buckets[size]` | 越界访问 | `nullptr` 哨兵构造 |
| ③ | `operator++` 前进后忘 `return` | 编译器续跑下一分支，链中间节点被跳过 | `if/else` 二选一，各分支都 return |
| ④ | `new Iterator(...)` 返回 | 类型不匹配 + 内存泄漏 | 按值返回 |
| ⑤ | range-for 里取迭代器本身 | 变量是 `operator*` 解引用结果 | `for (auto& v : map)` 的 `v` 是 Node& |
| ⑥ | `end()` 若用最后一个节点 | `!=` 恒真 → 死循环 | 必须 nullptr 哨兵 |

**验证**：`put` 100 个 key 触发 4 次扩容（8→17→37→79→163，装载因子 0.75 质数扩容），range-for 全部遍历无丢失 ✅

**追加设计对比**：`operator*` 从返回 `V&` 改成 `Node&`，遍历时可同时拿 key+value（`v.key` / `v.value`）；对比 `std::unordered_map` 的迭代器解引用返回 `pair<const K, V>&`——标准库刻意**不暴露内部节点**，只暴露键值对（封装性更强），而自造迭代器直接暴露 Node 更灵活。📎 [[哈希表冲突解决与Dictionary底层]]、[[C# foreach 与枚举器零分配]]
