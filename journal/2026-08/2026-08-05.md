### FireSim_URP_VR — Hose 水管系统：路径追踪 + 程序化网格（LJJ 新模块）

今天新建了整套消防水管系统（10+ 文件，`Assets/Scripts/Author/LJJ/Test/Hose/`），核心设计：**水管长度 = 消防员走过的路径总长度**，而不是两端直线距离。与手头的 Obi 绳索方案互补，纯代码 Mesh 方案。

**1. `HosePath.cs` — Trail Tracking 路径追踪**

问题：水带要真实地"铺在地上"，急转弯不能破面，且点太密会浪费性能。

根因/设计：历史点固化 + 软下落贴地 + 切角 + 平滑。

```cs
// 软下落：距消防栓越远越贴地（InverseLerp + SmoothStep 平滑过渡）
float t = Mathf.InverseLerp(FalloffStart, FalloffEnd, distToHydrant);
t = Mathf.SmoothStep(0f, 1f, t);
targetCenterY = Mathf.Lerp(AnchorA.y, fullGroundY, t);

// 急转弯切角（Chaikin 风格）：dot < 阈值时在尖角两侧加 q/r 两点
float dot = Vector3.Dot(d1, d2);
if (dot < CornerCutThreshold)
{
    float k = 0.3f * Mathf.Min(1f, distToAnchor / PointSpacing);
    _fixedPoints.Add(lastFixed + d1 * PointSpacing * k); // q
    _fixedPoints.Add(lastFixed + d2 * PointSpacing * k); // r
}

// 5 点高斯加权平均平滑（迭代 smoothingSubdivisions 次）
// sum = p0 + 4p1 + 6p2 + 4p3 + p4; newPoint = sum / 16
```

关键坑：**合并过近点防零长度段**（`MinPointDistance = 0.005f`），否则切线 NaN → 网格炸裂。

**2. `HoseMeshGenerator.cs` — Bishop Frame (Double Reflection) 管道网格**

问题：普通沿路径扫掠管道在急转/180° 掉头时截面会翻转破面。

根因：截面朝向（right/up 向量）随路径传播时会累积漂移和翻转。

解决：Bishop Frame 双反射算法保持截面方向连续 + 每步正交化 + 中心差分切线：

```cs
// 双反射核心：v1 = 归一化(prevForward + forward)
Vector3 r1 = prevRight - 2f * Vector3.Dot(prevRight, v1) * v1;
Vector3 r2 = r1 - 2f * Vector3.Dot(r1, forward) * forward;
right = r2.normalized;
// 防 180° 翻转：与 prevRight 反向则取反
if (Vector3.Dot(right, prevRight) < 0) right = -right;

// 正交化：right 完全垂直 forward，再重算 up
Vector3 orthoRight = right - Vector3.Dot(right, forward) * forward;
```

另外加了：退化三角形保护（边距 < 1e-5 跳过）、端帽只加 1 个中心点（保证顶点/UV 数量同步）、顶点/UV 数量校验、`IndexFormat.UInt32`、`mesh.RecalculateNormals()`（几何平均，比手动稳定）。

**3. `HoseController.cs` — 主控制器 + 锚点贴合**

- AnchorB（消防员端）滞后平滑：`Vector3.MoveTowards(_smoothedAnchorB, rawAnchorB, anchorBSmoothSpeed * dt)`，避免手部突变引起切线跳变折痕
- 锚点贴合双模式：`anchorAtExactPosition`（端点=锚点中心）或 `SnapToSurface`（`Collider.ClosestPoint` 贴表面 + 内部点用 bounds.center 外推）
- `ResolveGroundY()`：有 groundReference 时取 `Collider.bounds.max.y`（顶面）

**1. `WristStepPanel<TData, TItem>` — 泛型步进面板基类**（`WristUI/WristStepPanel.cs`）

把"步进 + 视野滚动 + 高亮"抽成通用框架，实现 `IWristUI`（Focus/Defocus/MoveNext/MovePrevious/Confirm）：

```cs
public class WristStepPanel<TData, TItem> : MonoBehaviour, IWristUI where TItem : Component
{
    // index = 数据索引；viewIndex = 视野内相对索引（两者分开管理）
    public virtual void MoveNext()
    {
        bool isOnBoundary = IsOnRightBoundary();   // 移动前判断边界
        index = Mathf.Min(index + 1, maxIndex);
        viewIndex = Mathf.Min(viewIndex + 1, countOfItemInView - 1);
        if (isOnBoundary) ApplyContentNextStep(index);  // 触底 → 滚动内容
        else             ApplyStepSelect(index);        // 未触底 → 仅移动高亮
    }
    protected virtual void Highlight(int _index) { }    // 子类实现
    public event UnityAction<TData> OnChooseData;       // event 访问器模式
}
```
