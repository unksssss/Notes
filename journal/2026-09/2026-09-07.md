1. **SceneTaskBase 任务基类状态机**（Lv/Task/Core，此前为抽象骨架）

2. **TaskTrigger 触发器**（Control）——玩家进入触发高光、可 PushComplete/PushReset 切换激活：
```cs
private void OnTriggerEnter(Collider other)
{
    SetShowActive(true);
    if (IsSelect) return;             // 任务已选中则不再高亮
    CommUtils.ShowHigh(triggerParent, true, true);
}
public void PushComplete()  { SetShowActive(false); gameObject.SetActive(false); }
public void PushReset()     { SetShowActive(false); gameObject.SetActive(true); }
```

### FireSim_URP_PC — 16:19 新工具三件套（NPC_Create / SceneLayoutLoader / NavMeshVisualizer）

1. **NPC_Create**（Lv/Task/Control）——预设体子物体随机创建：
   - `TaskPrefabType` 六类型：Escape 单个 Idle / Rescue_Sit / Rescue_Down / Evacuation_1~3（1~3 名疏散 NPC）
   - 疏散 NPC 在半径 0.6m 圆周上分布：`GenerateRandomAngles` 保证两两夹角 ≥50° 防重叠；`Quaternion.LookRotation(-position)` 让 NPC z 轴朝向圆心；运行期 `AddComponent<NPC_NavFollower>` + BoxCollider（center 0.85/0.35×1.7×0.28 近似人形）

2. **SceneLayoutLoader**——按任务类型从 JSON 加载场景布置：
   - `LoadLayout(TrainingTaskType)` → `JsonFileHelper.TryReadJson<TaskData>(StreamingPath.MOCKAPI_FILES + ToMockFileName(taskType))`（StreamingAssets/MockApi 目录）
   - `SpawnSceneLayout` 遍历 `sceneLayout.placedObjects` → `FindPrefabById`（组训预制体数组匹配 PrefabId、返回同索引实训预制体）→ Instantiate 到对应 Parent（GL 高楼/DYY 影院/PDS 配电房）→ 按 PlaceableCategory 分组入 `spawnedObjectList` → `MessageHandler.Notify((int)MessageEventType.Task_Train, dict)` 广播给各 SceneTaskBase 订阅者
   - `ClearSpawnedObjects()` 倒序遍历 Destroy 清理（换房/重载布局用）

3. **NavMeshVisualizer**——NavMesh 可视化调试工具（导航盲区排查用）：
```cs
NavMeshTriangulation data = NavMesh.CalculateTriangulation(); // 世界坐标
mesh.vertices = data.vertices;  mesh.triangles = data.indices;
```
   - **坑**：`NavMesh.CalculateTriangulation` 顶点是**世界坐标**，显示物体必须 Awake 归零 `transform.position/rotation/localScale`，否则网格偏移到看不见
   - 材质：`Shader.Find` 三级回退（Unlit/Color → URP Unlit → Hidden/Internal-Colored）+ 手改混合状态（SrcAlpha/OneMinusSrcAlpha + ZWrite off + renderQueue=3000 透明），`RecalculateNormals/Bounds`
   - 阴影关：`ShadowCastingMode.Off` + receiveShadows=false
