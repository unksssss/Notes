# DFS 与 BFS 遍历算法

## 对比总览

| | DFS（深度优先） | BFS（广度优先） |
|---|---|---|
| 数据结构 | 递归 / 显式栈 | 队列 |
| 遍历方式 | 一头扎到底再回溯 | 一层一层扫 |
| 典型应用 | **环检测**、拓扑排序、连通分量、回溯/迷宫 | **无权图最短路径**、层序遍历、状态扩散 |
| 时间复杂度 | O(V+E) | O(V+E) |
| 空间复杂度 | 最坏 O(V)（递归深度，通常更省） | 最坏 O(V)（队列） |

> 记忆口诀：**BFS = 队列 + 一层一层扫 → 最短路径；DFS = 递归/栈 + 一头扎到底 → 环检测**

## 细节要点（面试）

1. DFS 递归写法（系统栈）和显式栈写法**都行**，递归更常见
2. 有向图环检测需**三色标记**（白=未访问 / 灰=访问中 / 黑=完成）——DFS 回边指向"灰"节点即有环
3. BFS 求无权图最短路径：**第一次到达某节点即为最短**（层数即距离）
4. BFS 可配合 visited 数组防重复入队

## ⚠️ 高频失分点：最短路径为什么选 BFS 不是 DFS？（Day 12/13/14 连续失分）

**错解**："DFS 一条路走到底，最快碰到终点" ❌

**正解**：DFS 一条路走到底，但可能一头扎进一条**超长的分支**才碰到终点——**第一次找到的路径不保证最短**；BFS 按"距离层"逐层扩展（先所有距离 1 的节点，再距离 2 的…），所以**第一次访问到终点时经过的层数必然是最短距离**。

| | DFS | BFS |
|---|---|---|
| 找无权图最短路径 | ❌ 不保证 | ✅ 第一次命中即最短 |
| 环检测 | ✅ 三色标记 | 可用但不如 DFS 直观 |
| 拓扑排序 | ✅ | 可用（Kahn 算法） |
| 迷宫可行性/路径探索 | ✅ 回溯方便 | 可选 |

> 注意：**带权图**最短路径 DFS/BFS 都不行，要 **Dijkstra / A***。

## 典型代码骨架

```csharp
// BFS（队列）
void BFS(Graph g, int start)
{
    Queue<int> q = new Queue<int>();
    bool[] visited = new bool[g.N];
    q.Enqueue(start); visited[start] = true;
    while (q.Count > 0)
    {
        int v = q.Dequeue();
        foreach (int w in g.Adj(v))
            if (!visited[w]) { visited[w] = true; q.Enqueue(w); }
    }
}

// DFS（递归）
void DFS(Graph g, int v, bool[] visited)
{
    visited[v] = true;
    foreach (int w in g.Adj(v))
        if (!visited[w]) DFS(g, w, visited);
}
```

## 二叉树四种遍历（Day 17 补充）

本质区别一句话：**根节点什么时候被访问**。

| 遍历方式 | 访问顺序 | 根的位置 |
|---|---|---|
| **前序** | 根 → 左 → 右 | 根**最前** |
| **中序** | 左 → 根 → 右 | 根**中间**（二叉搜索树 = 从小到大输出） |
| **后序** | 左 → 右 → 根 | 根**最后** |
| **层序** | 逐层从左到右 | 按层（**队列** = BFS） |

例：
```
      A
     / \
    B   C
   / \
  D   E
```
- 前序：A B D E C
- 中序：D B E A C
- 后序：D E B C A

**记忆口诀**：「前中后」说的是**根**的位置（根前/根中/根后），左子树永远在右子树前面。前三种递归或栈（DFS），层序用队列（BFS）。

## ⚠️ 高频失分点：前序迭代实现 = 栈，不是队列！（Day 20 又滑铁卢）

**错解**："访问到节点就把左右孩子加入队列" ❌ —— 那是**层序（BFS）**的思路！

**正解**：前/中/后序的迭代实现（DFS）用 **栈**；只有层序（BFS）用队列。

> 口诀：**层序（BFS）= 队列；深度优先（前/中/后序迭代）= 栈**。队列先进先出横向铺开，栈后进先出纵向深入。

前序迭代模板：

```csharp
Stack<TreeNode> stack = new Stack<TreeNode>();
stack.Push(root);
while (stack.Count > 0)
{
    TreeNode node = stack.Pop();
    visit(node);                                  // 先访问根
    if (node.right != null) stack.Push(node.right); // 先压右
    if (node.left  != null) stack.Push(node.left);  // 再压左 → 左先弹出
}
```

**关键在压栈顺序**：栈是后进先出，要保证"左孩子先被访问"，就得**先压右、再压左**——后压的左孩子先弹出，顺序变成 根→左→右。

复杂度：时间 O(n)（每个节点进出栈一次），空间 O(h)（h 为树高，最坏退化为链时 O(n)）。

## 后序迭代：双栈法（Day 28 考点）

后序"左→右→根"是**最叛逆**的遍历：孩子访问完才轮到根，单栈没法边压边访问。经典解法是**双栈法**：

```
栈1 走"根→右→左"变体前序（注意压栈顺序与前序相反：先压左、再压右）
  → 弹出的节点按"根右左"顺序压入栈2（即后序的倒序）
栈2 依次弹出 = "左→右→根" ✅
```

```csharp
Stack<TreeNode> s1 = new(), s2 = new();
s1.Push(root);
while (s1.Count > 0)
{
    TreeNode cur = s1.Pop();
    s2.Push(cur);                          // 结果缓冲：先弹根，栈2 里根在最底
    if (cur.left  != null) s1.Push(cur.left);   // 先压左（与前序相反）
    if (cur.right != null) s1.Push(cur.right);
}
while (s2.Count > 0) visit(s2.Pop());      // 栈2 倒序输出 = 左 右 根
```

**核心洞察**：后序 = "根右左"的逆序。既然后序难直接做，就走一个能做的变体前序（根右左），再用第二个栈反转，曲线救国。另一个思路是**单栈+标记法**（访问过的节点打标记，第二次遇到才输出），但双栈法最直观。

复杂度：时间 O(n)，空间 O(n)（两个栈最坏都存 n/2 左右）。
