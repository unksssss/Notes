# 旋转矩阵

## 一、题目

`n × n` 矩阵**原地**顺时针旋转 90°（牛客 BM99 传入 `n`，返回矩阵）。

```
1 2 3        7 4 1
4 5 6   →    8 5 2
7 8 9        9 6 3
```

## 二、核心认知

顺时针 90° 就是下标变换 `(r, c) → (c, n-1-r)`。

**原地做**的关键：四个位置构成一个**闭环**，一圈正好四步：

```
左上 (top, left+i)  →  右上 (top+i, right)
                            ↓
左下 (bottom-i, left)  ←  右下 (bottom, right-i)
```

所以每次 `temp` 存一个、轮换四次就归位，不需要额外空间：

```cpp
int temp = mat[top][left + i];
mat[top][left + i]     = mat[bottom - i][left];
mat[bottom - i][left]  = mat[bottom][right - i];
mat[bottom][right - i] = mat[top + i][right];
mat[top + i][right]    = temp;
```

**这段灯皇写对了**，四个映射一个不差。问题在循环转几格。

## 三、❌ 错在「每层转几个」

```cpp
while (left < right && top < bottom) {
    for (int i = 0; i < n - 1; i++) {   // ❌ 用了整行的长度
        ...
    }
    left++; right--; top++; bottom--;
}
```

每层的边长是 `right - left + 1`，一圈四个角，**要转的次数 = 边长 − 1 = `right - left`**。

- 第 0 层：`right - left = n - 1` ✓（所以最外层恰好等于 `n - 1`，看起来没错）
- 第 1 层：`right - left = n - 3`
- 第 k 层：`n - 1 - 2k`

写死 `n - 1` 的后果，随 n 分三档：

| n | 现象 |
|---|---|
| 1、2、3 | **全对**（n≤3 时只有一层或一层半，`n-1` 刚好等于需要的次数） |
| 4、5 | 内层多转几格 → 结果错乱 |
| ≥ 6 | 中途越界 → **段错误** |

实测：

```
n=4  你的 = [[13,15,5,1],[14,11,10,9],[8,7,6,3],[16,12,2,4]]
     正确 = [[13,9,5,1],[14,10,6,2],[15,11,7,3],[16,12,8,4]]

n=5  你的 = [[21,24,11,6,1],[22,19,12,17,16],...]
     正确 = [[21,16,11,6,1],[22,17,12,7,2],...]

n=6  在 left=2 这一层、i=4 时访问 mat[2][6]（列越界，合法范围 0..5）→ 段错误
```

### 为什么 `n ≤ 3` 会"通过"

`n = 3` 时只有第 0 层（`left=0,right=2`），转 `n-1 = 2` 次正好正确；内层 `left=right=1` 不满足 `left < right` 直接退出。所以三层以内的用例**永远测不出这个 bug** —— 和上一题"方阵掩盖 m/n 写反"是同一类陷阱：**用例的规模掩盖了错误**。

## 四、正解

```cpp
vector<vector<int> > rotateMatrix(vector<vector<int> >& mat, int n) {
    int left = 0, top = 0, right = n - 1, bottom = n - 1;
    while (left < right) {                       // n×n 时 top/bottom 与 left/right 同步
        for (int i = 0; i < right - left; i++) { // ★ 当前层边长 − 1
            int temp = mat[top][left + i];
            mat[top][left + i]     = mat[bottom - i][left];
            mat[bottom - i][left]  = mat[bottom][right - i];
            mat[bottom][right - i] = mat[top + i][right];
            mat[top + i][right]    = temp;
        }
        left++; right--; top++; bottom--;
    }
    return mat;
}
```

`n = 1..12` 实测**全部正确**（与 `r[j][n-1-i] = mat[i][j]` 的参考实现逐元素比对）。

## 五、解法二：转置 + 逐行反转（最不容易错）

```cpp
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)
        swap(mat[i][j], mat[j][i]);          // ① 转置（只遍历上三角）
for (int i = 0; i < n; i++)
    reverse(mat[i].begin(), mat[i].end());   // ② 每行反转
```

**两次简单置换合成一个复杂置换**，几乎不可能写错下标。面试时先说这个，再说四路轮换的 `O(1)` 版本。

| 方向 | 做法 |
|---|---|
| 顺时针 90° | 转置 + 每行 reverse |
| 逆时针 90° | 转置 + 每列 reverse（或先每行 reverse 再转置） |
| 180° | 每行 reverse + 整体上下 reverse |

## 六、解法三：辅助矩阵（最直观）

```cpp
vector<vector<int> > r(n, vector<int>(n));
for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        r[j][n - 1 - i] = mat[i][j];
```

`O(n²)` 空间，但下标关系一眼可见 —— **调试时用它对拍**特别方便。

## 七、必须记住的点

1. **原地轮换的次数是「当前层边长 − 1」**，不是整行长度。`right - left` 就是它。
2. **外层恰好等于 `n-1`，所以最外层永远测不出这个错** —— 必须用 `n ≥ 4` 的用例。
3. **四路轮换必须"先存再覆盖"**：`temp` 存第一个，然后reverse 顺序赋三次，最后写回 `temp`。少存一处就丢数据。
4. **`while (left < right)` 一个条件就够**（n×n 时 `top==left`、`bottom==right`），写 `&& top < bottom` 也不出错，只是多余。

## 八、易错点

1. **`i < n - 1`** —— 本例。表现随 n 变化：小规模全对、中规模错乱、大规模崩，最难定位。
2. **转置时 `j` 从 `0` 开始** —— 会把每对元素交换两次，等于没转。必须 `j = i + 1`。
3. **reverse 方向搞反**（顺时针写成逆时针）—— 用 `1 2 / 3 4` 一组就能验：顺时针应得 `3 1 / 4 2`。
4. **`n` 与 `mat.size()` 不一致** —— 函数同时收了 `n` 和矩阵，若不一致以哪个为准要明确（本题保证一致）。
5. **空矩阵** —— `n = 0` 时 `right = -1`，循环不进，安全。

## 九、复杂度

| 解法 | 时间 | 空间 |
|---|---|---|
| 四路轮换 | `O(n²)` | **`O(1)`** |
| 转置 + reverse | `O(n²)` | `O(1)` |
| 辅助矩阵 | `O(n²)` | `O(n²)` |

## 十、面试延伸

- **LC 48 旋转图像**：同一题，不带 `n` 参数（自己取 `matrix.size()`）
- **LC 54 / 59 螺旋矩阵**：同族"按层处理"的题，但那是**读/写顺序**，本题是**位置轮换**
- **LC 1886 判断矩阵经轮转后是否一致**：暴力转四次逐一比对
- **LC 566 重塑矩阵**：一维下标映射 `i*m + j`，不涉及旋转
- **升级版**：非方阵不能原地转 90°，只能新开 `n×m` 的矩阵
