### 配电房项目 — HookRope 地下绳索淡出系统完善

**目标文件**: `Assets/Scripts/HookRope.cs`

**改动内容**:
- 新增 `fadeWidth`（Range 0~5）参数控制淡出宽度
- 绳索 GameObject 的 transform 位置从 `ropeEnd.position` 改为 `(ropeEnd.x, 0.05f, ropeEnd.z)`，放在地面高度而非枪口位置
- 使用 `Custom/RopeFade` 着色器替代默认材质，着色器通过**点到面距离算法**实现透明度渐变

**着色器原理** (`Assets/Shaders/RopeFade.shader`)：
- 定义 `_FadeCenter`（锚点位置）和 `_FadeNormal`（锚点→玩家方向）
- 每个顶点计算到该平面的有符号距离 `dot(pos - center, normal)`
- 玩家侧（距离 >0）可见，另一侧（距离 <0）按 `1 + dist/fadeWidth` 做 `saturate` 得到 alpha
- 支持 URP 渲染管线，Blend SrcAlpha OneMinusSrcAlpha

**淡出面更新逻辑**：
```csharp
// 初始化时设置
_fadeMat.SetVector("_FadeCenter", ropeStart.position);
_fadeMat.SetVector("_FadeNormal", (ropeEnd.position - ropeStart.position).normalized);
_fadeMat.SetFloat("_FadeWidth", fadeWidth);

// Update() 每帧跟随玩家移动更新法向
void Update() {
    _fadeMat.SetVector("_FadeCenter", ropeStart.position);
    Vector3 fadeNormal = (ropeEnd.position - ropeStart.position).normalized;
    _fadeMat.SetVector("_FadeNormal", fadeNormal);
}
```

**场景参数调整**（`Assets/Scenes/RopeTest.unity`）：
- `maxRopeLength`: 10000 → 50
- `fadeRadius`: 0.5, `fadeWidth`: 1.5（HookRobe 组件新增字段）

### 配电房项目 — StepBackPack index 溢出踩坑

**问题表现**：步进背包中，当装备数量 > 单屏显示数时，选中框 `img_Selected` 随着 `index` 递增一路飞到屏幕外。

**根因分析**：最初版本没有 `selectIndex`，`index` 同时兼任两职——数据索引（取 `equipDefDict[key]`）和视觉位置（`img_Selected` 偏移 = `index * stepSize`）。当 `index` 增长到 11（即超过 `countOfItemInView-1`）时，选中框自然飞出屏幕。

**修复方案**：引入 `selectIndex` 将视觉位置独立出来：
- `selectIndex ∈ [0, countOfItemInView - 1]` → 控制 `img_Selected` 选框位置，永远不超出屏幕
- `index ∈ [0, maxIndex]` → 正常取数据
- 边界时内容滚动委托给 `StepScrollView` 的 `StepNext/StepPrev`

```csharp
// 修复前：index 同时控制数据和选框
float offset = index * stepSize;
img_Selected.DOAnchorPos(originalPos + new Vector2(offset, 0), aniTime);

// 修复后：selectIndex 只控制选框，index 只控制数据
selectIndex = Mathf.Min(selectIndex + 1, countOfItemInView - 1);
float offset = selectIndex * stepSize;
img_Selected.DOAnchorPos(originalPos + new Vector2(offset, 0), aniTime);
```

**经验教训**：UI 的视觉索引和数据索引不能混为一谈，该解耦时就解耦。
