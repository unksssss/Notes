**题面**：判断一棵二叉树是否为有效 BST —— 左子树**所有**节点严格小于根、右子树**所有**节点严格大于根，且左右子树自身也必须是 BST。

---

**❌ 初版代码：三层问题，没有一个分支是对的**

```cpp
bool isValidBST(TreeNode* root) {
    if(root) return true;                                    // ① 少写 `!`
    return isValidBST(root->left)&&isValidBST(root->right);   // ② 只在 nullptr 时执行
    if(root->val>root->left->val&&root->val<root->right->val) return true;  // ③ 死代码
    else return false;
}
```

| 层 | 问题 | 后果 |
| --- | --- | --- |
| 控制流 | ① `if(root)` **少写 `!`** | 非空 → 恒 `true`，任何树都判通过；空 → 走 ② 对 `nullptr` 解引用崩溃 |
| 控制流 | ② 递归只在 `root == nullptr` 时执行 | 必然空指针解引用，`&&` 两侧都跑不到 |
| 不可达 | ③ 写在 `return` 之后 | 永远执行不到，纯死代码 |
| 算法思想 | 只比父子（`root->val > root->left->val`） | **跨层约束丢失** |
| 算法思想 | ③ 判完直接 `return`，不递归子树 | 即使父子都对，孩子自己的子树也没校验 |
| 健壮性 | ③ 访问 `root->left->val` 前不判空 | 叶子节点直接崩 |

**根因（唯一核心认知）**：BST 的约束是**整棵子树级**，不是**父子级**。定义写的是「左子树**所有**节点 < 根」，所以**每个节点能取什么值由它所有祖先共同决定** —— 必须落在祖先逐步收窄出来的一个开区间里。

**经典反例**（面试必须能当场画）：

```
       10
      /  \
     5    15
         /  \
        6    20
```

`10>5` ✓ `10<15` ✓ `15>6` ✓ `15<20` ✓ —— **每条父子边都合法**，但 `6` 落在 `10` 的右子树里却 `6 < 10`，不是 BST。只比父子的判据**必然误判**。

---

**✅ 修复一：上下界区间递归（首选，O(h) 空间）**

```cpp
class Solution {
public:
    bool isValidBST(TreeNode* root) {
        return check(root, LLONG_MIN, LLONG_MAX);              // 根：(-∞, +∞)
    }
private:
    bool check(TreeNode* node, long long low, long long high) {
        if (!node) return true;                                // 空节点不违反任何约束
        if (node->val <= low || node->val >= high) return false;  // ★ 等号也要拒绝（严格）
        return check(node->left,  low, node->val)               // 往左：上界收紧，下界保持
            && check(node->right, node->val, high);             // 往右：下界收紧，上界保持
    }
};
```

区间一路传下去，`10` 这个下界会「跟着」到右子树的孙子：`6 ∈ (10, 15)` 不成立 → 抓住反例。

**⚠️ 边界踩坑（Windows 专属）**：很多题解写 `LONG_MIN / LONG_MAX`，在 LeetCode（Linux LP64）能过，**在 Windows / VS 上会挂** —— Windows 是 **LLP64**，`long` 只有 **32 位**，`LONG_MIN == INT_MIN`。节点值恰好为 `INT_MIN` 时 `INT_MIN <= INT_MIN` 成立 → **合法 BST 被误判为 false**。

```cpp
check(root, LLONG_MIN, LLONG_MAX);                                                 // <climits>
check(root, numeric_limits<long long>::min(), numeric_limits<long long>::max());   // <limits>
// 或干脆不用数值边界，改用前驱指针（解法二）
```

---

**✅ 修复二：中序递归（BST 中序 = 严格升序）**

```cpp
bool inOrder(TreeNode* node, TreeNode*& prev) {              // ★ 引用传参
    if (!node) return true;
    if (!inOrder(node->left, prev)) return false;            // 左子树不合法 → 立即剪枝
    if (prev && prev->val >= node->val) return false;        // 必须【严格】递增
    prev = node;                                             // 更新前驱
    return inOrder(node->right, prev);
}
```

**`prev` 必须是 `TreeNode*&`** —— 和 📎 [[二叉搜索树转双向链表]] 里**完全同一个坑**：`prev` 每层都要更新且外层要用到内层更新后的值，值传递时每层各持一份副本、返回即销毁，外层 `prev` 永远 `nullptr` → **校验完全失效、函数恒返回 true**。这就是「**谁需要把改动带出去，谁就加 `&`**」的第二次登场。

**✅ 修复三：迭代中序（显式栈，防深递归爆栈）**

```cpp
while (cur || !st.empty()) {
    while (cur) { st.push(cur); cur = cur->left; }           // 向左压到底
    cur = st.top(); st.pop();                                // 弹出 = 访问
    if (prev && prev->val >= cur->val) return false;
    prev = cur;
    cur = cur->right;
}
```

面试被追问「不用递归」时直接上这个。

---

**三解法对比**

| | 上下界递归 | 中序递归 | 中序迭代 |
| --- | --- | --- | --- |
| 核心思想 | 区间约束 | 升序校验 | 升序校验 |
| 时间 / 空间 | O(n) / O(h) | O(n) / O(h) | O(n) / O(h) |
| 需要 `TreeNode*&` | 否 | **是** | 否 |
| 边界陷阱 | **有**（`LLONG_MIN`） | 无 | 无 |
| 推荐度 | ★★★ 首选 | ★★ 体现「中序 = 升序」 | ★★ 防爆栈 |

**必须记住的三条**
1. **BST 约束是子树级**，不是父子级 —— 所有错误判据的根源。
2. **必须严格**：`<= low || >= high` 两侧等号都要拒绝；中序版写 `>=` 而非 `>`，否则放过重复值。
3. **上下界单向收紧**：往左只收紧上界、往右只收紧下界；两侧都收紧会把合法子树误判非法。

**易错点清单（7 条）**：`if(root)` 少 `!` ／ 只比父子 ／ 判完直接 return 不递归子树 ／ 访问孩子值不判空 ／ 边界用 `INT_MIN`·`LONG_MIN` ／ 中序 `prev` 忘加引用 ／ 用 `>` 代替 `>=`。
