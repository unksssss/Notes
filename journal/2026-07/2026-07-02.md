### BreakingWall — 精准破碎 BreakAtPoint 实现

**目标文件**: `Assets/Scripts/Author/Wt/BreakingWall.cs`

实现点击位置精准破碎：从鼠标 Raycast 碰撞点向外扩散，只碎点击点 1m 内的碎片。

核心逻辑：
```cs
public void BreakAtPoint(Vector3 hitPoint)
{
    foreach (var rb in wallFragments.GetComponentsInChildren<Rigidbody>())
    {
        float dist = Vector3.Distance(rb.position, hitPoint);
        if (dist > 1f) continue;                        // 只碎 1m 内
        rb.isKinematic = false;
        float force = explosionForce * (1f - dist / 1f); // 越近越猛
        Vector3 dir = (rb.position - hitPoint).normalized + _breakingDirection * 0.5f;
        rb.AddForce(dir.normalized * force, ForceMode.Impulse);
    }
}
```

| 改前 | 改后 |
|---|---|
| 全部碎片受力 | **只碎点击点 1m 内** |
| 力度均匀 | **距离越近力越大** |
| 统一方向 | 从击打点**向外扩散** + 方向偏置 |

### OAVA 机制深度 — meshFire 与 BoxCollider

**天花板火焰问题**：BoxCollider center 设负值无法让火焰向下生长，OAVA 生成逻辑固定从 Collider 顶部生成。

**解决方案**：`useMeshFire = true` + `meshFireCount` 调至 20~30，火焰沿 Mesh 顶点均匀分布，底面可见。

**OAVA Convert — flammable skinned mesh 选项**：Editor 工具中的选项，针对 SkinnedMeshRenderer（骨骼动画模型）做转换适配。普通项目无需勾选。

### ShaderGraph 报错 — BlackboardController NullRef

ShaderGraph 在编译 OAVA Custom_flame.shadergraph 时内部 BlackboardController 初始化空引用。

解决路径：
1. 关 ShaderGraph 窗口 → Reimport .shadergraph 文件
2. 删 `Library/ShaderCache` 让 Unity 重建
3. Packages Manager → ShaderGraph 更新至最新 14.0.x

### 每日知识问答 — Day 3（2.5/5）

**Q1 — BreakAtPoint 精准破碎**：[A] 只碎点击点附近区域，远距离不受力 ✅
> 核心：`Vector3.Distance + Mathf.Clamp01` 距离衰减 + 从打击点向外扩散方向力。破墙不再一刀切。

**Q2 — 天花板火焰**：❌ 正解：`useMeshFire = true`
> BoxCollider center 改负值没用——OAVA 固定从 Collider 表面生成火焰。`meshFire` 沿 Mesh 顶点全方向分布，天花板底面的顶点也能烧到。

**Q3 — ShaderGraph 报错**：❌ 正解：BlackboardController 内部空引用 bug
> 不是 URP/ShaderGraph 版本不兼容。BlackboardController.cs:455 初始化时遇到 null。修复：Reimport .shadergraph 或删 `Library/ShaderCache`。

**Q4 — flammable skinned mesh**：部分对。OAVA Convert 中针对 SkinnedMeshRenderer 的转换选项
> 不是让 FlammableObject「支持」骨骼动画——是在 Convert 阶段就把骨骼模型的特殊配置设好。普通项目用不到。

**Q5 — Burnout 风格定制**：部分对。每个物体独立调参数
> `shaderBurntColor`、`shaderEmissionColor`、`burnOutLength_s`、`shaderToBurntInterpolateSpeed` 等参数逐物体设置——木头焦炭/金属烧红/布料灰烬各有不同。
