### FireSim_URP_PC — 登录→训练入口链路新增（LoginPanel / LoadingPanel，15:07~16:04）

ConducTraining 配置系统前面加了**入口分流**：登录页按角色 Toggle 分流——「学员」→ LoadingPanel 加载训练场景，「教员/指挥员」→ ConductTrainingPanel 进任务配置。`LoadingPanel.cs` 与 `LoginPanel.cs` 均为今日新建（创建时间=修改时间同刻）。

**LoginPanel 面板切换技巧——"当前面板浮在最上层、只淡出自己露出下层目标"**：目标面板先置可见（alpha=1 + 关交互），`transform.SetAsLastSibling()` 保证自己遮挡目标，随后 `DOFade(0)` 淡出自己 → OnComplete 再开目标交互并恢复自身 alpha（供下次复用）→ `SetActive(false)` 收尾；`_isTransitioning` 防连点、`_transitionSequence?.Kill()` 防叠动、`SetUpdate(true)` 无视 timeScale：

```cs
targetCanvasGroup.alpha = 1f;                       // 目标先显示
targetPanel.SetActive(true);
transform.SetAsLastSibling();                       // 当前面板保持在最上层
_loginCanvasGroup.interactable = false;

_transitionSequence = DOTween.Sequence()
    .SetUpdate(true)
    .Append(_loginCanvasGroup.DOFade(0f, _fadeDuration).SetEase(Ease.OutSine))
    .OnComplete(() =>
    {
        targetCanvasGroup.interactable = true;       // 露出后再放行目标交互
        _loginCanvasGroup.alpha = 1f;                // 恢复供下次显示
        _isTransitioning = false;
        gameObject.SetActive(false);
    });
```

> 与昨天 VR 里"先 SetActive 隐藏再淡入"不同，这里反向操作——先显示目标但关 raycast，靠层级 + 淡出当前面板完成无缝切换，视觉上没有黑帧。角色选择 `_instructors` Toggle 决定 `targetPanel = _isInstructors ? ConductTrainingPanel : LoadingPanel`。

### FireSim_URP_PC — FireSetPanel 滑杆初始值数据源切换（15:44）

`FireSetPanel.cs`（Wt/UI/FireSet/）初始值来源由「场景第一个 FlammableObject 字段当前值」改为**「taskData.flameSettings 任务配置」**，字段映射方向与 `CaptureConfig()` 相反（读入 ↔ 写回一一对应）：

| 面板滑杆（taskData.flameSettings） | FlammableObject 字段 |
|---|---|
| flameHeight / flameSize | flameLength / flameParticleSize |
| burnSpeed / activity | flameEnvironmentalSpeed / flameLiveliness |
| spreadSpeed / extinguishDifficulty | fireCrawlSpeed / fullExtinguishToughness |
| smokeConcentration / smokeIntensity | smokeAlpha / smokeColorIntensity |
| smokeSize / sparkSize / sparkQuantity | smokeParticleSize / embersParticleSize / embersBurstVFXMultiplier |

改动要点：
- `Start()` 里 `taskData` 获取提前 + manager 判空，订阅 `ConductTrainingManager.CurrentTaskChanged += UpdateView`（任务切换即刷新滑杆）
- 滑杆进度 = 字段值 / Range 上限（滑杆 0~1 → 字段值 = value × 上限），数值显示跟随
- **flameSettings 缺失时回退读取第一个 FlammableObject 当前值**，面板永不白屏

```cs
private void UpdateView(TaskData obj)
{
    taskData = obj;
    var first = flammableObject;
    TaskData.FlameSettings flameSettings = taskData?.flameSettings;
    if (flameSettings == null && first == null) return;   // 双空兜底

    // settings 存在 → 用任务配置初始值；否则回退到对象当前字段值
    float InitValue(Func<TaskData.FlameSettings, float> fromSettings, Func<FlammableObject, float> fromObject)
        => flameSettings != null ? fromSettings(flameSettings) : fromObject(first);

    SetSlider(slider_FlameHeight, tmp_FlameHeight,
        InitValue(s => s.flameHeight, o => o.flameLength),
        GetDisplayMax("flameLength", flameHeightMax), UnitMeter);
    // ... 其余 10 个滑杆同构
}
```

**确认任务闭环打通**：`ConductTrainingPanel.OnConfirmMission()` = `_fireSetPanel.CaptureConfig()`（11 滑杆当前值写回 `taskData.flameSettings`）→ `_trainingManager.SaveCurrentTask()`（`MockTrainingDataStorage` 落盘 JSON）。配合上述读入方向，形成**「载入读 flameSettings → 面板调参 → Capture 写回 → JSON 保存」双向闭环**。任务 JSON 中 flameSettings 存字段绝对值（如 flameHeight 3.5~8、burnSpeed 0.4~1.5）。
