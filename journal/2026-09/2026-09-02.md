**① SceneContent 房间任务切换 + 玩家传送**：按 `taskData.sceneLayout.roomId` 匹配 RoomBinding → Destroy 旧房 → Instantiate 新房到 `_roomRoot`；玩家传送用 **CharacterController 先禁用 → SetPositionAndRotation → 再启用**（禁用在传送瞬间避免控制器碰撞体与房间碰撞体挤压弹飞）：

```cs
CharacterController characterController = _player.GetComponent<CharacterController>();
characterController.enabled = false;
_player.SetPositionAndRotation(_currentRoom.PlayerSpawnPoint.position, _currentRoom.PlayerSpawnPoint.rotation);
characterController.enabled = true;
```

**③ 模型选择横向翻页**：PlaceableCategory 六分类（Fire/VirtualStep/InjuredPerson/TrappedPerson/ValuableItem/Explosive）Toggle 过滤 → 动态生成 `PlaceableModelOption`（首项默认选中）→ **ScrollRect 分页翻模型**：前后按钮按 `_modelScrollStep=0.5` 步进，`DOKill` 防连点叠动 + `DOHorizontalNormalizedPos` 带动画 + `SetUpdate(true)` 无视 timeScale + `SetLink` 防对象销毁后动画泄漏；列表重建后 `Canvas.ForceUpdateCanvases()` 强制布局。

```cs
_targetModelScrollPosition = Mathf.Clamp01(_targetModelScrollPosition + offset);
_modelScrollRect.DOKill();
_modelScrollRect.DOHorizontalNormalizedPos(_targetModelScrollPosition, _modelScrollDuration)
    .SetEase(Ease.OutCubic).SetUpdate(true).SetLink(_modelScrollRect.gameObject);
```
