### FireSim_URP_VR — VerticalBackPack 竖向装备背包（泛型基类二次复用）

路径：`Assets/Scripts/Author/Wt/UI/WristUI/VerticalBackPack/`（VerticalBackPack.cs + VerticalBackPackItem.cs 新增）

问题：装备选择此前只有 StepBackPack（横向步进方案），需要竖向列表式装备选择，且要复用 8-05 泛型化的 WristStepPanel 基类，避免重写步进逻辑。

实现：
```cs
public class VerticalBackPack : WristStepPanel<EquipDefinition, VerticalBackPackItem>
{
    protected override void CreatItems()
    {
        itemDict = new Dictionary<EquipDefinition, VerticalBackPackItem>();
        itemList = new List<VerticalBackPackItem>();
        var prefab = Resources.Load<VerticalBackPackItem>(ITEM_PREFAB_PATH);
        foreach (var equipDefinition in dataList)
        {
            var go = Instantiate(prefab, content);
            go.equip = equipDefinition;
            go.SetData(equipDefinition);              // icon / tmp_Name / tmp_Desc
            go.tmp_Num.text = (_index + 1).ToString();
            itemList.Add(go);
            itemDict.Add(equipDefinition, go);
        }
        tmp_EquipCount.text = $"工具总数:{_index}";
    }

    public override void Confirm()
    {
        var chooseEquip = itemList[index].equip;
        onChooseData?.Invoke(chooseEquip);
        foreach (var kv in itemDict)
            kv.Value.img_Status.gameObject.SetActive(false);   // 清空全部勾选
        itemDict[chooseEquip].img_Status.gameObject.SetActive(true);
        itemDict[chooseEquip].img_Status.sprite = sprite_Choose;
    }

    protected override void Highlight(int _index)
    {
        foreach (var item in itemDict)
            item.Value.img_bg.color = originColor;
        itemList[_index].img_bg.color = new Color(originColor.r, originColor.g, originColor.b, 0.5f);  // 半透明高亮
    }
}
```
要点：
- 基类 `WristStepPanel<TData,TItem>`（8-05 泛型化）提供 Init/CreatItems/Highlight/Confirm 虚方法 + 步进算法（边界判断 IsOnRight/LeftBoundary → StepScrollView 联动），子类只覆写数据绑定与高亮策略 → 竖向/横向背包一套逻辑
- item 用 `[NonSerialized] public EquipDefinition equip` 运行时赋值，避免被序列化
- 高亮策略 = 背景色透明度 0.5（区别于 StepBackPack 的 DOScale 放大 1.2 + Ease.OutBack）
- Init 里 `countOfItemInView = stepScrollView.countOfItemInView` → `SetMaxStep(countOfItemInView-1)`：最后一个 item 停在 Viewport 最右/最底

### FireSim_URP_VR — StepScrollView ForceSnapToIndex 防错位兜底

路径：`Assets/Scripts/Author/Wt/UI/StepScrollView.cs`

问题：DOTween 滚动动画偶发累积错位（多次快速步进后 content 停在非整数槽位，无法精确对齐 item）。

根因：动画时长内快速连续 StepNext/StepPrev，旧 tween 与新 tween 竞争 content 位置，最终停在动画中途的浮点位置。

修复：
```cs
content.DOKill(true);
content.DOAnchorPos(pos, animTime)
    .SetEase(Ease.OutCubic)
    .OnComplete(() => ForceSnapToIndex());   // 动画结束强制对齐，兜住概率错位

/// <summary>强制校正 Content 到精确的绝对位置（无动画）；出错错位后调用兜底</summary>
public void ForceSnapToIndex(int index = -1)
{
    if (index >= 0)
    {
        stepIndex = Mathf.Clamp(index, 0, Mathf.Max(0, maxStepIndex));
        CurrentIndex = stepIndex;
    }
    float target = Mathf.Clamp(stepIndex * m_StepSize, m_OriginalOffset, m_MaxOffset);
    Vector2 pos = content.anchoredPosition;
    SetAxisPos(ref pos, target);
    content.DOKill(true);            // 杀动画，防止继续拉扯
    content.anchoredPosition = pos;  // 瞬移到精确位置
}
```
- 新增 `ForceSnapToIndex`：DOKill + anchoredPosition 瞬移到 `stepIndex * m_StepSize` 精确绝对位置
- `SetMaxStep` 增强：当前 stepIndex 超过新 maxStepIndex 时自动拉回
- Awake 强制 `scrollRect.movementType = ScrollRect.MovementType.Unrestricted`（呼应 Day17 Q6：无限回绕必须无边界；Clamped 会卡死循环）
