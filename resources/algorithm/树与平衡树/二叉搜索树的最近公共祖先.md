# 二叉搜索树的最近公共祖先

对应 **剑指 Offer 68-I / LeetCode 235**。

> 题面：给定一个**二叉搜索树**，找到该树中两个指定节点 `p`、`q` 的最近公共祖先（LCA）。
> 最近公共祖先的定义：对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（**一个节点也可以是它自己的祖先**）。

## 一、核心认知：LCA = p 和 q 第一次被「分开」的节点

BST 的有序性让你在任意节点 `cur` 上立刻判断 p、q 的位置关系：

| 情况 | 含义 | 动作 |
| --- | --- | --- |
| `p->val < cur->val && q->val < cur->val` | p、q **都在左子树** | LCA 一定在左边 → `cur = cur->left` |
| `p->val > cur->val && q->val > cur->val` | p、q **都在右子树** | LCA 一定在右边 → `cur = cur->right` |
| **其余情况** | 一左一右，或其中一个就是 `cur` | **`cur` 就是 LCA** |

「其余情况」正好覆盖两种终局：

1. **p、q 分居两侧** → `cur` 是它们的分叉点
2. **`cur == p` 或 `cur == q`** → 其中一个就是另一个的祖先，`cur` 是 LCA

以 `p = 3, q = 5` 为例（树：`6 / 2,8 / 0,4,7,9 / 3,5` 挂在 4 下）：

```
① 节点 6：3 < 6，5 < 6 → 都在左边 → 走 2
② 节点 2：3 > 2，5 > 2 → 都在右边 → 走 4
③ 节点 4：3 < 4，5 > 4 → 首次分叉 → 返回 4
```

**关键：整个过程不需要记住走过的路** —— 因为每一步都知道该往哪边，**分叉点一到就停**。

## 二、解法一：BST 分流法（首选）

```cpp
// 迭代版（O(h) 时间 / O(1) 空间）
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    TreeNode* cur = root;
    while (cur) {
        if (p->val < cur->val && q->val < cur->val)        cur = cur->left;
        else if (p->val > cur->val && q->val > cur->val)   cur = cur->right;
        else return cur;                 // 分叉点，或 p/q 本身就是 cur
    }
    return nullptr;
}
```

```cpp
// 递归版（更短，但多了递归栈）
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root) return nullptr;
    if (p->val < root->val && q->val < root->val)
        return lowestCommonAncestor(root->left, p, q);
    if (p->val > root->val && q->val > root->val)
        return lowestCommonAncestor(root->right, p, q);
    return root;
}
```

### 必须记住的点

**① 三个分支的顺序不能换，也不能写成四个**

不需要单独处理「`cur == p`」或「`cur == q`」—— 它们天然落进 `else` 分支并返回 `cur`，这正好符合「节点可以是自己的祖先」的定义。

**② 用「都小于 / 都大于」而不是「<= / >=」**

写成 `<=` / `>=` 会在 p 或 q 恰好等于 `cur->val` 时多走一步，虽不一定错，但逻辑绕。用严格不等号 + `else` 兜底最清晰。

**③ 空间是 `O(1)`**

迭代版只用了 `cur` 一个指针 —— 这是本题相对「路径法」最大的优势。

## 三、解法二：路径法（存两条根路径求交集）

这是**通用二叉树 LCA** 的经典做法，在 BST 上也能用：

```cpp
vector<TreeNode*> getPath(TreeNode* root, TreeNode* target) {
    vector<TreeNode*> path;
    TreeNode* cur = root;
    while (cur) {
        path.push_back(cur);
        if (cur == target) break;
        cur = (target->val < cur->val) ? cur->left : cur->right;
    }
    return path;
}

TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    auto a = getPath(root, p);
    auto b = getPath(root, q);
    TreeNode* lca = nullptr;
    for (int i = 0; i < min(a.size(), b.size()) && a[i] == b[i]; ++i)
        lca = a[i];                    // 记录最后一个公共节点
    return lca;
}
```

### ⚠️ 表述要精修：「最深」不是「值最接近」

很容易把结论说成「求**值最接近**的交集」，这是**错的**。

准确说法：**两条根路径的公共部分一定是从根开始的连续前缀，取这个前缀里最深（最后一个）的节点。**

- 「**交集**」这个说法是准的 ✔
- 「**值最接近**」要改成「**最深 / 最后一个**」 ✔

反例感受一下：`p=3, q=5`，值最接近的两个节点就是 3 和 5 本身，但 LCA 是 `4` —— 跟「值差最小」毫无关系。

### 路径法的实现坑

| 坑 | 说明 |
| --- | --- |
| 用 `val` 比较而非指针 | 应写 `a[i] == b[i]`（指针相等），BST 一般无重复值，但指针比较才严谨 |
| 忘记 `min(a.size(), b.size())` | 两条路径长度通常不同，直接按一条遍历会越界 |
| 循环条件写错 | 必须「**遇到第一个不相等的就 break**」，不能继续往后找 |

## 四、两种解法对比

| | 路径法 | BST 分流法 |
| --- | --- | --- |
| 时间 | `O(h)` 搜两次 + `O(h)` 比较 | **`O(h)` 一次遍历** |
| 空间 | `O(h)`（两条路径） | **`O(1)`** |
| 适用 | **任意二叉树**（可泛化到 LC236） | 仅 BST |
| 代码量 | ~20 行 | ~8 行 |
| 本质 | **先记路，再回头比较** | **边走边判，分叉即停** |

**为什么 BST 能省掉「记忆」**：因为有序性让每一步都能**预知** p、q 该往哪边走，不需要回看历史。路径法是「事后比较」，分流法是「事中判断」。

> 💡 路径法最大的价值不是解这道题，而是它**能泛化到普通二叉树**。

## 五、延伸：普通二叉树的 LCA（LC236）

BST 的性质没了，只能靠**后序自底向上**：

```cpp
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root || root == p || root == q) return root;      // 命中或到底
    TreeNode* l = lowestCommonAncestor(root->left,  p, q);
    TreeNode* r = lowestCommonAncestor(root->right, p, q);
    if (l && r) return root;        // p、q 分居两侧 → root 是 LCA
    return l ? l : r;               // 都在同一侧 → 返回非空的那个
}
```

**与 BST 版的对照**：

| | BST 版 | 普通二叉树版 |
| --- | --- | --- |
| 思路 | 从上往下走，分叉即停 | 从下往上汇，左右都非空即答案 |
| 方向 | **自顶向下** | **自底向上（后序）** |
| 时间 | `O(h)` | `O(n)`（必须看完整棵树） |
| 为什么 | 有序性能预判方向 | 无序只能全树搜索 |

## 六、易错点

1. **把「分叉判断」写成 `<=` / `>=`** → 逻辑变绕，且容易漏掉 p 或 q 本身是 cur 的情况
2. **只处理「都在左/都在右」，忘了 else 兜底** → 函数没有返回值路径
3. **路径法用 `val` 比较而非指针** → 有重复值时误判
4. **路径法忘记取 `min(size)`** → 越界
5. **表述成「值最接近」** → 概念错误，正确是「最深 / 最后一个公共节点」
6. **误以为 BST 版也能处理普通二叉树** → 它依赖有序性，换普通二叉树必须改用后序

## 七、复杂度

| 解法 | 时间 | 空间 |
| --- | --- | --- |
| BST 分流（迭代） | `O(h)`，最坏 `O(n)`（退化成链） | **`O(1)`** |
| BST 分流（递归） | `O(h)` | `O(h)` 递归栈 |
| 路径法 | `O(h)` | `O(h)` 两条路径 |
| 普通二叉树（LC236） | `O(n)` | `O(h)` |

## 八、面试延伸

- **「p 或 q 不在树里怎么办」** → 标准题面保证都在；若不确定，需要先各搜一次确认存在
- **「p、q 允许相同吗」** → 允许，此时 LCA 就是 p 本身（`else` 分支自然返回）
- **「如果是普通二叉树」** → 换成后序版 LC236，`O(n)`
- **「BST 里找 k 个节点的 LCA」** → 取 `min(k 个值)` 与 `max(k 个值)`，问题归约为两个节点
- **「LCA 有什么用」** → 树上的「路径交点」、距离计算（`dist(u,v) = depth(u)+depth(v)-2·depth(lca)`）、离线 RMQ 等
