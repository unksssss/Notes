# 判断完全二叉树

对应 **LeetCode 958. Check Completeness of a Binary Tree**。

> 题面：给定一棵二叉树，判断它是否是完全二叉树。
> 完全二叉树的定义见 [[完全二叉树]]：除最后一层外每层填满，最后一层节点**全部靠左连续**。

## 一、核心认知

完全二叉树的定义等价于：**层序编号 `1..n` 后位置恰好占满、中间无空洞。**

于是有两条等价的判定思路：

1. **「断层」视角**：层序遍历时，**一旦出现过空位，后面就不允许再出现非空节点**。
2. **「编号」视角**：层序编号后，**最大编号恰好等于节点总数**。

第 1 条好写，第 2 条更能说明本质。

### ⚠️ 表述必须精修：不是「节点连续非空」

很多人会把这条记成「**层序里节点连续非空就是完全二叉树**」—— 这是**错的**，按字面理解会滑向**满二叉树**。

反证：**单节点树 `1`** 的层序序列是 `[1, ∅, ∅]`，明明有空位，却是最简单的完全二叉树。因为**叶子节点的孩子必然是空**，所以任何非空树都一定有空位。

**准确说法**：

> 层序序列（含空位）必须是 **「非空前缀 + 空后缀」** —— **空位只能堆在末尾，不能夹在中间**。

即形如 `[非空 × k] + [空 × m]`。一旦出现第一个 `∅`，后面就不许再有任何节点「回流」。这也正是代码里 `seenEmpty` 标志的全部意义。

```
完全 ✓    1  2  3  4  ∅  ∅  ∅  ∅
非完全 ✗  1  2  ∅  ∅  5  6  ∅  ∅     ← ∅ 之后又冒出 5、6 = 回流
```

| 记忆法 | 准确度 |
| --- | --- |
| 「节点连续非空」 | ⚠️ 字面会滑向满二叉树 |
| 「空位之后不能再有节点」 | ✅ 准确 |
| 「层序序列 = 非空前缀 + 空后缀」 | ✅✅ 最精确，最好自查 |


## 二、解法一：BFS + 空节点标记（首选）

```cpp
bool isComplete(TreeNode* root) {
    if (!root) return true;                          // 空树视为完全二叉树
    queue<TreeNode*> q;
    q.push(root);
    bool seenEmpty = false;                          // 是否已经遇到过空位
    while (!q.empty()) {
        TreeNode* node = q.front(); q.pop();

        if (!node) { seenEmpty = true; continue; }    // ① 是空位：打标记，继续
        if (seenEmpty) return false;                  // ② 空位之后又出现节点 → 不是

        q.push(node->left);                           // ③ ★ 不判空，nullptr 也入队
        q.push(node->right);
    }
    return true;
}
```

### 执行过程示例

树（非完全，`2` 的两个孩子都缺）：

```
        1
       / \
      2   3
         / \
        6   7
```

| 步骤 | 队列 | 说明 |
| --- | --- | --- |
| ① 初始 | `[1]` | |
| ② 弹出 1 | `[2, 3]` | 两个非空孩子入队 |
| ③ 弹出 2 | `[3, 空, 空]` | **首次出现空位** |
| ④ 弹出 3 | `[空, 空, 6, 7]` | |
| ⑤ 弹出 空 | `[空, 6, 7]` | `seenEmpty = true` |
| ⑥ 弹出 6 | — | 空之后又非空 → **`return false`** |

## 三、⚠️ 唯一的坑，也是最要命的坑

```cpp
// ❌ 习惯性写成「判空再入队」
if (node->left)  q.push(node->left);
if (node->right) q.push(node->right);
```

队列里就**永远只有非空节点** → `if (!node)` 分支永不触发 → `seenEmpty` 永远是 `false` → **函数恒返回 `true`**。

这和 [[验证二叉搜索树]] 迭代版的 `cur && !st.empty()` 是**同一类错误**：不崩、不报错、语法完全合法，只是结果永远错。**静默失效**，比空指针难查得多。

> 记忆点：**本题是全库唯一「故意把 `nullptr` 入队」的 BFS** —— 空指针在这里是**断层标记**，不是噪音。

另外两处小坑：

| 坑 | 后果 |
| --- | --- |
| 处理空节点用 `break` 而非 `continue` | 直接跳出循环 → 没检查完就 `return true` |
| 编号法用 `int` 存下标 | 深树时 `idx` 溢出 → 用 `long long` |

## 四、解法二：层序编号（判据更漂亮）

```cpp
bool isComplete(TreeNode* root) {
    if (!root) return true;
    queue<pair<TreeNode*, long long>> q;
    q.push({root, 1});
    long long count = 0, maxIdx = 0;
    while (!q.empty()) {
        auto [node, idx] = q.front(); q.pop();
        ++count;
        maxIdx = max(maxIdx, idx);
        if (node->left)  q.push({node->left,  idx * 2});      // 左 = 2i
        if (node->right) q.push({node->right, idx * 2 + 1});  // 右 = 2i+1
    }
    return maxIdx == count;      // 完全 ⇔ 最大下标恰好等于节点数
}
```

**为什么成立**：完全二叉树的定义就是「编号 `1..n` 全被占满」，所以**最大编号必然 = n = 节点数**。中间只要有洞，某个节点的编号就会超过 `n`。

例：上面那棵树，编号为 `1, 2, 3, 6, 7` —— 节点数 5，最大编号 7，`7 ≠ 5` → 非完全 ✔

### 优点

**完全不需要 `seenEmpty` 状态**，判据直接对应定义，逻辑更本质。缺点是要多存一个 `idx`，且要注意溢出。

## 五、两种解法对比

| | 空节点标记法 | 层序编号法 |
| --- | --- | --- |
| 核心 | 空位之后不能再有节点 | `maxIdx == n` |
| 额外状态 | `seenEmpty` 布尔 | `count` + `maxIdx` |
| 需要 `nullptr` 入队 | **必须**（否则失效） | 不需要 |
| 代码量 | 更短 | 略长 |
| 溢出风险 | 无 | `idx` 用 `long long` |
| 推荐 | ★★★ 首选 | ★★ 说出判据更显功底 |

## 六、为什么不推荐递归

完全二叉树**没有简洁的递归判据** —— 递归必须同时知道「左侧是否已出现缺口」和「当前处于第几层」，得返回 `(是否完全, 高度)` 这类复合状态，写起来比 BFS 绕得多。

**这题是少数「迭代天然优于递归」的树形题。** 对比 [[对称的二叉树]]、[[合并二叉树]] 这类双参递归题，本题的递归反而别扭。

## 七、易错点

1. **判空再入队**（`if (node->left) q.push(...)`）→ `seenEmpty` 永不触发 → **恒返回 true**
2. 处理空节点用 `break` → 提前跳出，返回 true
3. `if (seenEmpty) return false;` 的位置放到 `continue` 之后 → 永远不会执行
4. 空树未处理 → 有的写法会对 `root->left` 解引用崩
5. 编号法用 `int` 存下标 → 溢出
6. 编号法起点写成 0（`q.push({root, 0})`）→ `maxIdx == count` 判据不再成立（需改为 `maxIdx == count - 1`）

## 八、复杂度

| 维度 | 值 |
| --- | --- |
| 时间 | **O(n)**，每个节点访问一次 |
| 空间 | **O(n)** —— 因为 `nullptr` 也入队占位，队内元素最多约为节点数 |

> ⚠️ 注意空间**不是 `O(h)`**：普通 BFS 队列最多存一层（约 `n/2`），但这里空指针也占位，所以是实打实的 `O(n)`。

## 九、面试延伸

- **「和判断满二叉树有什么区别」** → 满二叉树：每层都满，节点数恰好 `2^h − 1`；只需算高度和节点数
- **「怎么判断平衡二叉树」** → [[二叉平衡树AVL]] 里的 `|bf| ≤ 1`，后序递归返回高度
- **「完全二叉树有多少个节点」** → LeetCode 222，利用「左右子树高度相同则左子树必满」做到 `O(log²n)`
- **「用完全二叉树性质做堆」** → 数组连续存储，见 [[完全二叉树]]
- **为什么这题适合 BFS 不适合 DFS** → 完全性是**层序**性质，DFS 天然不按层走，得额外记录层级与缺口状态
