# 排序算法：快排 / 归并 / 堆排

## 对比总览（必背）

| 算法 | 平均时间 | 最坏时间 | 额外空间 | 稳定 | 特点 |
|------|---------|---------|---------|------|------|
| 快排 | O(n log n) | **O(n²)** | O(log n) | ❌ | 平均最快，怕有序数组 |
| 归并 | O(n log n) | O(n log n) | **O(n)** | ✅ | 稳定，适合外部排序 |
| 堆排 | O(n log n) | O(n log n) | **O(1)** | ❌ | 省内存，常数大实际慢 |

> **记忆口诀**：快排快但怕有序、归并稳但费内存、堆排省内存但慢常数。

## 1. 快速排序（平均之王）

**思想**：分治三步走
1. 选基准（pivot）
2. 分区：比基准小的放左边、大的放右边（基准归位）
3. 递归对左右子区间重复

**复杂度**：
- 平均 O(n log n)：分区大致对半，递归 log n 层，每层扫 n 个元素
- **最坏 O(n²)**：已有序数组 + 固定取末尾基准 → 每次只切出一边，递归深度退化为 n
- 空间 O(log n)（递归调用栈），**最坏退化为 O(n)**

**⚡ 最经典的坑：不稳定！**
交换时相等元素相对顺序可能被打乱：`[3a, 3b, 1]` → `[1, 3b, 3a]`

**优化**：随机选基准 / 三数取中，把最坏情况概率压到几乎为零。

## 2. 归并排序（稳定暖男）

**思想**：分治（和快排相反顺序）
1. 数组对半拆，拆到单元素（天然有序）
2. 两两合并：双指针从小到大归并成有序区间

**复杂度**：
- 时间稳定 O(n log n)，任何输入都不退化
- 空间 O(n)：合并需要辅助数组
- **稳定**：合并时相等元素先取左半边

**适用**：外部排序（数据大到内存装不下）、链表排序（顺序访问，天然适配归并）。

## 3. 堆排序（省内存硬汉）

**思想**：数组表示完全二叉树（大顶堆：父 ≥ 子）
1. **建堆**：乱序数组调整成大顶堆，堆顶 = 最大值
2. **排序**：堆顶与末尾交换 → 堆大小减 1 → 堆顶下沉（sift down）恢复堆性质
3. 重复直到堆空

**复杂度**：
- 最坏也 O(n log n)，输入好坏都稳定
- 空间 O(1)：原地排序
- **不稳定**：交换堆顶/末尾时相等元素相对顺序可能变

**缺点**：常数大、cache 不友好（跳跃访问），工程上通常比快排慢。

## 面试高频题

1. **快排为什么最坏是 O(n²)？** → 每次基准都是最值，分区退化成每次只去掉一个元素，递归深度 n
2. **哪个排序稳定？** → 归并 ✅；快排/堆排 ❌
3. **排序大文件用哪个？** → 归并（外部排序，分段读入内存归并）
4. **要求 O(1) 空间 + 保证最坏 O(n log n)？** → 堆排
