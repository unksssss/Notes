#### 今日新增：NiloToon URP 卡通描边着色器

目标路径：`Assets/shader/`
- `SimpleURPToonLitOutlineExample.shader`（34 KB，主着色器）
- `SimpleURPToonLitOutlineExample_Shared.hlsl`（22 KB，顶点/片元共用逻辑）
- `SimpleURPToonLitOutlineExample_LightingEquation.hlsl`（3.6 KB，卡通光照方程）
- `NiloOutlineUtil.hlsl`（2.0 KB，线宽补偿）
- `NiloZOffset.hlsl`（1.5 KB，深度偏移）
- `NiloInvLerpRemap.hlsl`（0.7 KB，`invLerp` / remap 工具）

**着色器结构：五个 Pass**

```hlsl
// 本体
Name "ForwardLit"   ZWrite On   Cull Off    ZTest LEqual
// 描边
Name "Outline"      ZWrite On   Cull Front  ZTest LEqual   // ← Cull Front 是硬要求
// 深度/法线类
Name "ShadowCaster"       Cull Off   // + ToonShaderApplyShadowBiasFix
Name "DepthOnly"          Cull Off
Name "DepthNormalsOnly"   Cull Off
```

后三个 Pass 里同样 `#define ToonShaderIsOutline`，让**描边区也写进深度与法线**；否则 SSAO、深度雾、屏幕后处理里描边会凭空消失。

**关键代码 1 · 屏幕恒定线宽**

```hlsl
// Shared.hlsl:151
float3 TransformPositionWSToOutlinePositionWS(float3 positionWS, float positionVS_Z, float3 normalWS)
{
    float outlineExpandAmount = _OutlineWidth * GetOutlineCameraFovAndDistanceFixMultiplier(positionVS_Z);
    #if defined(UNITY_STEREO_INSTANCING_ENABLED) || ...   // VR 单眼
        outlineExpandAmount *= 0.5;
    #endif
    return positionWS + normalWS * outlineExpandAmount;
}
```

```hlsl
// NiloOutlineUtil.hlsl
float GetCameraFOV() {
    float t = unity_CameraProjection._m11;          // = 1 / tan(fovY/2)
    return atan(1.0 / t) * 2.0 * (180 / 3.1415);    // 反解整 FOV（角度）
}

float GetOutlineCameraFovAndDistanceFixMultiplier(float positionVS_Z) {
    float cameraMulFix;
    if (unity_OrthoParams.w == 0) {                 // 透视
        cameraMulFix = abs(positionVS_Z);           // 距离越远，世界偏移越大
        cameraMulFix = saturate(cameraMulFix);      // 近处淡出，别爆粗
        cameraMulFix *= GetCameraFOV();             // FOV 越大，偏移越大
    } else {                                        // 正交
        float orthoSize = abs(unity_OrthoParams.y);
        orthoSize = ApplyOutlineDistanceFadeOut(orthoSize);
        cameraMulFix = orthoSize * 50;              // 50 = 对齐透视观感的魔法数
    }
    return cameraMulFix * 0.00005;                  // 收进默认外扩量级
}
```

**为什么这么写**：世界空间固定偏移在屏幕上**不是固定宽度**（相机拉远变细、FOV 变大变细），卡通渲染要求线宽像手绘一样稳定，所以必须乘 `|viewSpaceZ| × FOV`。注意取的是**视空间 Z**，不是 clip 空间 z（clip z 是非线性的，直接乘会畸变）。

**关键代码 2 · ZOffset 只改 clipZ，不动几何**

```hlsl
// NiloZOffset.hlsl
float4 NiloGetNewClipPosWithZOffset(float4 originalPositionCS, float viewSpaceZOffsetAmount)
{
    if (unity_OrthoParams.w == 0) {
        float2 ProjM_ZRow_ZW = UNITY_MATRIX_P[2].zw;
        float modifiedPositionVS_Z = -originalPositionCS.w + -viewSpaceZOffsetAmount;   // w = -z_view
        float modifiedPositionCS_Z = modifiedPositionVS_Z * ProjM_ZRow_ZW[0] + ProjM_ZRow_ZW[1];
        originalPositionCS.z = modifiedPositionCS_Z * originalPositionCS.w / (-modifiedPositionVS_Z);
        return originalPositionCS;
    } else {
        originalPositionCS.z += -viewSpaceZOffsetAmount / _ProjectionParams.z;
        return originalPositionCS;
    }
}
```

应用处（`Shared.hlsl:204~217`）：

```hlsl
float outlineZOffsetMask = tex2Dlod(_OutlineZOffsetMaskTex,
        float4(input.uv, 0, 0)).r;                       // 顶点着色器必须 tex2Dlod
outlineZOffsetMask = 1 - outlineZOffsetMask;             // 约定：黑 = 应用偏移
outlineZOffsetMask = invLerpClamp(_OutlineZOffsetMaskRemapStart, _OutlineZOffsetMaskRemapEnd, outlineZOffsetMask);
output.positionCS = NiloGetNewClipPosWithZOffset(
        output.positionCS,
        _OutlineZOffset * outlineZOffsetMask + 0.03 * _IsFace);   // 脸部再硬推一点
```

**为什么这么写**：脸部（鼻子、下巴、眼皮）法线变化剧烈，外扩后的背面会从脸内部透出来，在额头糊出黑线。ZOffset 把描边顶点在**深度上**往相机推一点，`xy` 完全不动 —— 视觉效果上「描边被本体挡住」，几何一点没改。参数默认 `_OutlineZOffset = 0.0001`（`Range(0,1)`），`_IsFace` 是 `[ToggleUI]` 材质开关，用 `0.03` 的魔法数专门压掉脸部穿插。

> ⚠️ 顶点着色器不能用 `tex2D`（`ddx/ddy` 在光栅化前不存在），必须 `tex2Dlod` 并显式给 mip level。

**已知代价**（着色器注释自己承认的）
- 每个材质多 1 个 Pass → DrawCall 翻倍，且这个教学版 Outline Pass **不是 SRP Batcher 友好**（没写 C# 侧常量缓冲设置）
- 外扩依赖平滑法线 → 硬边低模会在接缝处裂口；顶点级外扩会让圆轮廓棱角化

> 完整拆解已归档：📎 [[URP 卡通描边 — 法线外扩与 ZOffset]]（含与屏幕后处理 Sobel 方案的对照表）
