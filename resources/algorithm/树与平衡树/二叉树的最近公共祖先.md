# 二叉树的最近公共祖先

对应 **剑指 Offer 68-II / LeetCode 236**。

> 题面：给定一个**普通二叉树**（不保证是 BST），找到该树中两个指定节点 `p`、`q` 的最近公共祖先。
> 说明：一个节点也可以是它自己的祖先；所有节点的值互不相同；p、q 均存在于树中。

## 一、核心认知：返回值是「混合语义」

先看清 `dfs(root)` 到底返回什么 —— 这是理解整段代码的关键：

> **在以 `root` 为根的子树里，找到的那个 `p` 或 `q`；如果两个都已经找到、且它们的 LCA 已经确定，就返回那个 LCA；一个都没找到就返回 `nullptr`。**

所以返回值**不一定是 LCA**，可能只是「命中的那个节点」。真正的判定在**上层**完成。

## 二、解法：后序自底向上（唯一推荐）

```cpp
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (!root || root == p || root == q) return root;   // ① 到底，或命中目标

        TreeNode* left  = lowestCommonAncestor(root->left,  p, q);
        TreeNode* right = lowestCommonAncestor(root->right, p, q);

        if (left && right) return root;                     // ② 两侧都有 → root 是分叉点
        return left ? left : right;                         // ③ 都在同一侧 → 往上送
    }
};
```

### 三种情况

| `left` / `right` | 含义 | 返回 |
| --- | --- | --- |
| 都非空 | p、q **分居两侧** → `root` 就是分叉点 | `root` |
| 只有一侧非空 | p、q **都在那一侧**（或只在那边找到） | 那一侧的值 |
| 都为空 | 这棵子树里 **p、q 都没有** | `nullptr`（`left ? left : right` 自然返回 `right` 即空） |

### 为什么「命中就返回自己」是对的

因为**节点可以是它自己的祖先**。若 `p` 是 `q` 的祖先，递归走到 `p` 时直接返回 `p` —— 它正是 LCA，**不需要**继续到 `p` 的子树里找 `q`。

反过来，如果非要在命中后继续往下找，结果也一样（最终还是会回到 `p`），只是白跑。

### 推演示例

树：

```
        3
       / \
      5   1
     / \ / \
    6  2 0  8
      / \
     7   4
```

`p = 7, q = 4`：

```
7 返回 7，4 返回 4
→ 节点 2：左右都非空 → 返回 2（即 LCA）★
→ 节点 5：左 6 返回 null、右 2 返回 2 → 只有右侧非空 → 把 2 原样往上送
→ 节点 1：两侧都空 → 返回 null
→ 节点 3：左 2 非空、右 null → 返回 2 ✔
```

## 三、必须记住的点

**① 必须后序（先递归左右，再判断）**

判定「左右两侧都有」的前提是**已经拿到两侧的返回值**。放前序位置就无从判断。

**② `root == p || root == q` 时直接返回 `root`**

不要写成「先递归再看命中」。命中是一个**终止条件**，不是判断条件。

**③ 用指针比较，不用 `val`**

题面保证「所有节点的值互不相同」，但 `root == p` 是**指针比较**，语义更严谨；用 `val` 在有重复值的变体题里会错。

**④ 空间上不去优化**

递归深度是树高，`O(h)`。**无法做到 `O(1)`** —— 因为需要回溯信息。

## 四、备选：DFS 求路径法

上一题的「存路径」思路在普通二叉树上依然可用，但**求路径的方式必须改**：不能按值定方向，要全树 DFS + **回溯**。

```cpp
bool getPath(TreeNode* root, TreeNode* target, vector<TreeNode*>& path) {
    if (!root) return false;
    path.push_back(root);
    if (root == target) return true;                     // 找到了，保留路径
    if (getPath(root->left,  target, path) ||
        getPath(root->right, target, path)) return true; // 任一子树找到即可
    path.pop_back();                                     // ★ 回溯：这条分支没找到，撤销
    return false;
}

TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    vector<TreeNode*> a, b;
    getPath(root, p, a);
    getPath(root, q, b);
    TreeNode* lca = nullptr;
    for (int i = 0; i < min(a.size(), b.size()) && a[i] == b[i]; ++i)
        lca = a[i];                                      // 最后一个公共节点
    return lca;
}
```

**`pop_back()` 不能省** —— 否则没找到的分支也会留在路径里，交集的最后一个节点就错了。

| | 后序递归版 | 路径法 |
| --- | --- | --- |
| 时间 | `O(n)` | `O(n)`（两次 DFS） |
| 空间 | `O(h)` 递归栈 | `O(h)` 两条路径 |
| 代码量 | 8 行 | ~18 行 |
| 推荐 | ★★★ | ★★ 思路直观，适合讲清「LCA 是什么」 |

## 五、与 BST 版（LC235）的对照

| | BST 版 LC235 | **普通二叉树版 LC236** |
| --- | --- | --- |
| 方向 | **自顶向下**，分叉即停 | **自底向上**，汇合即答案 |
| 时间 | `O(h)` | **`O(n)`** |
| 空间 | **`O(1)`**（迭代版） | `O(h)` 递归栈 |
| 依赖 | 必须有序（BST 性质） | **无** |
| 返回值语义 | 直接就是 LCA | 「找到的节点或 LCA」混合语义 |
| 判定依据 | p、q 是否被分到两侧 | 左右子树是否各自找到了东西 |

**为什么普通版降不到 `O(h)`**：无序意味着到达某个节点前**无法排除任何一侧**，必须两边都搜完才能确定，所以最坏要访问全部 `n` 个节点。

详见 [[二叉搜索树的最近公共祖先]]（那篇管「有有序性时怎么自顶向下」。本文管「没有有序性时怎么自底向上」）。

## 六、易错点

1. **忘记 `root == p \|\| root == q` 就返回** → 会一路找到叶子再返回 `nullptr`
2. **先递归后判命中** → 命中节点被跳过，结果错
3. **用 `val` 比较而非指针** → 有重复值的变体题会误判
4. **路径法忘记 `pop_back()`** → 未命中的分支污染路径
5. **以为返回值一定是 LCA** → 在「只找到一侧」时它只是命中的那个节点，LCA 要在上层才确定
6. **想套 BST 的「按值分流」** → 普通二叉树没有有序性，方向无从判断

## 七、复杂度

| 解法 | 时间 | 空间 |
| --- | --- | --- |
| 后序递归 | `O(n)`（最坏访问全部节点） | `O(h)` 递归栈 |
| 路径法 | `O(n)`（两次 DFS） | `O(h)` × 2 路径 |

> 注：虽然平均情况下命中较早可以提前结束，但**最坏必须 `O(n)`**（p、q 分别在最深的两侧叶子下时）。

## 八、面试延伸

- **「和 BST 版的区别」** → 一句话：**有有序性就能自顶向下 `O(h)`，没有就只能自底向上 `O(n)`**
- **「k 个节点的 LCA」**（LC1676）→ 后序统计每棵子树「命中了几个目标」，**第一个命中数 == k 的节点**就是答案
- **「p、q 可能不在树里怎么办」** → 需要额外记录「找到了几个」，返回前校验 `count == 2`
- **「不用递归怎么写」** → 显式栈后序 + `unordered_map<TreeNode*, TreeNode*>` 记录返回值的传播，代码量陡增，面试一般不必
- **「LCA 有什么用」** → 树上两点距离 `dist(u,v) = depth(u) + depth(v) - 2·depth(lca)`；也是「树上路径交集」类问题的基础

## 九、完整可运行代码（含自测用例）

### 提交版

```cpp
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        // ① 终止：走到空，或命中 p/q（命中即返回，因为节点可以是自己的祖先）
        if (!root || root == p || root == q) return root;

        // ② 后序：先拿到左右子树的结果
        TreeNode* left  = lowestCommonAncestor(root->left,  p, q);
        TreeNode* right = lowestCommonAncestor(root->right, p, q);

        // ③ 左右都非空 → p、q 分居两侧 → root 就是 LCA
        if (left && right) return root;

        // ④ 只有一侧非空 → 那边找到的结果继续往上送；都空则返回 nullptr
        return left ? left : right;
    }
};
```

### 自测版（本地可直接编译运行）

```cpp
#include <iostream>
#include <vector>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (!root || root == p || root == q) return root;
        TreeNode* left  = lowestCommonAncestor(root->left,  p, q);
        TreeNode* right = lowestCommonAncestor(root->right, p, q);
        if (left && right) return root;
        return left ? left : right;
    }
};

const int EMPTY = -999;

// 按层序数组建树（下标 i 的左孩子 2i+1、右孩子 2i+2）
TreeNode* build(const vector<int>& a, int i) {
    if (i >= (int)a.size() || a[i] == EMPTY) return nullptr;
    TreeNode* node = new TreeNode(a[i]);
    node->left  = build(a, 2 * i + 1);
    node->right = build(a, 2 * i + 2);
    return node;
}

TreeNode* findNode(TreeNode* root, int v) {
    if (!root) return nullptr;
    if (root->val == v) return root;
    TreeNode* l = findNode(root->left, v);
    return l ? l : findNode(root->right, v);
}

int main() {
    //        3
    //       / \
    //      5   1
    //     / \ / \
    //    6  2 0  8
    //      / \
    //     7   4
    vector<int> a = {3, 5, 1, 6, 2, 0, 8, EMPTY, EMPTY, 7, 4};
    TreeNode* root = build(a, 0);

    Solution s;
    struct Case { int p, q, expect; const char* note; };
    Case cases[] = {
        {7, 4, 2, "分居节点2两侧"},
        {5, 1, 3, "分居节点3两侧"},
        {5, 4, 5, "5 是 4 的祖先（命中即返回）"},
        {7, 7, 7, "p == q"},
    };

    for (auto& c : cases) {
        TreeNode* ans = s.lowestCommonAncestor(root,
                            findNode(root, c.p), findNode(root, c.q));
        int got = ans ? ans->val : -1;
        cout << "LCA(" << c.p << "," << c.q << ") = " << got
             << "  expect " << c.expect
             << (got == c.expect ? "  [OK]  " : "  [FAIL] ")
             << c.note << endl;
    }
    return 0;
}
```

**预期输出**：

```
LCA(7,4) = 2  expect 2  [OK]  分居节点2两侧
LCA(5,1) = 3  expect 3  [OK]  分居节点3两侧
LCA(5,4) = 5  expect 5  [OK]  5 是 4 的祖先（命中即返回）
LCA(7,7) = 7  expect 7  [OK]  p == q
```

> ✅ **已实测**：MSYS2 UCRT64 + `g++ -std=c++17` 编译无警告，四例全部 `[OK]`，输出与上面完全一致。

**四个用例的覆盖意图**（正好对应四个易错分支）：

| 用例 | 覆盖点 |
| --- | --- |
| `{7, 4}` | 两侧分叉（最常见的路径） |
| `{5, 1}` | 根处直接分叉（第一层就命中） |
| `{5, 4}` | **自己是祖先** —— 验证「命中即返回」 |
| `{7, 7}` | p 与 q 相同 —— 验证 `p == q` 时返回自身 |

### 写代码时的两个自检点

1. **`if (left && right) return root;` 必须在拿到两个返回值之后** —— 放前面就变成前序，判断不了
2. **`return left ? left : right;`** 一句同时处理「只有左」「只有右」「都空」三种情况，不需要写三个分支
