# Firefighting Simulator: Ignite — 灭火机制拆解

## 火灾分类 + 对应灭火介质

| 火灾类型 | 灭火方法 | VR 借鉴 |
|---|---|---|
| **普通火** (Class A) | 水 / 泡沫 / 灭火器 都行 | 你已有灭火器 |
| **电器火** (Class C) | **只能用泡沫**，水导电 | 配电房核心机制 |
| **油脂火** (Class B) | **只能用泡沫**，水会让油飞溅 | 厨房场景可拓展 |
| **燃气火** | **先关阀门**再灭火 | 加燃气阀交互点 |

## 标准灭火流程

```
1. 接水源（消防栓 / 消防车）
2. 破门 → 通风排烟（给烟出路，给火供氧可控）
3. 识别火灾类型（电器？油脂？普通？）
4. 选择对应灭火介质（水 / 泡沫 / 干粉）
5. 正面攻击火源基部（不是烧得最旺的地方）
6. 全面检查 → 热成像仪扫描隐藏高温点（Overhaul）
```

## 关键交互机制

| 机制 | 说明 |
|---|---|
| **水/泡沫切换** | 消防车侧面接口切换介质类型 |
| **燃气阀门** | 沿黄色管道找到阀门关闭后再灭火 |
| **PPV 正压排烟** | 风机架门口 → 开对面窗 → 推烟出去 |
| **热成像复查** | 灭完后 TIC 扫描墙壁发现隐藏热点 |
| **水带管理** | 接消防栓供水，水带会打结需整理 |

## 对我们 VR 项目的启示

已有: 灭火器、热成像、排烟、破门 ✅
可加:

1. **电器火 + 泡沫灭火器** — 配电房核心技术。普通水无效，强制用泡沫
2. **燃气阀门交互** — 灭火前先关阀，增加步骤
3. **火灾类型识别** — 热成像仪区分电弧/普通火特征
4. **多介质切换** — 水/泡沫/CO2，不同场景不同选择
