### 配电房项目 — 背包UI重构：放弃轮播，改用步进式方案

**修改文件：**
- `Assets/Scripts/Author/Wt/UI/StepScrollView.cs` — 步进式 ScrollView 组件核心
- `Assets/Scripts/Author/Wt/UI/WristUI/BackPackPlus/RotateBackPack.cs` — **全部注释掉**（202 行废弃）
- `Assets/Scripts/Author/Wt/UI/WristUI/BackPackPlus/StepBackPack.cs` — 新步进背包控制器
- `Assets/Scripts/Author/Wt/UI/WristUI/BackPackPlus/BackPackItemPlus.cs` — 简化为纯数据持有器

**问题：** 轮播式背包（RotateBackPack）实现过于复杂，轮播算法（CalcX/CalcScale/ShiftAll）与 ToggleGroup 管理耦合，且 VR 环境下滑动操作不直观。需要简化交互模型。

**方案：** 替换为步进式方案（StepBackPack）：
- 参考了原 RotateBackPack 的轮播算法思路，但改用了 StepScrollView 作为底层滚动引擎
- StepScrollView 支持水平/垂直方向自适应、LayoutGroup 间距自动检测、DOTween 动画、loop 循环模式
- StepBackPack 新增 `img_Selected` 选中指示器跟随动画，配合 `selectIndex` 在 Viewport 边界判断是否有 content 位移

**核心改动：**

```cs
// StepScrollView — 步进式滚动核心
public class StepScrollView : MonoBehaviour
{
    [Header("步进参数")]
    public int stepCount = 1;
    public float animTime = 0.3f;
    public bool loop = false;

    public ScrollRect scrollRect;
    public RectTransform content;
    public List<RectTransform> items = new List<RectTransform>();
    public float m_StepSize;
    public int countOfItemInView;

    public void Init() { /* 收集 item、计算步长、计算可见数 */ }
    public void SetMaxStep(int lastItemStopAtViewportIndex)
    {
        // 最后一个 item 停在 Viewport 指定位置
        maxStepIndex = Mathf.Max(0, items.Count - 1 - lastItemStopAtViewportIndex);
    }
    public void StepPrev(bool syncHighlight = true) { /* 防连击 + 步进 */ }
    public void StepNext(bool syncHighlight = true)  { /* 同上 */ }
}
```

```cs
// StepBackPack — 步进背包控制器
private int selectIndex = 0; // 选中指示器在 Viewport 内的索引

public void MoveNext()
{
    // 防连击
    if (Time.unscaledTime - lastClickTime < clickLimitTime) return;

    bool isOnBoundary = IsOnRightBoundary(); // 移动前判断边界
    index = Mathf.Min(index + 1, maxIndex);
    selectIndex = Mathf.Min(selectIndex + 1, countOfItemInView - 1);

    if (!isOnBoundary)
        ApplyStepImg_Select();       // 仅移动选中框
    else
        if (index <= maxIndex) ApplyContentNextStep(); // 滚动 content

    stepScrollView.HighlightItem(index);
}
```

**边界处理逻辑：** `selectIndex` 到达 Viewport 右边界时，content 整体左移一格，选中框不动；到达左边界时 content 右移。这种设计保证了当前选中项始终在 Viewport 可视区域内。

**废弃：** RotateBackPack 全部注释保留，待确认无引用后删除。

### 配电房项目 — PointerMoveTrigger 工具组件

**文件：** `Assets/Scripts/Author/Wt/UI/PointerMoveTrigger.cs`

Unity `EventTrigger` 不支持 `OnPointerMove`，新增一个独立组件弥补：

```cs
public class PointerMoveTrigger : MonoBehaviour, IPointerMoveHandler
{
    public UnityEvent<PointerEventData> onPointerMove;
    public void OnPointerMove(PointerEventData eventData)
    {
        onPointerMove?.Invoke(eventData);
    }
}
```

用法：挂到 UI 上，在 Inspector 绑定回调，与 EventTrigger 用法一致。
