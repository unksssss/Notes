# 链表反转

## 迭代法（三指针，面试首选）

```csharp
public ListNode ReverseList(ListNode head)
{
    ListNode prev = null;
    ListNode curr = head;
    while (curr != null)
    {
        ListNode next = curr.next;  // ① 先保存后继（防断链！）
        curr.next = prev;           // ② 反转指针：指向前一个
        prev = curr;                // ③ prev 前移
        curr = next;                // ④ curr 前移
    }
    return prev;                    // 原链表尾 = 新头
}
```

> ⚠️ **铁律**：① 必须先把 `next` 存下来！否则 `curr.next = prev` 一执行，后面的链表就"断"了，剩余节点全部丢失。

## 递归法（面试加分项）

```csharp
public ListNode ReverseList(ListNode head)
{
    if (head == null || head.next == null) return head;
    ListNode newHead = ReverseList(head.next);  // 递归反转后面的
    head.next.next = head;   // 让下一个节点指回自己
    head.next = null;        // 断开原方向
    return newHead;
}
```

## 复杂度对比（面试常问）

| | 时间复杂度 | 空间复杂度 |
|---|---|---|
| 迭代法 | O(n) | **O(1)** |
| 递归法 | O(n) | **O(n)**（递归栈深度） |

## 快慢指针判环（Floyd 判圈，Day 20 补充）

判断单链表是否有环，**最优解**是快慢指针：

```csharp
bool HasCycle(ListNode head)
{
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null)
    {
        slow = slow.next;        // 慢指针 1 步
        fast = fast.next.next;   // 快指针 2 步
        if (slow == fast) return true;  // 相遇即有环
    }
    return false;
}
```

- 原理：进环后两者**相对速度 1 步**，快指针绕圈迟早追上慢指针
- 复杂度：时间 O(n)、空间 **O(1)**（优于 HashSet 的 O(n) 空间）
- **找环入口**（进阶）：相遇后快指针重置为 head，两指针都改为每次 1 步，**再次相遇处即环入口**
- ⚠️ 反转链表判环不可行——有环时反转会死循环
