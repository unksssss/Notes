# 三角形的最大相邻连通块

## 一、题意

给若干个三角形（每个用 3 个顶点编号表示）。**两个三角形共享一条边（即共享 2 个顶点）就算「相邻」**。求最大的相邻组大小。

```
{0,1,2} 与 {0,2,3}  → 共享 0,2  → 相邻
{0,1,2} 与 {4,5,6}  → 共享 0 个 → 不相邻
{0,1,2} 与 {2,3,4}  → 共享 2 一个 → 不相邻（只共享一个顶点 = 只碰了个角）
```

样例：`{{0,1,2}, {0,2,3}, {4,5,6}, {2,3,4}}`

```
T0-T1 相邻（0,2）    T1-T3 相邻（2,3）
→ 连通块 {T0,T1,T3} 大小 3；{T2} 大小 1
→ 答案 3
```

> ⚠️ 这里要先把「最长」定义清楚。本笔记按 **最大连通块**（组内任意两个三角形能通过一串相邻连起来）来解。若是「最长链」（每个只与前一个相邻）或「最大团」（两两都相邻），解法不同 —— 见第七节。

## 二、灯皇的思路：顺序扫描 + 贪心 + 聚合顶点集

```cpp
vector<int> temp = indexArray[0];
for (int i = 2; i <= n; i++) {
    if (isConnected(temp, indexArray[i-1])) {   // temp 与当前三角形"相邻"
        dp[i] = dp[i-1] + 1;
        temp = AddItem(temp, indexArray[i-1]);   // 顶点合并进 temp
    } else {
        dp[i] = dp[i-1];
    }
}
```

方向是对的（把它看成"能不能接上"），但**这个模型本身撑不起"最大"**。三处独立错误，效果还相反。

## 三、错误 ①：`sameV == 2` 应该是 `>= 2`（主力，造成偏小）

```cpp
return sameV == 2;      // ❌
return sameV >= 2;      // ✅
```

**为什么 `== 2` 会漏？** 因为 `temp` 是**多个三角形顶点并集**，不是单个三角形。一旦 temp 变大，新三角形与它可能共享 **3 个甚至更多**顶点：

```
temp = {0,1,2,3}        ← T0{0,1,2} 与 T1{0,1,3} 合并而来
T    = {0,2,3}
共享 = {0,2,3} 共 3 个  → sameV == 2 为 false → 判"不相邻" ❌
```

但 T 与 T0 共享边 `0-2`、与 T1 共享边 `0-3`，**完全连通**。

最小复现：

```
{{0,1,2}, {0,1,3}, {0,2,3}}
三条边两两相邻（0-1 / 0-2 / 0-3），正确答案 3
你的代码：2
```

## 四、错误 ②：用「聚合顶点集」判断连通（造成偏大）

即使把 `== 2` 改成 `>= 2`，这个设计也不成立。因为**顶点并集丢掉了「这个顶点来自哪个三角形」的信息**，于是两个本来不相邻的三角形可以靠"各贡献一个顶点"拼出 2 个共享：

```
已选： T0 = {0,1,2}，T1 = {2,5,9}     （T0-T1 共享 2，相邻，合并）
temp = {0,1,2,5,9}

新来： T  = {0,9,7}
temp ∩ T = {0,9}  大小 2 → 判"相邻" ❌

实际上：
  T 与 T0 只共享 {0}  → 1 个 → 不相邻
  T 与 T1 只共享 {9}  → 1 个 → 不相邻
  T 跟这一组毫无关系
```

**这就是偏大的 1185 例的来源。**

> **核心认知**：连通性不能用「集合交集大小」来代理。**必须两两判断** —— 每条边（两个三角形之间的关系）是独立的，不能压缩成"整体顶点集"。

## 五、错误 ③：贪心只维护一个聚合体 → 结果依赖输入顺序

即使把前两个都修好，**贪心骨架仍然不成立**。因为它只跟踪**一个** `temp`，跳过某个三角形后就再也不回头看。

实测找一个顺序敏感的例子（把 `==2` 改成 `>=2`、其余不动）：

```
集合：{{1,5,6}, {1,4,6}, {1,3,6}, {0,1,2}}      正确解 = 3

排列 A：{{1,5,6}, {1,4,6}, {1,3,6}, {0,1,2}}  →  得 3  ✅
排列 B：{{0,1,2}, {1,5,6}, {1,4,6}, {1,3,6}}  →  得 1  ❌
```

**同一组数据，只是换了顺序，答案从 3 掉到 1。**

原因：B 里第一个是 `{0,1,2}`，它和后三个都不相邻（只共享顶点 1）。于是 `temp` 永远是 `{0,1,2}`，而后三个 `{1,5,6}/{1,4,6}/{1,3,6}` 彼此共享 `1,6` 构成大小 3 的连通块 —— 全部被漏掉。

> **只要题目要"最大"，单次顺序扫描 + 贪心就必须先证明最优性。** 这题不能，因为一个三角形可能属于多个候选组，得全局看。

## 六、实测：68% 不一致

顶点取 0~7、每个用例 3~8 个三角形，随机生成 20000 组，与并查集正解对比：

| 类别 | 例数 | 占比 |
|---|---|---|
| 偏小（少算） | 12423 | 62.1% |
| 偏大（多算） | 1185 | 5.9% |
| **合计不一致** | **13608** | **68.0%** |

**两个方向都错**，正说明错误①和责任②在互相抵消：`== 2` 偏严（偏小），聚合判断偏松（偏大）。

而他自己给的样例 `{{0,1,2},{0,2,3},{4,5,6},{2,3,4}}` 恰好得 3 —— 所以能过一部分用例，卡在 60%。

## 七、正解：建图 + 并查集

把**每个三角形看成一个节点**，两个三角形共享 ≥2 个顶点就连一条边，然后求**最大连通分量**。

```cpp
struct DSU {
    vector<int> p;
    DSU(int n) : p(n) { for (int i = 0; i < n; ++i) p[i] = i; }
    int find(int x) { return p[x] == x ? x : p[x] = find(p[x]); }
    void unite(int a, int b) { a = find(a); b = find(b); if (a != b) p[a] = b; }
};

int sharedVerts(const vector<int>& a, const vector<int>& b) {
    int c = 0;
    for (int x : a) for (int y : b) if (x == y) ++c;
    return c;
}

int maxConnectedTriangles(vector<vector<int>>& tri, int n) {
    if (n <= 0) return 0;
    DSU d(n);
    for (int i = 0; i < n; ++i)
        for (int j = i + 1; j < n; ++j)
            if (sharedVerts(tri[i], tri[j]) >= 2) d.unite(i, j);   // ★ 两两判断

    map<int, int> cnt;
    int best = 0;
    for (int i = 0; i < n; ++i)
        best = max(best, ++cnt[d.find(i)]);      // 每个根下有几个
    return best;
}
```

**三个关键点**：

1. **`>= 2` 而不是 `== 2`**：两个完全相同的三角形也共享边
2. **两两判断，不用聚合集**：`sharedVerts` 只吃两个原始三角形
3. **并查集天然处理"多个连通块"**：不需要知道有几组，扫完统计每个根的大小即可

**复杂度**：比较 `O(n²)` 次，每次比 9 对顶点 → `O(n²)`；并查集近 `O(1)`。空间 `O(n)`。

实测与独立实现的 BFS 版**逐例一致**（2 万组 0 差异）。

## 八、另外两种题意的解法

题目表述有歧义，面试时**先问清楚**再写：

| 题意 | 模型 | 解法 |
|---|---|---|
| **最大连通组**（本笔记） | 无向图连通分量 | **并查集** / DFS，`O(n²)` |
| **最长相邻链**（每个只接前一个） | 有向图最长路径 | 建图 + DFS 记忆化；**有环时无解**，要判环 |
| **最大团**（两两相邻） | 最大团 | **NP-hard**，n 小才能回溯；别写成贪心 |

灯皇的 `dp` 命名暗示他按第三种（最长链）想的，但 `temp` 累积又像第二种（连通组）—— **模型没定，代码就成了混合体**，这也是错的深层原因。

> 遇到"最大 XX"的题，先明确三件事：① 组内关系是"连通"还是"两两"？② 是要一段还是任意多？③ 有没有顺序要求？

## 九、易错点

1. **`== 2` 应为 `>= 2`** —— 两个三角形可能共享 3 个顶点（同一个三角形出现两次）
2. **不要用顶点并集判连通** —— 必须两两比，否则会拼出假共享
3. **不要用贪心求"最大"** —— 除非能证明贪心选择性质
4. **`n` 与 `tri.size()` 不一致会越界** —— 建议直接用 `tri.size()`，别另传 `n`
5. **`isConnected(vector<int> a, vector<int> b)` 按值传** —— 每对比较拷两次 vector，应 `const&`
