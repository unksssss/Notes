| 笔记 | 核心内容 |

| 📎 [[二叉搜索树BST]] | 性质（左<根<右，**中序遍历 = 升序**）；递归查找 / 插入（查到空位才 `new`）/ 删除三情况（叶子 / 单孩子顶替 / 双子用**中序后继值替换 + 递归删后继**）；三个实现坑（根指针未初始化野指针、`remove` 递归返回值没接住丢子树、分支缺 `return`）；顺序插入退化成链 O(n) → 引出平衡树 |
| 📎 [[二叉平衡树AVL]] | **严格平衡 \|bf\| ≤ 1**：平衡因子 + **最小失衡子树** + 四型旋转 **LL/RR/LR/RL**（之字先掰直，旋转后**先更新儿子再更新新根**）；插入**至多 1 次旋转** vs 删除**最坏 O(log n) 次**；斐波那契树高上界 **1.44·log₂n**；与 BST / 红黑树三方对比 |
| 📎 [[红黑树]] | 五性质（根黑 / NIL 黑 / 禁红红 / 黑高相等）；黑高推导树高 ≤ 2·log₂(n+1)；插入默认红、父红才修；**插入三 case**（叔红→变色上推 / 叔黑之字→绕 P 掰直 / 叔黑一字→绕 G 旋转+换色）；**2-3-4 树同构**（黑=占层格子、红=格内挂件、禁红红=每格 ≤3 key）；C++ `map`/`set` 底层 |

#### 3. 网络方向补全（`2436df4` / `8461514` / `60d9152`）

- **新建** 📎 [[可靠 UDP 与 KCP 原理]]：核心结论 **「可靠 UDP = 把序列号 / ACK / 重传 / 滑动窗口搬到用户态重做」**（TCP 那套在内核里改不动）。四个机制逐个拆解：一次丢包完整走查、**TCP 字节序号 vs 包序号**、累积确认 vs 位图确认、**超时重传 vs 快速重传（阈值为何是 3）**、`min(rwnd, cwnd)` 与流量控制·拥塞控制分工；**RTO 是算出来的**（Karn 算法 + Jacobson 公式 + 退避 ×2 vs ×1.5）、BDP 与吞吐上限公式、`MSS = MTU − 首部`；KCP 比 TCP 快在哪 = **用带宽换延迟**；**选择性可靠**——指令类走可靠通道、状态类走不可靠通道。
- **补强** 📎 [[TCP 与 UDP 的区别与游戏选型]]：新增「**字节流 vs 数据报**」一节 —— 收发次数不对应 / 读不完时续读 vs 截断 / **粘包归属与三种划界方案**；**队头阻塞**是实时游戏弃用 TCP 的核心原因（位置数据有时效性，宁可丢包也不等重传）。
