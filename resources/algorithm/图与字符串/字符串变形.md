# 字符串变形

> **题目**：给定含空格的字符串 `s` 和长度 `n`，把**由空格隔开的单词反序**，同时**反转每个字符的大小写**。
> 例：`"Hello World"` → `"wORLD hELLO"`

## 一、核心认知：这题其实是两件事

| 要求 | 具体动作 |
| --- | --- |
| **单词顺序反序** | 最后一个词挪到最前面，第一个词挪到最后 |
| **每个字符大小写反转** | `isupper → tolower`，`islower → toupper` |

**关键：单词内部的字符顺序不能变。** "World" 变成 "wORLD"，不是 "DLROw"。这一条是区分「整体反转字符串」和「按单词反转」的分水岭 —— 初学者最容易把整串 `reverse` 一遍就当完事。

## 二、灯皇的栈思路（方向对，而且很巧）

从**右往左**扫，一路上把字符**压栈**；遇到空格就**把栈清空弹出**。

为什么巧：栈的 LIFO 会把「从右往左压入」自动变成「从左往右弹出」，于是**一个栈同时完成了两件事**：

```
"World" 从右往左读： d, l, r, o, W
压栈后转大小写：    D, L, R, O, w   （栈底 → 栈顶）
弹出：              w, O, R, L, D   →  "wORLD"
```

- 弹出顺序 = 单词内部**正序**（因为压入时是反的）
- 单词被处理的先后 = **从后往前**（因为扫描方向）+ 空格重新插入 = 单词顺序反了

一个数据结构顶两个循环，这是很好的直觉。

## 三、唯一的 bug：`i > 0` 漏掉 `s[0]`

```cpp
for (int i = n - 1; i > 0; i--)      // ❌ 应为 i >= 0
```

从 `n-1` 扫到 `0` 一共 `n` 个字符，写 `i > 0` 只扫到 `i == 1`，**少处理第一个字符 `s[0]`**。

而 `s[0]` 恰好是**第一个单词的首字母**，反序之后它属于**最后一个单词** → 所以错误表现为「输出的最后一个单词缺一个字母」。

实测（7 个用例，**6 个错**）：

| 输入 | 期望 | 原版输出 | 差异 |
| --- | --- | --- | --- |
| `Hello World` | `wORLD hELLO` | `wORLD ELLO` | 缺 `h` |
| `This is a sample` | `SAMPLE A IS tHIS` | `SAMPLE A IS HIS` | 缺 `t` |
| `" hello world "` | `" WORLD HELLO "` | `" WORLD HELLO"` | 缺末尾空格 |
| `a` | `A` | **`""`** | `n=1` 时循环一次都不进，整个串丢了 |
| `a b` | `B A` | `B ` | 缺 `A` |
| `abc  def` | `DEF  ABC` | `DEF  BC` | 缺 `a` |
| `""` | `""` | `""` | ✅ 唯一对的（本来就空） |

**「单字符 `a` 返回空串」这个用例最有说服力** —— `i > 0` 在 `n == 1` 时让循环体零次执行，函数直接返回空字符串。而空串恰好是这题唯一的"通过"用例，说明**这个 bug 不会被空串掩盖**。

## 四、修法一：只改循环条件（保留栈思路）

```cpp
string trans(string s, int n) {
    stack<char> st;
    string result;
    for (int i = n - 1; i >= 0; i--) {          // ★ i >= 0
        char c = s[i];
        if (c != ' ') st.push(isupper(c) ? tolower(c) : toupper(c));
        else {
            while (!st.empty()) { result += st.top(); st.pop(); }
            result += ' ';
        }
    }
    while (!st.empty()) { result += st.top(); st.pop(); }
    return result;
}
```

顺手把三件事也收紧了：

1. 大小写合并成一句三元表达式（原来是两个分支，逻辑重复）
2. `else` 分支改成显式判断 `c == ' '` 的取反 —— 原版把所有非字母字符都当空格，题目虽然保证只有空格和字母，但显式写更安全
3. `st.push()` 前不再分开判断大小写，`toupper`/`tolower` 对数字和符号原样返回，不影响结果

## 五、修法二（推荐）：整体反转 + 逐词反转，`O(1)` 空间

```cpp
string trans(string s, int n) {
    // ① 大小写反转（每个字符独立，放前面放后面都行）
    for (char& c : s) {
        if (islower((unsigned char)c)) c = toupper((unsigned char)c);
        else if (isupper((unsigned char)c)) c = tolower((unsigned char)c);
    }
    // ② 整体反转：单词顺序反了，但每个单词内部也反了
    reverse(s.begin(), s.begin() + n);
    // ③ 逐词反转回来：恢复单词内部顺序
    int i = 0;
    while (i < n) {
        int j = i;
        while (j < n && s[j] != ' ') ++j;
        reverse(s.begin() + i, s.begin() + j);
        i = j + 1;
    }
    return s;
}
```

**两遍反转的妙处**：

```
"Hello World"  --整体反转-->  "dlroW olleH"  --逐词反转-->  "World Hello"
```

第一步把单词顺序弄反了（顺带每个词内也反了），第二步把每个词内部反回来。**净效果 = 单词逆序 + 词内不变**。

**首尾空格和连续空格天然保留**：反转只是搬位置，不会增减空格；逐词反转遇到空格就跳过，双空格还是双空格。

复杂度 `O(n)` 时间 / **`O(1)` 额外空间**（原地改 `s`，函数参数虽然是值传递，但内部不再需要第二个缓冲区）。

## 六、三版对比

| | 原版 | 修法一（栈） | 修法二（反转） |
| --- | --- | --- | --- |
| 正确性 | ❌ 漏 `s[0]` | ✅ | ✅ |
| 时间 | `O(n)` | `O(n)` | `O(n)` |
| 额外空间 | `O(n)` 栈 + `O(n)` 结果串 | 同 | **`O(1)`** |
| 代码长度 | 短 | 短 | 略长（两个循环） |
| 直观度 | ★★★ 一个栈搞定两件事 | 同 | ★★ 需要想通"反转两次" |
| 首尾/连续空格 | 修好后正确 | 正确 | 正确 |

## 七、易错点

1. **`i > 0` 漏 `s[0]`** —— 从 `n-1` 到 `0` 共 `n` 个字符，边界必须是 `>= 0`
2. **只处理一种大小写方向** —— 只写 `isupper → tolower` 忘了 `islower → toupper`，小写字母全部原样
3. **`toupper` / `tolower` 的参数要转 `unsigned char`** —— 这两个函数接受 `int`，若 `char` 是有符号的，遇到 >127 的字节（中文 UTF-8 常见）会传负数 → **未定义行为**。写成 `toupper((unsigned char)c)` 才安全
4. **别 trim 首尾空格** —— 题目要求原样保留（`" hello world "` 的正确输出首尾都有空格）
5. **别用 `erase` 移动空格** —— 那会把连续空格压成一个
6. **只反转整串就交** —— 每个单词内部也被反了，句子变乱码
7. `n` 与 `s.size()` 一般相等，但按题面签名用 `n` 更稳（`s.begin() + n` 也是对的）

## 八、复杂度

| 版本 | 时间 | 空间 |
| --- | --- | --- |
| 栈版 | `O(n)` | `O(n)` 栈 + `O(n)` 结果 |
| 反转版 | `O(n)`（每字符被访问常数次） | **`O(1)`** 额外 |

## 九、面试延伸

- **「不许用额外空间」** → 只能用反转版（栈版必然 `O(n)`）
- **「单词不反转，只反转字符大小写」** → 去掉第 ② 步就行
- **「反序单词但压缩多余空格」** → 反转后在逐词扫描时顺便重建结果串（双指针原地压缩）
- **「C 风格 `char*`，`in-place`，不许 `malloc`」** → 就是 `reverse` 版，但 `reverse` 要自己写
- **和 `LC 151 反转字符串中的单词` 的关系** → 那题要求「压缩多余空格 + 去首尾」，本题要求「原样保留空格」，算法骨架相同但第 ③ 步的收尾不同

## 实测

| `Hello World` | `wORLD hELLO` | ❌ `wORLD ELLO` | ✅ | ✅ |
| `This is a sample` | `SAMPLE A IS tHIS` | ❌ | ✅ | ✅ |
| `" hello world "` | `" WORLD HELLO "` | ❌ | ✅ | ✅ |
