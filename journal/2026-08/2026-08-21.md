### C++ 学习 — 二叉树迭代版三遍历完成（四遍历全成就）

目标：`D:\CppTest\hello\Tree\Tree.cpp`（今日 14:44，昨日递归版基础上补迭代版）

昨日递归版 → 今日补齐 **preorderIter / inorderIter / postorderIter（双栈法）**：

```cpp
// 前序迭代：先压右再压左（栈 LIFO，右先入栈出栈顺序才是"左先"）
void preorderIter(TreeNode* node)
{
    if(node==nullptr) return;
    std::vector<TreeNode*> stack;
    stack.push_back(node);
    while(!stack.empty())
    {
        TreeNode* node = stack.back();
        stack.pop_back();
        std::cout<<node->val<<std::endl;
        if(node->right) stack.push_back(node->right);
        if(node->left) stack.push_back(node->left);
    }
}

// 中序迭代：钻到底压栈 → 弹栈访问 → 转右开新局（两层循环）
void inorderIter(TreeNode* root)
{
    if(root==nullptr) return;
    std::vector<TreeNode*> stack;
    TreeNode* cur = root;
    while(!stack.empty()||cur!=nullptr)
    {
       while(cur!=nullptr)          // 左链全压栈（记账）
       {
            stack.push_back(cur);
            cur = cur->left;
       }
       cur = stack.back();          // 弹出访问（还债）
       stack.pop_back();
       std::cout<<cur->val<<std::endl;
       cur=cur->right;              // 转右开新局
    }
}

// 后序迭代：双栈法 —— s1 走"根右左"前序变体 + s2 反转成"左右根"
void postorderIter(TreeNode* root)
{
    if(root==nullptr) return;
    std::vector<TreeNode*> stack1, stack2;
    stack1.push_back(root);
    while(!stack1.empty())
    {
        TreeNode* cur = stack1.back();
        stack2.push_back(cur);
        stack1.pop_back();
        if(cur->left) stack1.push_back(cur->left);   // 注意先左后右（与前序相反）
        if(cur->right) stack1.push_back(cur->right);
    }
    while(!stack2.empty())
    {
        TreeNode* cur = stack2.back();
        std::cout<<cur->val<<std::endl;
        stack2.pop_back();
    }
}
```

验证：编译运行，递归 vs 迭代输出全部一致（`1 2 4 5 3 6 / 4 2 5 1 3 6 / 4 5 2 6 3 1`）✅

教学要点：
- **显式栈 = 模拟调用栈**：Day 21 账本比喻 + Day 23/27 前序迭代的落地，递归转迭代的实质就是自己管"下一层要干什么"的栈
- **中序迭代三层洞察**：压栈=记账（把待访问的祖先记下来）、弹出=还债（左子树走完轮到根）、转右=开新局（对右子树重新执行同一套流程）
- **双栈法 = 曲线救国**：后序（左右根）不好直接做，先走"根右左"变体（改前序的压栈顺序），再用第二个栈反转即得

### C++ 学习 — 层序 BFS 完成 + 红黑树路线启动（BST 第一天）

**层序 BFS**（`Tree.cpp`，vector + head 指针模拟队列，验证输出 `1 2 3 4 5 6` ✅）：

```cpp
void levelorder(TreeNode* root)
{
    if(root==nullptr) return;
    std::vector<TreeNode*> queue;
    size_t head = 0;
    queue.push_back(root);
    while(head<queue.size())
    {
        TreeNode* cur = queue[head];
        std::cout<<cur->val<<" ";
        if(cur->left) queue.push_back(cur->left);
        if(cur->right) queue.push_back(cur->right);
        head++;
    }
}
```

```cpp
BSTNode* insert(BSTNode* root,int val)
{
    if(root==nullptr)
        return new BSTNode(val);
    if(val>root->val)
        root->right = insert(root->right,val);   // 递归插入右子树
    else if(val<root->val)
        root->left = insert(root->left,val);     // 递归插入左子树
    return root;
}
```
