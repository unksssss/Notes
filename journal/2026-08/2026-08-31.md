### FireSim_URP_PC — TaskStateManager 任务数据层抽取（08-27 补录）

路径：`Assets/Scripts/Author/Wt/UI/WristUI/TaskTips/TaskStateManager.cs`

**背景**：项目 VR → PC 改造，手腕任务面板（TaskPanelPlus）UI 设计稿未出。策略：不整类重写，**抽逻辑层，表现层等设计稿**。

**核心设计**：纯 C# 静态单例（不依赖 MonoBehaviour），任务状态与 UI 解耦：

```cs
public class TaskStateManager
{
    public static TaskStateManager Instance { get; } = new();
    private TaskStateManager() { }

    /// <summary>TaskType → 中文描述（从 TaskPanelPlus 搬来）</summary>
    public Dictionary<TaskType, string> TaskDescMap { get; } = new() { /* 11 种任务 */ };

    public readonly Dictionary<TaskType, TaskStatus> dataDict = new();
    public IReadOnlyDictionary<TaskType, TaskStatus> DataDict => dataDict;   // 只读暴露，防外部绕过事件

    public event Action<TaskType, TaskStatus> OnTaskStatusChanged;

    public void SetStatus(TaskType taskType, TaskStatus status)
    {
        dataDict[taskType] = status;
        if (status == TaskStatus.Finished) completedTaskCount++;              // ⚠️ 累加实现，见下方风险
        OnTaskStatusChanged?.Invoke(taskType, status);
    }

    private void BindEventSystem()
    {
        TaskTipsSystem.Instance?.SubscribeAll(arg0 =>
        {
            if (arg0.Status == TaskStatus.Finished) SetStatus(arg0.taskType, TaskStatus.Finished);
        });
    }

    public void StartTask(TaskType taskType)
    {
        SetStatus(taskType, TaskStatus.GoingOn);
        TaskTipsSystem.Instance?.Notify(taskType, TaskStatus.GoingOn);
    }
}
```

要点与踩坑：
- `DataDict` 暴露为 `IReadOnlyDictionary`：若直接暴露 `Dictionary`，外部可 Add/Remove 绕过事件广播 → 状态变更不通知 UI。
- `TaskTipsSystem.Instance?.` 空安全绑定：若 TaskTipsSystem 尚未 Awake（Instance null）会**静默失败**，注意 `Init()` 调用时机。
- **⚠️ 遗留风险（现状与结论不一致）**：当时结论是"CompletedTaskCount 用累加字段会翻倍，必须每次从状态重新推导"，但最终代码仍是 `SetStatus` 里 `completedTaskCount++` 的累加实现——若同一任务 `Finished` 被重复回调（订阅去重缺失），计数会翻倍。待修点，可改为：

```cs
public int CompletedTaskCount
{
    get
    {
        int count = 0;
        foreach (var kv in dataDict) if (kv.Value == TaskStatus.Finished) count++;
        return count;
    }
}
```

TaskPanelPlus 同步瘦身：删 dataDict/TaskFinished/SubscribeAll，改订阅 `OnTaskStatusChanged` 刷新 UI；Confirm 调 `TaskStateManager.Instance.StartTask(chooseTask)`。

### FireSim_URP_PC — Ignis 运行时点火顺序 + 环境排坑（08-28 补录）

**Ignis 运行时改字段要点**（`FlameOn` / `FlameRestart`，顺序不能乱）：

```cs
private void FlameOn()
{
    if (FlameEngine.instance != null)
        FlameEngine.instance.modifyFlamesOnRuntime = true;   // ① 先开"运行时可改"开关
    ApplyToAll(obj => obj.isEffectOnForever = true);          // ② 常燃（不熄灭）
    ApplyToAll(obj => obj.burnOutLength_s = 1000f);           // ③ 燃烧时长拉满（等效不烧完）
    ApplyToAll(obj => obj.SetOnFireFromCenter());             // ④ 从中心点燃
}

private void FlameRestart()
{
    ApplyToAll(obj => obj.ExtinguishFully());                 // 先全灭再重燃
    // ②③④ 同上
}
```

根因回顾：Ignis（FlameEngine/FlammableObject）**运行时改字段必须先开 `modifyFlamesOnRuntime`**，否则 Inspector 改的值不会同步到运行时模拟（📎 [[Ignite-灭火机制分析]]）。

**环境排坑：WHEA 硬件错误导致电脑崩溃**。排查结论：与超大 docx 文件 + Windows 快速启动相关 → 修复方案 `powercfg /hibernate off` 关闭快速启动（管理员权限），重启后稳定。
